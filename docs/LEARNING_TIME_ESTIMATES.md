# 知识地图学习耗时估计

表格中的小时是**学习者的有效投入时间**，用于安排学习，不是AI编写教材的耗时。数值为本项目针对读者背景作出的人工规划估算，尚无真实学习者计时数据，不是行业标准、置信区间或固定通关承诺。

## 适用读者与学习范围

读者已有多年Android / Flutter / React Native经验，具备编程、网络、类型、架构和调试基础，但首次系统学习浏览器Web。下限适用于相关经验较多、能顺利解释和排错；上限给浏览器差异、练习返工和集成留下余量，实际仍可能超出区间。

每阶段包含：理解理论并解释机制；运行或按说明观察示例；完成关键独立练习；完成一个最小综合切片。相近能力在练习和项目中复用，避免重复计时。**估计覆盖全图，包含React等选修的教材范围**；不默认完成每个扩展变体、长期巩固、部署所有云平台或上线完整生产产品。全阶段合计只是各区间端点相加，不是达到高级职级的工时，也不是Vue/Nuxt首次交付的最低门槛。按[学习路径](./LEARNING_PATH.md)跳过不适用选修后应重新估算自己的路线，不能照搬全图合计。

## 维护与输出

唯一数值来源为[scripts/data/learning_hours.json](../scripts/data/learning_hours.json)，各阶段的basis说明估算依据。标题/知识点/正文完成度仍取实际地图与文件，耗时不按知识点数量机械乘算，也不随正文已编写或学习复选框自动减少；它估计的是从头学习本阶段的投入，不是个人剩余时间。

运行 `python3 scripts/check_knowledge.py --table` 自动显示“学习耗时估计（小时）”并合计。未配置的非空阶段显示“待估算”，合计显示“待补全”，不静默当0；空阶段显示“—”；无效或倒置区间报错，不能以旧结果充数。增加或实质调整课程范围时复核对应阶段区间，不把总数自动增长等同估算已校准。有自己的计时后，可记录实际范围并据此修订。

已检索Modern Web Guidance的学习相关资料，没有找到适用于本课程的阶段工时表。其[持续学习文章](https://developer.chrome.com/blog/beyond-code-generation)可帮助理解“解释选择、审查代码、验证假设”的学习方式，**不为本表的小时数提供统计依据**。本次只改Python统计展示与规划元数据，不改变Web示例技术方案。
