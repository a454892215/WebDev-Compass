# 知识内容编写与验证规范

## 先查依据，再写方案

Web 笔记、示例及评审遵循根目录 AGENTS.md。先用简短英文动作短语检索 Modern Web Guidance，再阅读匹配正文；无匹配或访问失败时记录结果，继续查 WHATWG、MDN、web.dev 或框架官方资料。链接指向具体页面并记录核对日期；指南中的新能力不等于所有浏览器已支持。

本轮参考 [Modern Web Guidance：HTML](https://developer.chrome.com/docs/modern-web-guidance/guides/html/html)，核对日期 2026-11-24。原生语义、表单标签、允许缩放、键盘操作和渐进增强为示例基本要求。可选新能力说明能力检测或回退。

## 正文与示例

每篇对应知识地图中的唯一序号，沿用已有路径；更名同步更新所有入口。至少包含概念机制、常用规则、最小代码、移动开发对照、误区、配套示例、实践验收与官方来源。

DNS、TLS 等可用可操作的观察清单代替浏览器 demo，但必须标明类型。不能把清单计为已运行的代码，不能用空文件、只有标题或无法运行的伪示例充当完成。

HTML 示例默认零依赖、无远程字体和上报、不使用真实凭据。资源本地提供；需用户选择媒体时说明操作和资源边界。交互优先原生元素，动态不可信内容使用 textContent。静态示例不宣称验证了真实后端、SEO 抓取或生产认证。

## 内容与学习进度分开

地图的 `[x]` 保留为原有或学习者主动记录的学习进度。生成正文不自动勾选。发布状态独立维护：

| 状态       | 判定                                       |
| ---------- | ------------------------------------------ |
| 已规划     | 地图有编号，正文尚不存在                   |
| 已编写     | 正文与必要示例存在，来源和链接可核对       |
| 本轮已验证 | 有实际命令、结果、日期及验证边界           |
| 待复核     | 旧正文已存在，但尚未按当前规范逐篇技术复审 |

知识点数量只代表内容覆盖，不代表深度或个人能力百分比。

## 最小充分验证

1. 运行检查器修复真实断链；未来章节仅以明确的预留链接存在，不为通过检查生成空文档。
2. 新交互执行对应后台浏览器检查，核对关键行为、控制台、键盘及宽窄视口；移动模拟不表述为真机通过。
3. 改动检查器时运行解析边界回归。人工技术审查、来源和浏览器证据分别记录。
4. 更新进度及本轮验证记录，检查差异后创建中文本地提交。推送、发布和真实业务测试另按授权执行。

scripts/ 的 rebuild_merged_map、split_knowledge_map、编号及术语迁移脚本是历史迁移工具。日常以六个分册为内容源，不在未审查输入的情况下反复执行旧迁移脚本。
