# AI辅助教程编写：教学依据与项目采用方式

检索与正文核对：2026-11-24。来源仅选机构、作者或项目的一手页面。下面把既有教学设计方法用于本库，不能将AI生成、自评通过或文件齐全当作学习有效性的证明。

| 来源与正文入口 | 来源支持的原则 | 本库采用方式与边界 |
| --- | --- | --- |
| [CMU Eberly：Learning Objectives](https://www.cmu.edu/teaching/designteach/syllabus/newcourse/learningobjectives.html) | 学习目标应可观察，并与教学活动及考核对齐 | 阶段目标映射到具体任务和判据；不把“了解框架”当可验收目标 |
| [IES/WWC：Organizing Instruction and Study](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)，[2007完整指南](https://ies.ed.gov/ncee/wwc/Docs/PracticeGuide/20072004.pdf) | 示例和独立解题交替，提取、延后回顾、解释性问题 | 预测/运行/解释、独立变体和阶段延后自测；指南不同建议证据等级不同，不把全部建议说成同等级强证据 |
| [Diátaxis：Tutorials](https://diataxis.fr/tutorials/) | 教程应有连贯小步、可见结果、可复现路径；长篇解释应有单独入口 | 原理放notes，操作路径放examples并链接；不把本库四目录强称Diátaxis四象限的一一实现 |

## 资料核对与研究适用范围

已阅读上表页面正文、Diátaxis教程关键原则以及IES完整PDF的相关建议；UNESCO英文UNESDOC落地页没有返回可解析正文，故只采用官网介绍页能够支持的高层原则，不声称全文逐章核验。IES指南发布于2007年，引用日期不是版本更新日期；CAST采用2024年的3.0版。CMU、Google和Diátaxis页面按本次读取内容使用，未编造发布日期。

这些来源包含机构教学建议、研究综合与技术写作方法，证据类型不同。成人资深移动开发者学习Web是本库的具体场景，教学方案属于据此作出的项目适配，尚无本项目学习者效果实验。不规定一套保证成功的复习天数、知识点字数或固定学习时长。

## 项目采用范围

只采用与目标有关的基本原则：目标和练习对应、按读者经验解释Web差异、从简单到复杂、操作有预期结果、保留独立尝试和纠错。预测、解释及延后变体作为学习建议，不强制打卡，也不增加单独教学设计文件。

阶段0、1已利用现有章节入口、逐点练习和综合任务落实这些原则；层次、事实假设和错误说明已在[本轮验收](./audits/STAGE_0_1_ACCEPTANCE.md)中复核。尚未进行真实学习者试学或长期保持实验，不声称资料审查等于学习效果证据。后续继续执行[阶段编写与验收总则](./AUTHORING.md)。
