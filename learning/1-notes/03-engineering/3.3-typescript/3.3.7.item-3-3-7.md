# 3.3.7 函数参数、返回值与回调契约

[章节目录](./README.md) · [知识地图](../../../../knowledge-map/02-engineering-stages-3-5.md)

## 前置与目标

JS函数、默认参数、回调与基本类型。

## 原理与选择

参数类型和返回类型描述调用契约；函数类型可用于依赖注入、事件回调和测试替身，不能混淆函数本身与执行结果。

可选参数意味着调用方可不传；默认参数在缺失或undefined时生效，不在null时自动生效。必需参数和可选顺序要设计清楚。

返回void的回调契约允许调用方忽略结果，不表示传入函数不能有返回值。strictFunctionTypes对函数参数兼容提供额外检查，方法位置有特殊规则，不以一个例子概括所有变体。

## 最小例子

```typescript
type Formatter = (title: string, prefix?: string) => string;
const format: Formatter = (title, prefix = "") => prefix + title;
console.log(format("课程"), format("课程", "#"));
```

此处是本节机制片段；完整可编译源和反例见[运行实验](../../../2-examples/03-engineering/3.3-typescript/3.3.7.item-3-3-7-demo.md)。类型检查与运行输出分别观察，不能把注释当编译器证据。

## 场景、边界与误区

为模块协作固定最小契约。异步函数显式Promise<Result>，注意reject不是类型中的自动错误分支，错误处理另设计。

## 移动开发对照

与移动端函数类型/lambda概念相通，但JS调用参数及void兼容规则不同，不直接照搬语法。
