## 原理与选择

Vue组件的Props与事件形成组件契约；defineComponent可从运行时props/emits声明推断类型。script setup的defineProps/defineEmits属于SFC编译宏，不能在任意普通TS文件直接调用来模拟编译。

composable函数可以返回Ref、方法及只读派生值；Ref<T>与T不同，script与模板解包规则后续展开。不要为方便全转any失去返回契约。

类型注解与运行时props验证仍有边界。示例只编译契约、创建VNode并运行ref函数，不挂载DOM，不声称已验证交互；组件测试在3.5，完整Vue在阶段4。React只作为选修，不额外引依赖。

## 最小例子

```typescript
import { ref } from "vue";
function useSelection() {
  const selected = ref<string | null>(null);
  return { selected, select: (id: string) => { selected.value = id; } };
}
const state = useSelection(); state.select("a");
console.log(state.selected.value);
```

此处是本节机制片段；完整可编译源和反例见[运行实验](../../../2-examples/03-engineering/3.3-typescript/3.3.11.react-vue-ts-props-demo.md)。类型检查与运行输出分别观察，不能把注释当编译器证据。
