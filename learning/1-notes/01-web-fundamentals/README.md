## 阶段目标与推荐顺序

前置：完成阶段 0 的本地服务、DevTools 和请求/响应观察。目标：独立完成语义正确、布局可用、有交互和失败恢复的原生 Web 页面，并能解释核心浏览器行为。此阶段不依赖 Vue/Nuxt。

推荐顺序：1.1.1 文档语义 → 1.1.2 原生表单结构 → 1.2 样式与布局 → 1.3 语言基础/DOM/事件/异步 → 返回 1.1.3 及表单脚本练习 → 1.4 完整质量走查 → 综合项目独立实现。1.4 的标签、键盘和失败提示从早期贯穿，不必等到最后才考虑。CSS 构建工具需先具备阶段 0 包管理和基本 CLI 能力；不以深入 Vite 原理作为本阶段阻断条件。

综合验收要求代码、观察结果和一次故障修复记录，四部分入口见[学习入口](../../README.md)。地图编号是稳定索引，具体阅读顺序按前置关系安排。
