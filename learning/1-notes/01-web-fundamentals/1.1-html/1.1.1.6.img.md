# 1.1.1.6 图片与媒体：img、picture、video、audio、source、figure

> [← 返回 HTML 目录](./README.md) · [知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 一句话理解

图片、音频和视频各有原生资源选择与播放能力；可访问替代内容、尺寸和加载策略同样属于媒体交付。

## 核心机制与选择

| 元素/属性                    | 作用                                                  |
| ---------------------------- | ----------------------------------------------------- |
| `img` + `alt`                | 显示图片并提供符合上下文的替代文本；纯装饰用 `alt=""` |
| `width` / `height`           | 提前给出固有比例，减少加载布局跳动                    |
| `srcset` / `sizes`           | 给出候选资源与预期显示尺寸，由浏览器选择              |
| `picture` + `source` + `img` | 按视口构图或支持格式选择资源，img 是必要回退          |
| `video` / `audio`            | 原生播放、暂停、音量和进度控制，使用 controls         |
| `track`                      | 为媒体加载字幕等定时文本，常见格式为 WebVTT           |
| `figure` / `figcaption`      | 对相对独立的图、代码或媒体及其说明分组                |

首屏关键图不要随意 lazy；非首屏图可使用 loading="lazy"。alt 应表达图片在当前内容中的意义，通常无需重复“这是一张图片”。

## 最小示例

```html
<figure>
  <picture>
    <source media="(max-width: 500px)" srcset="diagram-narrow.svg" />
    <img
      src="diagram-wide.svg"
      alt="请求从浏览器发往服务器，再返回响应"
      width="800"
      height="300"
    />
  </picture>
  <figcaption>浏览器与服务器的通信。</figcaption>
</figure>
<!-- 下列资源路径需要替换为真实媒体与对应字幕。 -->
<video controls playsinline preload="metadata">
  <source src="lesson.mp4" type="video/mp4" />
  <track
    kind="captions"
    src="lesson.zh.vtt"
    srclang="zh"
    label="中文字幕"
    default
  />
</video>
```

## 实际使用与边界

文字稿帮助理解语音内容；需要时还应描述关键视觉信息，字幕应与所发布媒体对应。video 的后备文字不会在所有“编码不支持”情形自动变成错误提示，真实项目应处理 error 状态。

示例用两张本地 SVG 演示构图切换、一个生成的 WAV 演示 audio。视频需主动选择本地文件，不上传；示例没有完整视频课程和字幕资产，因此不声称覆盖真实字幕验收。Object URL 在替换或离开页面时释放。

## 📱 移动端对照

img 可以类比 Image，video 可以类比平台播放器，但浏览器还涉及资源协商、网络缓存、自动播放限制和文档可访问性。控件存在不表示资源一定能解码。

## 常见误区

- 图片尺寸约束与响应式 srcset 是两个不同问题。
- alt、caption 和字幕各有用途，不能互相随意替换。
- 不自动播放带声音媒体，也不把浏览器静音策略当成保证。

## 实践与验收

配套示例：[打开 1.1.1.6.img-demo.html](../../../2-examples/01-web-fundamentals/1.1-html/1.1.1.6.img-demo.html)。

1. 调整视口，在 Console 检查 `document.querySelector('#diagram').currentSrc`。
2. 用音频原生控件播放一秒提示音，再阅读文字替代。
3. 可选本地视频并测试播放/错误；文件始终留在本机。
4. 检查图片加载后是否出现明显布局跳动。
