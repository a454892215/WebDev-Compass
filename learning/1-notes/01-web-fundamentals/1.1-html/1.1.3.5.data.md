# 1.1.3.5 data-* 自定义属性

> [← 返回 HTML 目录](./README.md) · [知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 一句话理解

data-* 把公开的、与元素相关的补充信息放在 HTML 上，JavaScript 通过 dataset 读写字符串。

## 工作方式与使用规则

`data-project-id` 对应 `element.dataset.projectId`：连字符转换为驼峰命名。读写值始终是字符串，设置数字也会转换；删除用 delete element.dataset.key 或 removeAttribute。

适合测试定位、轻量组件配置、事件委托中的操作名或公开标识。实际权限、token、价格校验和服务器状态不应该依赖它，用户可以直接修改 DOM。需要数字时显式转换并验证有限性，布尔值也不能用 Boolean('false') 解析。

事件委托要判断 event.target 是否为 Element，再用 closest 寻找目标按钮；复杂应用状态保留在数据层，而不是同时维护一份 dataset 和状态管理器造成不同步。展示用户文本使用 textContent，不能把 dataset 当可信 HTML 插入。

## 最小示例

本节属性结构可先阅读；数字转换、DOM 访问和事件委托的独立实现应在完成 1.3 对应章节后返回练习。不要把演示支架中的 JavaScript 当作 HTML 首课前置。

```html
<button type="button" data-project-id="demo-42" data-count="2">练习</button>
<script>
  const button = document.querySelector("button");
  const count = Number(button.dataset.count); // 显式解析
  if (Number.isFinite(count)) button.dataset.count = String(count + 1);
  console.log(button.dataset.projectId); // "demo-42"
</script>
```

## 📱 移动端对照

可类比 View 的 tag 或组件的公开附加参数，但 dataset 会出现在可检查的 DOM 中。与内存中的业务对象不是同一个信任边界。

## 常见误区

- dataset.count + 1：字符串可能拼成 "21"，先转换数字。
- data-admin="true" 可以授权：DOM 可被用户修改。
- 把重要说明仅写在 data-*：辅助技术与用户通常读不到，应有可见文本。
