# 1.1.1.5 链接与导航：href、锚点、相对路径与绝对路径

> [← 返回 HTML 目录](./README.md) · [知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 一句话理解

a 的 href 表达可导航的目标 URL；按钮表达当前界面动作，浏览器原生处理链接的键盘、菜单和历史行为。

## 核心机制与选择

| 写法                           | 解析方式                                   |
| ------------------------------ | ------------------------------------------ |
| `https://example.com/help`     | 包含协议和主机的绝对 URL                   |
| `/help`                        | 当前站点根路径；部署到子路径时需留意基路径 |
| `./help.html`、`../index.html` | 以文档基地址解析相对路径                   |
| `#contents`                    | 当前文档中的片段目标                       |

href 依据 `document.baseURI` 解析，通常就是当前文档 URL；head 中的 base 元素能改变它，因此入门项目不应无意添加 base。文件系统路径不是 Web URL。

## 最小示例

```html
<a href="./help.html">阅读帮助</a>
<a href="#details">查看详情小节</a>
<a href="https://example.com" target="_blank" rel="noopener noreferrer">
  官方站点（新窗口）
</a>
<button type="button">展开筛选</button>
<section id="details">
  <h2>详情</h2>
  <p>目标内容。</p>
</section>
```

## 实际使用与边界

不要把 href 设为 `javascript:`，也不要用 `href="#"` 伪装按钮。描述目标的文字比“点击这里”更有意义。新窗口应明确告知用户；noopener 隔离 opener，noreferrer 还会抑制 Referer，是否需要后者要结合业务。

片段不发送给服务器。SPA 可拦截站内导航，但仍应保留有效链接目标、浏览器后退和可复制 URL。跳转到不存在的 id 不会自动产生对应内容。

## 📱 移动端对照

Web URL 同时承担页面定位、分享、刷新和历史入口。它比单纯 Navigator.push 的运行时栈更外显；应在设计页面时一起考虑深链接。

## 常见误区

- 用 div 的 click 实现链接，会丢失打开新标签页、复制地址等原生能力。
- 给 link 文本加 aria-label 并不自动修复错误目标。
- 根相对地址在子目录静态托管中可能跳出项目。
