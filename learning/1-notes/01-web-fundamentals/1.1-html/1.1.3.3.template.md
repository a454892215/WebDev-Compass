# 1.1.3.3 template、slot 与 Web Components

> [← 返回 HTML 目录](./README.md) · [知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 一句话理解

template 保存可复用且不立即显示的 DOM 片段；slot 在 Shadow DOM 中接收宿主提供的内容。

## 工作方式与使用规则

template.content 是 DocumentFragment，内容在模板内不会按普通 DOM 直接呈现。需要重复使用时 cloneNode(true) 后插入；直接 append(template.content) 会把原片段移走，后续再取可能为空。它不是 Vue 的 template 指令系统，也没有自动数据绑定。

Web Components 包括 Custom Elements、Shadow DOM 等能力。自定义元素名称需要连字符；attachShadow 创建独立树，slot 放在这棵树里。宿主的普通子节点称 light DOM：slot="title" 匹配同名插槽，没有 slot 属性的节点分配到默认插槽。插槽后备内容只在没有被分配的节点时显示。

Shadow DOM 封装 DOM 与样式边界，不是安全沙箱；open 模式可通过 shadowRoot 读取。clone 的模板中 id 会重复，跨实例引用要放在各自 Shadow Root，普通 DOM 克隆应重新生成唯一 id。示例通过能力检测，失败时仍保留 light DOM 正文。

## 最小示例

这是理解原生组件边界的延伸片段；需要先掌握 1.3 的 DOM、类与模块基础，再自行编写。首次学习 HTML 时可先操作示例、观察模板不显示与克隆结果，不要求先实现构造函数。完整演示包含能力检测与 light DOM 回退。

```html
<template id="card"
  ><h2><slot name="title">默认标题</slot></h2></template
>
<script>
  customElements.define(
    "demo-card",
    class extends HTMLElement {
      constructor() {
        super();
        this.attachShadow({ mode: "open" }).append(
          document.querySelector("#card").content.cloneNode(true),
        );
      }
    },
  );
</script>
<demo-card><span slot="title">来自宿主的标题</span></demo-card>
```

## 📱 移动端对照

slot 类似 Vue 插槽、Flutter 通过参数传入 child 的组合思想，但原生 slot 的实际分发需要 Shadow DOM；不要把这几套运行机制混为一谈。

## 常见误区

- 页面任意位置放 slot 都会投影：普通 DOM 中不承担 Shadow DOM 插槽分发。
- template 自动重复渲染：需要克隆插入或框架接管。
- Shadow DOM 隔离秘密：它只是一种封装机制。
