# 1.2.4.4 响应式图片：布局、资源选择与构图

[返回 CSS 目录](./README.md) · [知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

前置：HTML 元素、属性与基本页面结构；含切换按钮的脚本仅用于观察，不要求此时掌握完整 JavaScript。

学完应能解释此规则、在 DevTools 中找到获胜声明或计算值，并对照内容变化判断是否适用。工程化选修项需区分源码与浏览器产物。

## 一句话理解

CSS控制图片盒子，srcset/sizes协助选资源，picture允许按条件选择不同构图或格式。

## 工作机制与使用规则

1. 图片通常用max-inline-size:100%;block-size:auto保持比例，并用width/height或aspect-ratio提前预留空间。
2. srcset的w候选需配合sizes说明预期显示宽度，浏览器还会考虑DPR等；不是保证每次选你指定文件。
3. picture中的source按媒体/类型条件匹配，img作为必要回退及替代文本载体。
4. object-fit:cover会裁切，contain保全图；信息性图片不要因视觉适配丢失关键内容。

## 最小代码与阅读顺序

```html
<picture>
  <source media="(max-width:500px)" srcset="./assets/narrow.svg" />
  <img src="./assets/wide.svg" alt="请求与响应" width="480" height="180" />
</picture>
<style>
  img {
    max-inline-size: 100%;
    block-size: auto;
  }
</style>
```

先读匹配目标与参照条件，再读计算结果。不要把一份截图当作所有内容、浏览器和字号均正确的证据。

## 移动开发经验对照

类似Image fit与分辨率资源变体，但浏览器可根据视口/DPR和网络缓存自行选源，DOM中的alt仍必须提供。

## 常见误区与修正

- 只写max-width就认为已经减少下载字节。
- cover裁切数据图且没有说明完整内容。
