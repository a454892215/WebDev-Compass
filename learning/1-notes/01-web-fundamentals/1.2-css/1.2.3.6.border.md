# 1.2.3.6 边框、圆角与阴影的布局边界

[返回 CSS 目录](./README.md) · [知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

前置：HTML 元素、属性与基本页面结构；含切换按钮的脚本仅用于观察，不要求此时掌握完整 JavaScript。

本点产出：写两张相邻卡片，对照border与box-shadow尺寸差别，并测试内部按钮焦点。 验收时需解释实际规则与适用边界，不能仅复述界面输出。

## 一句话理解

边框参与盒尺寸，阴影通常不参与正常布局，圆角也不自动裁切所有后代。

## 工作机制与使用规则

1. border-width/style/color共同定义边框；只设置颜色不保证有可见边线，border-style初始为none。
2. border-radius控制边角形状，可用多个值；它与overflow裁剪及后代绘制的关系需要单独处理。
3. box-shadow可以有多层、内阴影和模糊，但不会像margin一样为邻居预留空间。
4. 不要只用阴影提示焦点或禁用状态；forced colors或打印时效果可能变化。

## 最小代码与阅读顺序

```css
.card {
  border: 2px solid #146a83;
  border-radius: 12px;
}
.card {
  box-shadow: 0 4px 12px rgb(0 0 0 / 0.15);
}
```

先读匹配目标与参照条件，再读计算结果。不要把一份截图当作所有内容、浏览器和字号均正确的证据。

## 移动开发经验对照

与BorderRadius/BoxShadow相似；Web中的绘制溢出与正常流尺寸要分开分析。

## 常见误区与修正

- 阴影会自动撑开父元素和相邻间隔。
- 把所有内容overflow:hidden来配合圆角，连焦点轮廓也被裁。
