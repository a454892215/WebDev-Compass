# 1.2.3.5 背景图、尺寸、位置与重复

[返回 CSS 目录](./README.md) · [知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

前置：HTML 元素、属性与基本页面结构；含切换按钮的脚本仅用于观察，不要求此时掌握完整 JavaScript。

学完应能解释此规则、在 DevTools 中找到获胜声明或计算值，并对照内容变化判断是否适用。工程化选修项需区分源码与浏览器产物。

## 一句话理解

background负责盒子背后的装饰；承载内容信息的图片通常仍应使用img及替代文本。

## 工作机制与使用规则

1. background-color在图像未加载时提供底色；多个背景层按列表前者在上叠放。
2. cover填满区域并可能裁切，contain完整容纳并可能留空；背景定位影响裁掉的内容。
3. background-repeat默认repeat，图标/插画常需显式no-repeat；尺寸与position分开控制。
4. CSS背景没有alt，关键信息不能只藏在背景；高对比/打印/加载失败也应可理解。

## 最小代码与阅读顺序

```css
.banner {
  background: #e6f4f0 url("./assets/wide.svg") center / contain no-repeat;
  min-block-size: 10rem;
}
```

先读匹配目标与参照条件，再读计算结果。不要把一份截图当作所有内容、浏览器和字号均正确的证据。

## 移动开发经验对照

与BoxDecoration背景类似，但background-image参与资源下载，内容语义和alt不能靠装饰层补齐。

## 常见误区与修正

- 背景图片中的关键文案没有真实文字。
- 用cover显示身份证件/图表，裁掉关键边缘。
