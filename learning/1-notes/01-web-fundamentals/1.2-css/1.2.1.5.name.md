# 1.2.1.5 CSS 自定义属性与 var 回退

## 学习目标与前置

前置：HTML 元素、属性与基本页面结构；含切换按钮的脚本仅用于观察，不要求此时掌握完整 JavaScript。

学完应能解释此规则、在 DevTools 中找到获胜声明或计算值，并对照内容变化判断是否适用。工程化选修项需区分源码与浏览器产物。

## 一句话理解

自定义属性在浏览器层叠和继承阶段传递值，适合运行期主题与语义 token。

## 工作机制与使用规则

1. --name 定义大小写敏感的自定义属性，var(--name, fallback) 在使用点替换值，普通双横线属性默认继承。
2. 自定义属性可在元素子树覆盖；作用域越贴近组件，越容易避免全局 token 相互污染。
3. fallback 处理缺失/无效的自定义属性值，不会把所有代入后类型错误都变成合理值。
4. Sass 变量在构建时求值，自定义属性在运行期存在；JS 可用 style.setProperty 修改后者。

## 最小代码与阅读顺序

```css
.card {
  --accent: teal;
  color: var(--accent, navy);
}
.card[data-tone="warning"] {
  --accent: firebrick;
}
.card__icon {
  color: inherit;
}
```

先读匹配目标与参照条件，再读计算结果。不要把一份截图当作所有内容、浏览器和字号均正确的证据。

## 移动开发经验对照

类似 ThemeExtension/设计 token，但 CSS token 会参与级联和继承；不是强类型 Dart 对象，也不能装密钥。

## 常见误区与修正

- 把 var 的回退当成条件分支或类型校验。
- 所有值都定义全局变量，反而扩大耦合。
