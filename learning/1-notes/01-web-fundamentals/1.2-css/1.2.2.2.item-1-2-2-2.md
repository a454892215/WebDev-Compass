# 1.2.2.2 display：外部参与方式与内部布局

## 学习目标与前置

前置：HTML 元素、属性与基本页面结构；含切换按钮的脚本仅用于观察，不要求此时掌握完整 JavaScript。

学完应能解释此规则、在 DevTools 中找到获胜声明或计算值，并对照内容变化判断是否适用。工程化选修项需区分源码与浏览器产物。

## 一句话理解

display 同时决定盒子如何参与父布局，以及如何布局自己的子内容。

## 工作机制与使用规则

1. block/inline 描述外部流；flex/grid 建立内部格式化上下文，不能只理解成“横向/纵向”。
2. inline 通常不接受 width/height 的预期块尺寸；inline-block 在行内占位但可有块尺寸。
3. display:none 不生成布局盒，也会使内容通常不可被辅助技术访问；与 visibility:hidden、opacity:0 不同。
4. 切成 flex 不会自动把按钮、链接变得可访问；语义仍来自 HTML。

## 最小代码与阅读顺序

```css
.group {
  display: flex;
  flex-wrap: wrap;
  gap: 0.5rem;
}
.hidden {
  display: none;
}
/* 父元素成为 flex container，直接子元素成为 flex items */
```

先读匹配目标与参照条件，再读计算结果。不要把一份截图当作所有内容、浏览器和字号均正确的证据。

## 移动开发经验对照

Flex/Grid 与 Row/Column 目标相似，但 Web 的 DOM 源顺序、行内文字和盒生成行为需要单独理解。

## 常见误区与修正

- 把所有布局都写 display:flex，包括正文段落。
- 透明元素看不见但仍可点击/聚焦，误以为等同 none。
