# 1.2.5.3 transform：视觉变化与布局尺寸

[返回 CSS 目录](./README.md) · [知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

前置：HTML 元素、属性与基本页面结构；含切换按钮的脚本仅用于观察，不要求此时掌握完整 JavaScript。

学完应能解释此规则、在 DevTools 中找到获胜声明或计算值，并对照内容变化判断是否适用。工程化选修项需区分源码与浏览器产物。

## 一句话理解

transform在布局之后改变绘制坐标，通常不会让正常流中的邻居为其新位置重新排布。

## 工作机制与使用规则

1. translate、rotate、scale、skew可组合，组合顺序影响结果，不能任意交换。
2. transform-origin决定变换原点；百分比translate常相对元素自身参考盒，而不是父容器。
3. transform可创建层叠上下文和包含块，可能改变后代fixed/absolute行为。
4. 放大视觉内容不改变其布局占位；需要确保焦点轮廓、点击目标和溢出仍正确。

## 最小代码与阅读顺序

```css
.tile {
  transform-origin: center;
  transform: translateX(24px) rotate(3deg);
}
/* 顺序影响坐标；不等同于给邻居增加margin */
```

先读匹配目标与参照条件，再读计算结果。不要把一份截图当作所有内容、浏览器和字号均正确的证据。

## 移动开发经验对照

与Transform组件相似；CSS同时影响层叠和定位上下文，不能只把它看成绘图矩阵。

## 常见误区与修正

- scale放大后相邻元素会自动让位。
- 为了GPU加速到处添加translateZ(0)。
