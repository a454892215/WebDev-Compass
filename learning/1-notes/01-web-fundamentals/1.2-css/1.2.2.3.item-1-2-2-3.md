# 1.2.2.3 position：正常流、包含块与粘性定位

## 一句话理解

定位模式决定元素是否留在流中，以及 inset 相对哪一个包含块计算。

## 工作机制与使用规则

1. static 留在正常流，top 等 inset 通常不生效；relative 仍保留原位置，视觉偏移不推动相邻元素。
2. absolute 脱离正常流，相对于最近能建立相应包含块的祖先；“最近定位祖先”是常见情形而非全部规则。
3. fixed 常相对视口，但 transform 等祖先可能改变其包含块；sticky 依赖滚动容器、阈值和可移动空间。
4. sticky 需要对应轴的 inset；祖先 overflow 与容器高度常是失效排查点。

## 最小代码与阅读顺序

```css
.container {
  position: relative;
}
.badge {
  position: absolute;
  inset-block-start: 0.5rem;
  inset-inline-end: 0.5rem;
}
.toolbar {
  position: sticky;
  inset-block-start: 0;
}
```

先读匹配目标与参照条件，再读计算结果。不要把一份截图当作所有内容、浏览器和字号均正确的证据。

## 移动开发经验对照

接近 Stack/Positioned，但 CSS 包含块与滚动祖先并不是 Widget 父节点的简单映射。

## 常见误区与修正

- absolute 总相对父元素，无视包含块。
- 固定底部栏遮住内容，只增加z-index却不预留空间。
