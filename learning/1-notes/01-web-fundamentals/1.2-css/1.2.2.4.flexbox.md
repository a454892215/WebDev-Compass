## 一句话理解

Flexbox 是一维布局，先决定主轴，再分配该轴空间，并处理交叉轴对齐。

## 工作机制与使用规则

1. flex-direction 规定主轴；justify-content 沿主轴，align-items 沿交叉轴，不能固定翻译成水平/垂直。
2. flex-grow/shrink/basis 合作决定尺寸；basis 不是最终宽度，空间分配仍受 min/max 约束。
3. flex-wrap 允许换行，gap 管理项目间距；有多行剩余空间时 align-content 才有意义。
4. 长文本项目常需 min-inline-size:0；DOM 交互顺序不应为视觉重排而使用 order/reverse 随意改变。

## 最小代码与阅读顺序

```css
.items {
  display: flex;
  flex-wrap: wrap;
  gap: 12px;
}
.item {
  flex: 1 1 120px;
  min-inline-size: 0;
}
.action {
  margin-inline-start: auto;
}
```

先读匹配目标与参照条件，再读计算结果。不要把一份截图当作所有内容、浏览器和字号均正确的证据。

## 移动开发经验对照

与 RN Flexbox、Flutter Row/Column 有关联，但 CSS 默认收缩、内在最小尺寸和源顺序规则需重新验证。

## 常见误区与修正

- 列方向下仍把 justify-content 当水平对齐。
- 只写 flex:1，却忽略长字符串的自动最小尺寸。
