# 1.2.3.4 文本对齐、换行、截断与内容保留

[返回 CSS 目录](./README.md) · [知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

前置：HTML 元素、属性与基本页面结构；含切换按钮的脚本仅用于观察，不要求此时掌握完整 JavaScript。

学完应能解释此规则、在 DevTools 中找到获胜声明或计算值，并对照内容变化判断是否适用。工程化选修项需区分源码与浏览器产物。

## 一句话理解

文字排版由行内空间和换行机会共同决定；截断只改变呈现，不应丢掉读者需要的信息。

## 工作机制与使用规则

1. 用text-align:start/end适配书写方向；对齐与元素本身定位是两件事。
2. white-space控制空白与换行；overflow-wrap:anywhere适合允许长URL等在必要位置换行。
3. text-overflow:ellipsis通常还需受约束宽度、overflow及white-space:nowrap；只写ellipsis不会自动截断。
4. 不要用连续br或空格制造布局；重要完整值应可查看，不能依赖触屏不存在的hover提示。

## 最小代码与阅读顺序

```css
.title {
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}
.url {
  overflow-wrap: anywhere;
}
.copy {
  text-align: start;
}
```

先读匹配目标与参照条件，再读计算结果。不要把一份截图当作所有内容、浏览器和字号均正确的证据。

## 移动开发经验对照

类似TextOverflow和maxLines，但Web受文档流和实际容器宽度影响，省略号不是内容删除策略。

## 常见误区与修正

- 只给文本写text-overflow却不限制盒子。
- 对全部正文word-break:break-all，使普通单词难读。
