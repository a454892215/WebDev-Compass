# 1.2.6.5 现代选择器、流动尺寸与逻辑属性

## 学习目标与前置

前置：HTML 元素、属性与基本页面结构；含切换按钮的脚本仅用于观察，不要求此时掌握完整 JavaScript。

学完应能解释此规则、在 DevTools 中找到获胜声明或计算值，并对照内容变化判断是否适用。工程化选修项需区分源码与浏览器产物。

## 一句话理解

现代CSS能力可让默认样式容易覆盖、尺寸随空间变化，并适应不同书写方向。

## 工作机制与使用规则

1. :is()组合选择器并采用参数最大特异性；:where()同样可组合但自身及参数为零特异性。
2. min/max/clamp参与数值计算，需单位可比较；clamp(min,preferred,max)不替代真实内容溢出处理。
3. margin-inline、padding-block、inline-size等逻辑属性按书写方向映射；并非每个物理方向都应自动翻转。
4. 先确认目标浏览器，再渐进增强；原生嵌套、:has、@scope等按实际兼容范围选用，而非一股脑强制。

## 最小代码与阅读顺序

```css
:where(.card, .panel) {
  padding-block: 1rem;
}
.card {
  inline-size: min(100%, 30rem);
  font-size: clamp(1rem, 2vw, 1.4rem);
}
.card__badge {
  margin-inline-start: auto;
}
```

先读匹配目标与参照条件，再读计算结果。不要把一份截图当作所有内容、浏览器和字号均正确的证据。

## 移动开发经验对照

与支持RTL和约束尺寸的思路类似；CSS的选择器权重与书写模式映射需要独立验证。

## 常见误区与修正

- :where和:is的权重相同。
- 为了国际化把所有left/right机械替换，连不应翻转的图形方向也改变。
