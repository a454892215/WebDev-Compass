# 1.2.3.2 字体、行高与文字间距

[返回 CSS 目录](./README.md) · [知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

前置：HTML 元素、属性与基本页面结构；含切换按钮的脚本仅用于观察，不要求此时掌握完整 JavaScript。

学完应能解释此规则、在 DevTools 中找到获胜声明或计算值，并对照内容变化判断是否适用。工程化选修项需区分源码与浏览器产物。

## 一句话理解

字号决定字形尺度，行高决定行盒节奏；字体回退和内容长度都会改变布局。

## 工作机制与使用规则

1. font-family按列表选择可用字体，最后用通用族作为回退；系统字体在不同平台上外观和字宽不一致。
2. font-size常使用rem/em以响应根字号或局部字号；px不是完全不能缩放，但要尊重用户设置。
3. 无单位line-height作为乘数继承，通常比固定px更适合不同字号的后代。
4. font-weight的可用值受字体文件支持影响；letter-spacing过大可能伤害阅读，尤其是长文。

## 最小代码与阅读顺序

```css
.prose {
  font-family: system-ui, sans-serif;
  font-size: 1rem;
  line-height: 1.6;
}
.prose h2 {
  font-size: 1.5rem;
  line-height: 1.25;
}
```

先读匹配目标与参照条件，再读计算结果。不要把一份截图当作所有内容、浏览器和字号均正确的证据。

## 移动开发经验对照

类似TextStyle，但CSS行盒、继承与字体回退会影响整段文档，不是只计算单个Text控件。

## 常见误区与修正

- 固定容器高度，字体变大后把内容裁掉。
- 所有元素都继承固定px行高，放大标题时行间重叠。
