# 1.2.4.3 rem、em、百分比和视口单位

[返回 CSS 目录](./README.md) · [知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

前置：HTML 元素、属性与基本页面结构；含切换按钮的脚本仅用于观察，不要求此时掌握完整 JavaScript。

学完应能解释此规则、在 DevTools 中找到获胜声明或计算值，并对照内容变化判断是否适用。工程化选修项需区分源码与浏览器产物。

## 一句话理解

相对单位的“相对谁”各不相同，先选择参照，再决定要声明哪个尺寸。

## 工作机制与使用规则

1. rem相对根元素字号，em用于font-size时相对父字号，用在其他属性通常相对当前元素字号。
2. 百分比参照依赖具体属性与包含块，height:100%常需要可确定的父高度，不是所有百分比都相对视口。
3. vw/vh相对视口，ch近似当前字体0字符的度量，不是严格字符数；字体变化会改变结果。
4. clamp可组合相对和视口尺寸，但保留可读最小值与缩放效果，避免纯vw字体在放大时抵消。

## 最小代码与阅读顺序

```css
.card {
  font-size: 20px;
  padding: 1em;
}
.card small {
  font-size: 0.8em;
}
.page {
  max-inline-size: 60ch;
  padding: 1rem;
}
```

先读匹配目标与参照条件，再读计算结果。不要把一份截图当作所有内容、浏览器和字号均正确的证据。

## 移动开发经验对照

与逻辑像素/比例尺寸有相似目标；rem对应根字号而非固定dp换算，用户字号会改变它。

## 常见误区与修正

- 把em视为永远相对父元素。
- 所有height:100%都能填满屏幕。
