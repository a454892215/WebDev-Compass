# 1.2.1.2 选择器、状态伪类与伪元素

[返回 CSS 目录](./README.md) · [知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

前置：HTML 元素、属性与基本页面结构；含切换按钮的脚本仅用于观察，不要求此时掌握完整 JavaScript。

本点产出：从空白HTML写三项导航，用类、属性、nth-child和focus-visible表达状态，并保留真实按钮名称。 验收时需解释实际规则与适用边界，不能仅复述界面输出。

## 一句话理解

选择器匹配元素，伪类表达状态或位置，伪元素表示元素生成的部分。

## 工作机制与使用规则

1. 元素、类、ID 和属性选择器分别按标签、复用名称、唯一标识和属性值匹配，不用视觉外观反推语义。
2. 组合器空格、>、+、~ 分别表达后代、子代和相邻/后续兄弟关系，结构改变会影响匹配。
3. :hover 依赖指针悬停；键盘需要 :focus-visible；nth-child 按兄弟位置计数。
4. ::before/::after 可添加装饰，但关键说明与可操作内容仍应在真实 DOM 中，不能只靠 content 告知错误。

## 最小代码与阅读顺序

```css
.list > li:nth-child(2) {
  font-weight: 700;
}
input:focus-visible {
  outline: 3px solid teal;
}
.badge::before {
  content: "• ";
}
```

先读匹配目标与参照条件，再读计算结果。不要把一份截图当作所有内容、浏览器和字号均正确的证据。

## 移动开发经验对照

相当于按 Widget 角色和状态选样式；CSS 还依赖 DOM 亲属关系，不能把 nth-child 当业务 ID。

## 常见误区与修正

- 只写 hover，导致触控和键盘用户没有同等反馈。
- 把装饰生成文字当唯一可访问标签。
