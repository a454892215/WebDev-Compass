# 1.2.2.6 float 与 clear：维护旧布局和文字环绕

[返回 CSS 目录](./README.md) · [知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

前置：HTML 元素、属性与基本页面结构；含切换按钮的脚本仅用于观察，不要求此时掌握完整 JavaScript。

本点产出：从空白页实现一张插图旁文字环绕的文章卡片，用flow-root包含浮动并用clear分隔末段。 验收时需解释实际规则与适用边界，不能仅复述界面输出。

## 一句话理解

float 主要用于内容环绕；现代应用布局优先选择 Flex/Grid。

## 工作机制与使用规则

1. float 使盒子向一侧浮动，后续行内内容可环绕；它不是通用二维布局系统。
2. clear 让元素避开相应方向的浮动，常见旧清除技巧会引入额外伪元素。
3. flow-root 可建立独立块格式化上下文以包含浮动，常比依赖 overflow 的副作用明确。
4. 迁移旧页面时先记录视觉/阅读顺序再替换布局，不以“现代”理由改变内容可达性。

## 最小代码与阅读顺序

```css
.thumbnail {
  float: inline-start;
  margin-inline-end: 12px;
}
.article {
  display: flow-root;
}
.footer {
  clear: both;
}
```

先读匹配目标与参照条件，再读计算结果。不要把一份截图当作所有内容、浏览器和字号均正确的证据。

## 移动开发经验对照

接近文字围绕插图的排版，不等价于 Row 中的普通子组件；不要把全站列布局建在 float 上。

## 常见误区与修正

- 父元素高度塌陷就固定写高度，遇长文本再次失败。
- 清浮动直接 overflow:hidden，误裁阴影或浮层。
