# 1.2.2.10 内在尺寸、最小约束与媒体比例

[返回 CSS 目录](./README.md) · [知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

前置：HTML 元素、属性与基本页面结构；含切换按钮的脚本仅用于观察，不要求此时掌握完整 JavaScript。

学完应能解释此规则、在 DevTools 中找到获胜声明或计算值，并对照内容变化判断是否适用。工程化选修项需区分源码与浏览器产物。

## 一句话理解

先用内容和可用空间表达尺寸约束，通常比硬编码设计稿像素更稳健。

## 工作机制与使用规则

1. min-content按最小可换行机会度量，max-content不主动换行，fit-content在可用空间和两者之间约束。
2. Flex/Grid项目自动最小尺寸可能被长URL撑大；min-inline-size:0允许项目收缩，再为文字定义换行或滚动策略。
3. minmax(0,1fr)用于可收缩网格轨道；fr不保证内容不会溢出，子内容仍需处理。
4. aspect-ratio为媒体预留比例空间；当两轴都已明确固定时，比例不一定改变最终尺寸。

## 最小代码与阅读顺序

```css
.layout {
  display: grid;
  grid-template-columns: minmax(0, 1fr) auto;
}
.content {
  min-inline-size: 0;
  overflow-wrap: anywhere;
}
.media {
  inline-size: 100%;
  aspect-ratio: 16/9;
}
```

先读匹配目标与参照条件，再读计算结果。不要把一份截图当作所有内容、浏览器和字号均正确的证据。

## 移动开发经验对照

与LayoutBuilder/约束布局的目标一致；CSS内在尺寸基于内容测量，且自动最小尺寸会影响收缩结果。

## 常见误区与修正

- 固定宽度+overflow:hidden只是隐藏布局错误。
- 只写min-width:0，却让内容仍无换行/滚动出路。
