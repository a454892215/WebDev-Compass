## 一句话理解

Grid 先定义行列轨道，再将内容放入网格，适合需要二维对齐的页面和组件。

## 工作机制与使用规则

1. grid-template-columns/rows 定义显式轨道；额外内容会生成隐式轨道，grid-auto-* 控制其尺寸。
2. fr 分配剩余空间，不是固定百分比；minmax(0,1fr) 能允许轨道缩到内容最小宽度以下。
3. repeat、auto-fit/auto-fill 可减少固定断点；两者对空轨道的折叠行为不同。
4. 视觉跨列/重新定位不自动改变阅读和键盘顺序；表格数据仍使用 table 语义。

## 最小代码与阅读顺序

```css
.cards {
  display: grid;
  gap: 12px;
}
.cards {
  grid-template-columns: repeat(2, minmax(0, 1fr));
}
.cards > * {
  min-inline-size: 0;
}
```

先读匹配目标与参照条件，再读计算结果。不要把一份截图当作所有内容、浏览器和字号均正确的证据。

## 移动开发经验对照

类似二维 GridView，但 CSS Grid 可以做跨行跨列和轨道对齐，不以滚动列表虚拟化为默认职责。

## 常见误区与修正

- 把fr等同于屏幕百分比，忽略gap和内容约束。
- 为数据表外观换成div，丢失行列表头关系。
