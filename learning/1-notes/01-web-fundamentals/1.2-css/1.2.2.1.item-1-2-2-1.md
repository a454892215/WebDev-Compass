前置：HTML 元素、属性与基本页面结构；含切换按钮的脚本仅用于观察，不要求此时掌握完整 JavaScript。

本点产出：创建180px卡片与240px父框，分别计算content-box/border-box的内容、边框与margin占位。 验收时需解释实际规则与适用边界，不能仅复述界面输出。

## 一句话理解

内容、内边距、边框和外边距共同决定盒子占据的空间；box-sizing 改变 width 的计量边界。

## 工作机制与使用规则

1. content-box 的 width 只指定内容区；左右 padding/border 会加到外部宽度上，margin 仍在盒子之外。
2. border-box 将 padding/border 包含在指定宽度内，但不包含 margin；内容尺寸不能为负。
3. 元素实际布局还受 min/max、父布局约束、自动尺寸与 scrollbar 等因素影响。
4. 调试时同时看 Computed 的盒模型、getBoundingClientRect 与父容器，不只看代码里的 width。

## 最小代码与阅读顺序

```css
.card {
  width: 180px;
  padding: 20px;
  border: 4px solid;
}
.card {
  box-sizing: border-box;
}
/* 外边框宽 180，内容宽 132；margin 另算 */
```

先读匹配目标与参照条件，再读计算结果。不要把一份截图当作所有内容、浏览器和字号均正确的证据。

## 移动开发经验对照

Flutter 的约束与 Padding 同样影响最终尺寸，但 CSS 的 content-box 声明不是 Flutter tight constraints；要区分声明值和布局值。

## 常见误区与修正

- width:100% 再加 padding 导致溢出，却用 overflow:hidden 掩盖。
- 认为 border-box 把 margin 也算进 width。
