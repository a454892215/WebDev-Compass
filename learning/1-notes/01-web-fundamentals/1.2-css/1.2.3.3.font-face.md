## 一句话理解

@font-face声明字体来源与匹配信息；是否下载、是否阻塞及是否换字形需要另行观察。

## 工作机制与使用规则

1. font-family是自定义家族名，src指向local或url来源；font-style/weight需要与真实字体文件能力匹配。
2. font-display:swap允许先显示回退字体再替换；交换可能引起布局变化，需考虑回退度量和字形覆盖。
3. Web字体通常选WOFF2并按需子集化；跨域加载需要服务端CORS，不能只在CSS里解决。
4. 预加载仅用于首屏关键且确实会使用的字体；避免重复下载错误weight或预加载所有文件。

## 最小代码与阅读顺序

```css
@font-face {
  font-family: LessonLocal;
  src: local("Arial");
  font-display: swap;
}
.copy {
  font-family: LessonLocal, system-ui, sans-serif;
}
```

先读匹配目标与参照条件，再读计算结果。不要把一份截图当作所有内容、浏览器和字号均正确的证据。

## 移动开发经验对照

与Flutter字体资源声明目标类似，但Web有网络、缓存、CORS和回退交换过程；不能只验本机存在字体。

## 常见误区与修正

- computed font-family包含名字就断言该字体已实际成功显示。
- 在生产用远程字体却只验证离线local来源。
