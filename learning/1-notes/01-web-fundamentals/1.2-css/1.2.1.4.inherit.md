# 1.2.1.4 继承与 inherit、initial、unset、revert

[返回 CSS 目录](./README.md) · [知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

前置：HTML 元素、属性与基本页面结构；含切换按钮的脚本仅用于观察，不要求此时掌握完整 JavaScript。

本点产出：创建父子两层文本与按钮，对照inherit、initial、unset、revert的颜色和内边距。 验收时需解释实际规则与适用边界，不能仅复述界面输出。

## 一句话理解

继承来自父元素，几个重置关键字分别选择不同的回退边界。

## 工作机制与使用规则

1. color、font 等通常继承；margin、padding、border 等通常不继承，需按属性定义判断。
2. inherit 显式采用父元素该属性的计算值；initial 采用规范初始值，不是“浏览器常用默认样式”。
3. unset 对可继承属性等同 inherit，对其他属性等同 initial；revert 回退当前来源的层叠效果。
4. revert-layer 只撤销当前层的贡献；与 revert、清空 style 或删除整个类不是同一种操作。

## 最小代码与阅读顺序

```css
.panel {
  color: teal;
}
.panel strong {
  color: inherit;
}
.reset {
  color: unset;
  padding: initial;
}
.native {
  all: revert;
}
```

先读匹配目标与参照条件，再读计算结果。不要把一份截图当作所有内容、浏览器和字号均正确的证据。

## 移动开发经验对照

与 Flutter 继承主题有相似性，但 CSS 每个属性有自己的继承/初始行为；all 可能同时重置交互外观，需谨慎。

## 常见误区与修正

- 把 initial 当作父元素样式。
- 对整个表单 all:unset 却没重新提供焦点、布局和控件可识别外观。
