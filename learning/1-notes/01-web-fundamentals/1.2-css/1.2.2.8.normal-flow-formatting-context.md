# 1.2.2.8 正常流、BFC 与外边距折叠

[返回 CSS 目录](./README.md) · [知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

前置：HTML 元素、属性与基本页面结构；含切换按钮的脚本仅用于观察，不要求此时掌握完整 JavaScript。

本点产出：做父子margin与相邻兄弟margin两组实验，分别加入border、flow-root和flex并记录折叠条件。 验收时需解释实际规则与适用边界，不能仅复述界面输出。

## 一句话理解

理解正常流和格式化上下文，可以先解释布局现象，再决定是否需要额外容器或定位。

## 工作机制与使用规则

1. 正常流中块盒通常沿块轴依次排布，行内内容组成行盒；布局不是每个元素都需要绝对坐标。
2. 相邻块的垂直margin在特定条件下会折叠；父子或空块也可能参与，不是简单把两段margin相加。
3. BFC 是浮动、块布局等规则的独立环境；flow-root 可明确建立BFC，包含内部浮动，并阻止父盒与其内部子盒之间的相关margin折叠；同一BFC内部相邻块的margin仍可能折叠。
4. Flex/Grid内部的项目margin不按正常块流同样折叠；不要用固定高度掩盖因上下文产生的现象。

## 最小代码与阅读顺序

```css
.content {
  display: flow-root;
}
.content > p {
  margin-block: 20px;
}
/* 检查父子和相邻margin；不是所有margin都会折叠 */
```

先读匹配目标与参照条件，再读计算结果。不要把一份截图当作所有内容、浏览器和字号均正确的证据。

## 移动开发经验对照

Flutter的布局协议有约束向下/尺寸向上；CSS还包含文本正常流和margin折叠，不能只用Padding相加解释。

## 常见误区与修正

- 所有margin都折叠或全部不折叠。
- 为包含浮动顺手overflow:hidden，导致内容被裁。
