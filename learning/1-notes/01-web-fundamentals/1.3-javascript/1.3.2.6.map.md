# 1.3.2.6 `Map`、`Set`、`WeakMap`、`WeakSet`

[返回 JavaScript 目录](./README.md) · [阶段知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

Map 保存任意键值，Set 去重；Weak集合只弱持有适用键，不提供可枚举的内容列表。

前置与顺序：先学 1.3.1.2 对象身份和 1.3.1.11 数组；先掌握 Map/Set。Weak 集合及未注册 Symbol 为选读，不以 GC 时机验收。 适用场景是原生页面、组件逻辑与浏览器排障；不要求先搭 Vue/Nuxt。

## 工作机制

Map的键可为对象或原始值，按键身份匹配；Set保存唯一值。WeakMap/WeakSet的弱引用机制允许键对象在其他地方不可达时被回收；现代标准还允许未注册Symbol，注册Symbol和普通字符串/数字不适用。

## 使用规则

1. Map/Set按插入顺序迭代；对象键比较的是身份，不是字段深相等。

2. Weak集合没有可靠size/遍历接口，不能观察或依赖GC何时运行。

3. 需要缓存生命周期可控时先考虑显式清理/有界Map，不为“省内存”无条件替换成WeakMap。

## 最小代码

```javascript
const key = {};
const map = new Map([[key, "metadata"]]);
console.log(map.get(key));
console.log([...new Set([1, 1, 2])]);
const weak = new WeakMap();
weak.set(key, { active: true });
console.log(weak.has(key));
```

这段代码用于观察本节规则。浏览器 DOM、事件、网络与模块代码需要在对应的环境运行；配套实验把预期错误捕获并展示，不制造未处理的页面异常。

## 移动开发对照与边界

Dart Map/Set可帮助理解容器，但JS对象键通常按身份；WeakMap不等同于普通Map，也不是可预测的资源释放机制。

## 常见误区

- “两个同字段对象是同一个Map键”：它们通常是不同对象身份。

- “WeakMap能显示自动清理后的大小”：其内容不提供可靠枚举和size。
