# 1.3.2.5 迭代器与生成器（了解）

[返回 JavaScript 目录](./README.md) · [阶段知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

迭代器描述逐次取值协议；生成器用yield暂停并恢复函数，适合按需生成序列。

前置：能阅读变量、函数与基础 HTML。语言核心按顺序学习；DOM 需要先理解函数和对象，异步示例建议先学 Promise。适用场景：原生练习、Vue/Nuxt 组件逻辑与浏览器排障；框架不会改变这些语言规则。

## 工作机制

迭代器的next返回{value,done}；可迭代对象通过Symbol.iterator提供迭代器。function*调用后返回生成器对象，函数体通常直到第一次next才开始执行。

## 使用规则

1. for...of消费可迭代协议，普通对象不会因为有属性就自动可迭代。

2. 生成器return值出现在最终next结果，但不会被普通for...of当作序列元素。

3. 生成器不是并行线程，也不会自动把同步计算移出主线程；复杂控制流按需选学。

## 最小代码

```javascript
function* range(limit) {
  for (let value = 0; value < limit; value++) yield value;
  return "done";
}
const sequence = range(2);
console.log(sequence.next()); // {value:0,done:false}
console.log([...range(3)]); // [0,1,2]
```

这段代码用于观察本节规则。浏览器 DOM、事件、网络与模块代码需要在对应的环境运行；配套实验把预期错误捕获并展示，不制造未处理的页面异常。

## 移动开发对照与边界

Dart sync* 与Iterable的惰性序列有相似思想；JS还需区分可迭代对象、迭代器和异步迭代协议。

## 常见误区

- “生成器一创建就执行完”：取值会按需恢复。

- “yield等于await”：它们对应不同协议和控制流。
