# 1.3.3.4 属性与样式：`setAttribute`、`classList`（add/remove/toggle）、`style`、`dataset`

[返回 JavaScript 目录](./README.md) · [阶段知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

属性、DOM属性、class和style各有用途；修改状态时同步必要的可访问信息。

前置：能阅读变量、函数与基础 HTML。语言核心按顺序学习；DOM 需要先理解函数和对象，异步示例建议先学 Promise。适用场景：原生练习、Vue/Nuxt 组件逻辑与浏览器排障；框架不会改变这些语言规则。

## 工作机制

setAttribute修改HTML属性，DOM对象属性可能有实时状态语义，例如input.value与初始value属性不同。classList便于状态类操作，style只表达内联样式，dataset读写data-*字符串。

## 使用规则

1. 能用样式类表达的外观通常优先classList，避免散落内联样式。

2. 布尔属性以存在与否表达真/假，setAttribute("disabled","false")仍然禁用。

3. 视觉状态与aria-pressed/expanded等语义状态需要一致，dataset不是秘密存储。

## 最小代码

```javascript
const button = document.querySelector("button");
button.classList.add("active");
button.setAttribute("aria-pressed", "true");
button.dataset.count = String(1);
button.style.borderRadius = "12px";
```

这段代码用于观察本节规则。浏览器 DOM、事件、网络与模块代码需要在对应的环境运行；配套实验把预期错误捕获并展示，不制造未处理的页面异常。

## 移动开发对照与边界

Android View属性和Flutter状态更新可作概念对照；Web还需区分HTML attribute、DOM property以及供辅助技术读取的ARIA状态。

## 常见误区

- “disabled=false属性会启用”：属性仍存在就代表禁用。

- “style读到所有最终样式”：它只读取内联声明，最终值用getComputedStyle。
