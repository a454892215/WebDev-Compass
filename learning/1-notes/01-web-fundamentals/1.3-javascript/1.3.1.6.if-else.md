# 1.3.1.6 条件：`if/else`、`switch`、`三元表达式`

[返回 JavaScript 目录](./README.md) · [阶段知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

分支应表达业务状态，优先让每个条件和返回路径清楚。

前置与顺序：先学 1.3.1.4 转换与 1.3.1.5 运算符；示例中的函数仅包装输入到输出，函数声明/返回值在 1.3.1.8 解释，可先读该节基础语法。 适用场景是原生页面、组件逻辑与浏览器排障；不要求先搭 Vue/Nuxt。

## 工作机制

if 将条件转换为布尔值；switch 的 case 匹配使用严格相等语义，且默认会继续执行后面的分支，除非 break/return。三元运算符是表达式，可用于简单二选一。

## 使用规则

1. 多个互斥条件用 else if 或提前返回，避免多个独立 if 意外叠加。

2. switch 的 case 后通常需要 break；有意贯穿时应注释意图。

3. 嵌套三元会降低可读性，复杂状态用命名函数或映射表。

## 最小代码

```javascript
function statusText(status) {
  switch (status) {
    case "loading":
      return "加载中";
    case "error":
      return "请重试";
    default:
      return "就绪";
  }
}
const label = 0 > 0 ? "有数据" : "暂无数据";
```

这段代码用于观察本节规则。浏览器 DOM、事件、网络与模块代码需要在对应的环境运行；配套实验把预期错误捕获并展示，不制造未处理的页面异常。

## 移动开发对照与边界

Kotlin when / Dart switch 与 JS switch 的语法和贯穿规则不同；不要把所有语言的 switch 当成相同行为。

## 常见误区

- “多个 if 等同于 else if”：多个 if 可以全部执行。

- “switch 自动结束”：缺少 break/return 会发生贯穿。
