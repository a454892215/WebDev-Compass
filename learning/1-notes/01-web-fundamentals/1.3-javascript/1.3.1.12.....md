# 1.3.1.12 对象：字面量、属性访问、展开运算符（`...`）、解构、计算属性名

[返回 JavaScript 目录](./README.md) · [阶段知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

对象保存键值属性，解构和展开简化读写，但展开只复制一层。

前置与顺序：先学变量、函数与 1.3.1.2 引用共享；本节展开对象字段、浅复制和解构，不能将展开理解成深复制。 适用场景是原生页面、组件逻辑与浏览器排障；不要求先搭 Vue/Nuxt。

## 工作机制

对象字面量可声明普通、计算属性名和方法；点访问适合已知合法标识符，方括号可按运行时字符串或 symbol 访问。解构默认值仅在属性值为 undefined 时生效。

## 使用规则

1. {...source} 复制自身可枚举属性，不复制原型，也不深拷贝嵌套对象。

2. 使用可选键时先校验外部输入，避免无约束地把任意键合并到配置对象。

3. 解构不会删除源对象属性，重命名只改变局部变量名。

## 最小代码

```javascript
const source = { name: "Ada", prefs: { theme: "light" } };
const copy = { ...source, active: true };
copy.prefs.theme = "dark";
const { name: displayName } = source;
const field = "name";
const patch = { [field]: "Lin" }; // 计算属性名，不是名为 field 的属性
console.log(displayName, source.prefs.theme, patch.name);
```

这段代码用于观察本节规则。浏览器 DOM、事件、网络与模块代码需要在对应的环境运行；配套实验把预期错误捕获并展示，不制造未处理的页面异常。

## 移动开发对照与边界

Dart Map 展开也需要留意嵌套共享；JS 对象还具有原型、属性描述符等语义，不能完全等同于 Map<String,dynamic>。

## 常见误区

- “展开之后互不影响”：嵌套对象可能仍然共享。

- “解构默认值能替换 null”：只有 undefined 才触发默认值。
