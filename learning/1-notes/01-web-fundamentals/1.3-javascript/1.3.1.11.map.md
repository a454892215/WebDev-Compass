# 1.3.1.11 数组：创建、`map`、`filter`、`reduce`、`find`、`some`、`every`、`forEach`、解构

## 学习目标与前置

选择能表达意图的数组方法：映射、筛选、查找、判断和归约各有不同返回值。

前置：能阅读变量、函数与基础 HTML。语言核心按顺序学习；DOM 需要先理解函数和对象，异步示例建议先学 Promise。适用场景：原生练习、Vue/Nuxt 组件逻辑与浏览器排障；框架不会改变这些语言规则。

## 工作机制

map 返回新数组，filter 保留满足条件的元素，find 返回第一个匹配值或 undefined；some/every 返回布尔值；reduce 逐项累计。forEach 适合副作用，不返回结果数组。

## 使用规则

1. map 返回新数组不代表元素深拷贝；对象引用可能仍共享。

2. reduce 尽量提供初始值，否则空数组可能抛错。

3. sort/reverse 会修改原数组；需要不可变排序可先复制或使用目标支持的 toSorted。

## 最小代码

```javascript
const prices = [10, 20, 5];
const totals = prices.map((value) => value * 2);
const large = prices.filter((value) => value >= 10);
const sum = prices.reduce((acc, value) => acc + value, 0);
console.log(totals, large, sum);
```

这段代码用于观察本节规则。浏览器 DOM、事件、网络与模块代码需要在对应的环境运行；配套实验把预期错误捕获并展示，不制造未处理的页面异常。

## 移动开发对照与边界

Dart Iterable 的 map/where 通常惰性；JS Array.map/filter 通常立即产生新数组，链式处理会有分配成本。

## 常见误区

- “map 等于深拷贝”：只建立新数组容器。

- “find 返回索引”：索引用 findIndex；find 返回元素。
