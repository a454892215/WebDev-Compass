# 1.3.1.5 运算符：算术、比较、逻辑、空值合并（`??`）、可选链（`?.`）

## 学习目标与前置

理解每种运算符对值的处理，再用短路运算表达默认值和条件访问。

前置与顺序：先学 1.3.1.2 类型与 1.3.1.4 转换；对象点访问是读取字段，完整解构/对象组织稍后在 1.3.1.12 展开。 适用场景是原生页面、组件逻辑与浏览器排障；不要求先搭 Vue/Nuxt。

## 工作机制

=== 不做类型转换，== 有转换规则；&&/|| 返回操作数而不一定是布尔值。?? 只在 null/undefined 时选默认值；?. 只在左侧为空值时停止继续访问。

## 使用规则

1. 业务判断默认用严格相等；NaN 与任何值都不严格相等，应使用 Number.isNaN。

2. 0、false 和空字符串可能是有效值，不能一律用 || 覆盖。

3. ?. 不验证字段类型；对象缺方法时可用 method?.()，但非函数仍会报错。

## 最小代码

```javascript
const count = 0;
console.log(count || 10); // 10
console.log(count ?? 10); // 0
const user = null;
console.log(user?.profile?.name ?? "访客");
console.log(2 === "2"); // false
```

这段代码用于观察本节规则。浏览器 DOM、事件、网络与模块代码需要在对应的环境运行；配套实验把预期错误捕获并展示，不制造未处理的页面异常。

## 移动开发对照与边界

Dart/Kotlin 的空值操作有类似写法，但 JavaScript 的 || 处理所有 falsy 值，不能直接等同于空合并。

## 常见误区

- “&&/|| 总返回 true/false”：它们返回选中的操作数。

- “可选链保证数据合法”：它只处理 null/undefined 链路。
