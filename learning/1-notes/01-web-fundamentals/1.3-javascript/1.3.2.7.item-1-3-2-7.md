# 1.3.2.7 可选链、空值合并、逻辑赋值（`&&=`、`||=`）

[返回 JavaScript 目录](./README.md) · [阶段知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

空值保护与逻辑赋值减少重复访问，但必须保留0、false等合法业务值。

前置与顺序：先学 1.3.1.5 短路/空值运算和 1.3.1.12 对象；本节只深化条件赋值与求值次数，不重复把默认值视为数据校验。 适用场景是原生页面、组件逻辑与浏览器排障；不要求先搭 Vue/Nuxt。

## 工作机制

??只处理null/undefined；||处理全部falsy值；&&只在左值truthy时继续。逻辑赋值先读取左侧并按条件写回，通常只求值一次左侧位置；不等于所有表达式的简单文本替换。

## 使用规则

1. 配置默认值一般优先??，但业务若明确把空串视为未填，应单独表达。

2. ?.不能放在普通赋值目标左侧，也不会捕获函数内部错误。

3. 混用??与&&/||需要明确括号，避免语法限制和阅读歧义。

## 最小代码

```javascript
const options = { retries: 0, title: "" };
options.retries ??= 3;
options.title ||= "未命名";
console.log(options); // retries 保留0
const user = null;
console.log(user?.name ?? "访客");
```

这段代码用于观察本节规则。浏览器 DOM、事件、网络与模块代码需要在对应的环境运行；配套实验把预期错误捕获并展示，不制造未处理的页面异常。

## 移动开发对照与边界

Dart的??=可对照空合并赋值；JS ||=还会覆盖0、false和空串，需要按领域选择。

## 常见误区

- “||=和??=都只是补默认值”：它们判断的集合不同。

- “可选链是通用异常处理”：它不等同try/catch。
