# 1.3.1.7 循环：`for`、`while`、`do...while`、`for...of`、`for...in`

[返回 JavaScript 目录](./README.md) · [阶段知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

遍历值通常用 for...of，遍历自有键通常用 Object.keys/entries，避免混淆 for...in。

前置与顺序：先学 1.3.1.6 条件；先比较索引和值，再在 1.3.1.11 学数组方法。异步循环规则在 Promise/await 后回读，不要求当前实现并发。 适用场景是原生页面、组件逻辑与浏览器排障；不要求先搭 Vue/Nuxt。

## 工作机制

for/while/do...while 控制次数和退出；for...of 依赖可迭代协议并取得值。for...in 枚举可枚举字符串属性名，可能包含继承属性，不应作为普通数组值遍历。

## 使用规则

1. 数组里的 index 与 value 不同，for...in 的索引还是字符串。

2. 异步循环里 forEach 不等待返回的 Promise；串行处理用 for...of + await，并发可用 Promise.all。

3. 循环必须有可达的退出条件，不能在主线程跑无限循环来演示卡顿。

## 最小代码

```javascript
const list = ["A", "B"];
for (const value of list) console.log(value);
for (const [index, value] of list.entries()) {
  console.log(index, value);
}
for (const key of Object.keys({ count: 2 })) {
  console.log(key);
}
```

这段代码用于观察本节规则。浏览器 DOM、事件、网络与模块代码需要在对应的环境运行；配套实验把预期错误捕获并展示，不制造未处理的页面异常。

## 移动开发对照与边界

Dart for-in 更接近 JS for...of；JS for...in 的 in 并不是同一种值遍历。

## 常见误区

- “for...in 与 Dart for-in 一样”：JS 版本枚举属性名。

- “forEach(async ...) 会等待全部”：forEach 不收集或 await 回调 Promise。
