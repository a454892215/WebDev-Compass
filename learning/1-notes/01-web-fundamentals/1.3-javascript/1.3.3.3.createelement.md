# 1.3.3.3 创建与修改：`createElement`、`appendChild`、`insertBefore`、`removeChild`

[返回 JavaScript 目录](./README.md) · [阶段知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

创建元素、设置安全内容并挂到正确父节点；移动与复制节点是不同操作。

前置：能阅读变量、函数与基础 HTML。语言核心按顺序学习；DOM 需要先理解函数和对象，异步示例建议先学 Promise。适用场景：原生练习、Vue/Nuxt 组件逻辑与浏览器排障；框架不会改变这些语言规则。

## 工作机制

createElement只创建未挂载节点；append/appendChild/insertBefore建立父子关系。已存在节点再次append会移动它，不会自动复制；cloneNode才能复制，事件监听器不会因此自动完整复制。

## 使用规则

1. 少量节点用清晰DOM操作即可，不为性能猜测过早批量优化。

2. removeChild要求节点确实属于该父节点，element.remove可更直接移除自己。

3. 用textContent填用户文本，不把字符串拼接成可执行HTML。

## 最小代码

```javascript
const list = document.querySelector("ul");
const item = document.createElement("li");
item.textContent = "学习 DOM";
list.appendChild(item);
list.insertBefore(document.createElement("li"), item);
item.remove();
```

这段代码用于观察本节规则。浏览器 DOM、事件、网络与模块代码需要在对应的环境运行；配套实验把预期错误捕获并展示，不制造未处理的页面异常。

## 移动开发对照与边界

Android直接操作ViewGroup有相似命令式思路；Vue/Flutter声明式UI通常应让状态驱动渲染，手动DOM仅用于明确适配边界。

## 常见误区

- “append现有节点会复制一份”：它会移动。

- “cloneNode会复制所有监听器”：addEventListener注册的回调不会因此复制。
