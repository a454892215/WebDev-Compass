# 1.3.2.1 类（`class`）：constructor、方法、继承（`extends`）、`super`、静态方法

[返回 JavaScript 目录](./README.md) · [阶段知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

class 是基于原型的类语法；实例方法、静态方法与实例字段承担不同职责。

前置：能阅读变量、函数与基础 HTML。语言核心按顺序学习；DOM 需要先理解函数和对象，异步示例建议先学 Promise。适用场景：原生练习、Vue/Nuxt 组件逻辑与浏览器排障；框架不会改变这些语言规则。

## 工作机制

new 调用构造器建立实例，class 方法通常位于原型上；extends 建立继承关系，子类构造器读取 this 前必须调用 super。class 体在严格模式下执行，调用 class 构造器必须使用 new。

## 使用规则

1. 静态方法属于类本身，不能通过普通实例直接调用。

2. 私有字段使用 #name，访问受类定义约束，不等同于普通命名约定。

3. 继承不是代码复用的唯一方式；页面业务也可优先使用组合与普通函数。

## 最小代码

```javascript
class Counter {
  #value = 0;
  increment() {
    return ++this.#value;
  }
  static description() {
    return "计数器";
  }
}
const counter = new Counter();
console.log(counter.increment(), Counter.description());
```

这段代码用于观察本节规则。浏览器 DOM、事件、网络与模块代码需要在对应的环境运行；配套实验把预期错误捕获并展示，不制造未处理的页面异常。

## 移动开发对照与边界

Kotlin/Dart class 经验可帮助理解对象建模，但 JS class 运行时仍基于原型；TypeScript private 与 JS #私有字段也不是同一种运行时约束。

## 常见误区

- “static 方法在每个实例上”：通过构造器调用。

- “class 等于传统类语言全部特性”：重载、接口和访问修饰符不能直接套用。
