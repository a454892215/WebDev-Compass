# 1.3.4.7 自定义事件：`CustomEvent`、`dispatchEvent`

[返回 JavaScript 目录](./README.md) · [阶段知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

CustomEvent为应用定义有名字的通知，通过detail携带结构化数据。

前置：能阅读变量、函数与基础 HTML。语言核心按顺序学习；DOM 需要先理解函数和对象，异步示例建议先学 Promise。适用场景：原生练习、Vue/Nuxt 组件逻辑与浏览器排障；框架不会改变这些语言规则。

## 工作机制

dispatchEvent同步分发事件；默认CustomEvent不冒泡、不可取消，也不跨Shadow DOM边界，需按契约显式设置。它不是跨页面、跨进程或跨源消息总线。

## 使用规则

1. 为事件命名和detail结构定义契约，接收方仍应校验来源与数据。

2. detail可共享对象引用，事件不是自动深拷贝或不可变消息。

3. 组件卸载时清理订阅，跨window通信要使用适当API并校验origin。

## 最小代码

```javascript
const event = new CustomEvent("lesson:completed", {
  bubbles: true,
  detail: { lessonId: "html", progress: 100 },
});
card.dispatchEvent(event);
```

这段代码用于观察本节规则。浏览器 DOM、事件、网络与模块代码需要在对应的环境运行；配套实验把预期错误捕获并展示，不制造未处理的页面异常。

## 移动开发对照与边界

类似Flutter通知或事件总线的消息思想，但DOM事件有传播、同步分发和Shadow DOM边界，不等同全局广播流。

## 常见误区

- “CustomEvent默认冒泡”：默认bubbles为false。

- “dispatchEvent是异步队列”：监听器通常在调用返回前同步执行。
