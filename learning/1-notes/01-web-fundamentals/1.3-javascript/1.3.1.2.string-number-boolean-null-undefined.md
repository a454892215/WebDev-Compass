# 1.3.1.2 数据类型：原始类型（string、number、boolean、null、undefined、symbol、bigint）与引用类型（object）

[返回 JavaScript 目录](./README.md) · [阶段知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

JavaScript 的值有类型，变量可以在运行时绑定不同类型的值。

前置：能阅读变量、函数与基础 HTML。语言核心按顺序学习；DOM 需要先理解函数和对象，异步示例建议先学 Promise。适用场景：原生练习、Vue/Nuxt 组件逻辑与浏览器排障；框架不会改变这些语言规则。

## 工作机制

原始值包括 undefined、null、boolean、number、bigint、string、symbol；对象包含普通对象、数组和函数。对象赋值复制引用，原始值按值传递；函数参数同样是值传递，对象引用本身也是一个值。

## 使用规则

1. number 为双精度浮点，整数精确范围受 Number.MAX_SAFE_INTEGER 限制。

2. bigint 用于较大整数，不能直接与 number 做算术混用。

3. 对象共享引用导致可观察的属性变化；原始字符串的方法返回新字符串。

## 最小代码

```javascript
let value = 1;
value = "1";
const source = { count: 1 };
const alias = source;
alias.count = 2;
console.log(source.count); // 2
const big = 9007199254740993n;
```

这段代码用于观察本节规则。浏览器 DOM、事件、网络与模块代码需要在对应的环境运行；配套实验把预期错误捕获并展示，不制造未处理的页面异常。

## 移动开发对照与边界

Dart dynamic/Kotlin Any 可容纳不同值，但 JavaScript 普通绑定天然在运行时取值；不代表不存在类型或不会产生类型错误。

## 常见误区

- “JS 没类型”：是动态类型，而非无类型。

- “对象按引用传参”：严格说传递的是引用值；重新给参数赋值不会替换调用方变量。
