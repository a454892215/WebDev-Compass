# 1.3.1.9 作用域：全局、函数、块级作用域；作用域链

[返回 JavaScript 目录](./README.md) · [阶段知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 学习目标与前置

作用域决定标识符到哪里找，不由函数在哪里被调用来决定。

前置：能阅读变量、函数与基础 HTML。语言核心按顺序学习；DOM 需要先理解函数和对象，异步示例建议先学 Promise。适用场景：原生练习、Vue/Nuxt 组件逻辑与浏览器排障；框架不会改变这些语言规则。

## 工作机制

词法作用域由代码嵌套结构确定；查找先当前作用域，再向外层，直到全局。块级 let/const 可遮蔽外层同名绑定；浏览器 ES Module 的顶层绑定不会自动成为 window 属性。

## 使用规则

1. 尽量缩小变量作用域，避免多个 UI 操作共享不必要的可变全局。

2. 局部同名变量会遮蔽外层变量，调试时先确认所读绑定。

3. var 没有普通块作用域，但函数内部 var 不会泄露到调用方。

## 最小代码

```javascript
const theme = "light";
function preview() {
  const theme = "dark";
  return theme;
}
console.log(preview()); // dark
console.log(theme); // light
```

这段代码用于观察本节规则。浏览器 DOM、事件、网络与模块代码需要在对应的环境运行；配套实验把预期错误捕获并展示，不制造未处理的页面异常。

## 移动开发对照与边界

Dart/Kotlin 同样采用词法作用域，但浏览器经典 script 与 module 的全局规则不同；框架组件作用域也不等于进程级全局。

## 常见误区

- “函数从调用方作用域找变量”：它从定义位置的外层环境查找。

- “模块顶层变量就是 window.xxx”：ESM 顶层绑定不自动挂到 window。
