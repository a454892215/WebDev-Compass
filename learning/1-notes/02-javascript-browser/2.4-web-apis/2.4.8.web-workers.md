# 2.4.8 Web Worker：消息、计算与终止

[章节目录](./README.md) · [知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 前置与目标

ESM、消息事件、异步错误与结构化克隆；按计算任务需要选学。

## 解决什么问题

把可分离的统计计算放到独立Worker，让主线程处理界面。Worker不能直接访问DOM，跨线程是消息协议而不是共享页面变量。

## 原理与使用规则

new Worker(new URL(..., import.meta.url), {type:"module"})加载独立脚本；两边postMessage，接收message/error/messageerror。多数数据通过结构化克隆传递，Transferable可转移底层资源，SharedArrayBuffer有额外跨源隔离要求，不能概括成所有对象共享或全部零复制。

用requestId忽略过期结果，取消任务可terminate整个Worker或设计协作取消协议。postMessage已排队不等于完成计算；大数据序列化也有成本。创建和通信有开销，小任务不应机械迁移。销毁页面时终止并清理监听。

## 最小例子

```javascript
// main.mjs：页面无需DOM之外的共享变量
const worker = new Worker(new URL("./worker.mjs", import.meta.url), { type: "module" });
worker.onmessage = ({ data }) => console.log(data.total);
worker.onerror = () => console.warn("统计失败，保留列表");
worker.postMessage({ requestId: 1, values: [2, 3, 4] });
// worker.mjs单独文件：self.onmessage = ({data}) =>
//   self.postMessage({requestId:data.requestId,total:data.values.reduce((a,b)=>a+b,0)});
// 不再使用：worker.terminate();
```

## 移动端对照

类似原生后台线程/Flutter isolate的职责分离，但具体消息与共享机制不同；不等于让整个页面多线程直接操作DOM。

## 边界与常见误区

例子统计小数组仅展示消息协议，不宣称性能提升。Worker缺失或错误时显示回退提示，不阻塞核心阅读。

## 实验与验收

[打开真实示例](../../../2-examples/02-javascript-browser/2.4-web-apis/2.4.8.web-workers-demo.html)。从仓库根目录启动本组服务 `node learning/2-examples/02-javascript-browser/2.3-browser-storage/server.mjs`，使用HTTP访问；Cookie示例必须本服务，其他API也可用普通静态服务。

输入逗号分隔数字，真实Worker返回总和；错误输入拒绝，停止后Worker终止且不会再更新。

先预测结果，再操作并解释差异；[独立练习](../../../3-exercises/02-javascript-browser/2.4-web-apis/2.4.8.web-workers.md)不要求复制示例。综合任务由阶段项目索引关联，新增能力与既有实现分别说明。
