# 2.4.1 IntersectionObserver：按交叉状态触发工作

[章节目录](./README.md) · [知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md)

## 前置与目标

DOM、事件回调、滚动容器与资源清理；无需先会框架。

## 解决什么问题

当卡片接近滚动容器可视区时再开始加载。Observer异步报告几何交叉变化，减少手写scroll回调逐项测量。

## 原理与使用规则

root指定观察容器，null代表视口；rootMargin扩展或收缩其几何边界，threshold决定交叉比例越过哪些阈值时报告。首次observe也会异步报告初始状态。isIntersecting与intersectionRatio须结合用途判断，普通交叉不证明元素未被遮挡、用户真正阅读或广告可见性达标。

一次性加载成功后unobserve，页面卸载时disconnect。无限滚动还需loading标志、去重、结束条件、失败重试和手动加载回退；Observer并不自动解决接口竞态。

## 最小例子

```javascript
const target = document.querySelector("#sentinel"); // 页面需有此元素
const observer = new IntersectionObserver((entries) => {
  if (entries.some(entry => entry.isIntersecting)) console.log("进入观察区");
}, { root: null, rootMargin: "0px", threshold: 0.5 });
observer.observe(target);
// 不再需要时：observer.unobserve(target); observer.disconnect();
```

## 边界与常见误区

不支持时保留普通内容/手动按钮；不要因Observer回调到来就重复请求或以它替代键盘可达内容。
