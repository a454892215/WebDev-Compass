# 2.1.7 柯里化与函数组合：小型可复用转换

[返回章节](./README.md) · [知识地图](../../../../knowledge-map/01-foundation-stages-0-2.md#21-javascript-进阶)

## 解决什么问题与前置

多个列表使用相似过滤条件时，如何固定一部分参数并复用，不把简单逻辑变成抽象迷宫？

前置：阶段1高阶函数、闭包、数组方法；属于按需回读，不阻塞首个Nuxt应用。

## 工作机制

1. 柯里化把多个参数的函数改写成一次接收一个参数的函数链；部分应用只固定部分参数，两者相关但不是同义词。

2. 组合把一个函数的输出作为下一个函数的输入。pipe通常从左向右，compose通常从右向左；这是常用命名约定，项目仍需看具体函数定义。

3. 每步输入输出类型和错误策略要一致；纯同步组合不能自动处理Promise。异步流水线应显式await或使用专门约定。

4. 小型命名函数通常比多层匿名闭包更容易调试。没有重复变化点时直接写一个普通函数更清楚，不为“函数式”而改写全部业务。

## 最小示例

```javascript
const hasMinLength = min => text => text.length >= min;
const normalize = text => text.trim().toLowerCase();
const pipe = (...steps) => value => steps.reduce((v, step) => step(v), value);
const prepare = pipe(normalize, text => text.replaceAll(" ", "-"));
console.log(["  Vue 3  ", " Nuxt "].map(prepare)); // vue-3, nuxt
console.log(["js", "vue"].filter(hasMinLength(3))); // vue
```

## 场景、边界与误区

字符串长度例子用的是JS UTF-16码元长度；它不是通用的用户可见字符计数器。带副作用函数组合还可能改变执行次数和可测试性。
