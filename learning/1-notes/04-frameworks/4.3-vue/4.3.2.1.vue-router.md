# 4.3.2.1 Vue Router：动态参数、懒加载、导航守卫与历史

## 前置与目标

Vue组件、URL/History和动态import；不要求先学Nuxt文件路由。

目标：能解释本节机制，运行对应实验，独立定位下述故障并说明边界。

## 解决什么问题与原理

router将路径映射到组件，RouterLink生成可导航链接，RouterView显示当前匹配。createWebHistory使用干净URL，生产服务器必须让应用深链回退到入口；hash模式对托管要求不同。客户端路由不自动定义真实HTTP404状态或服务端API权限。

/items/:id把参数放到route.params；从id1到id2可能复用同一组件，onMounted不会因此再次执行。本例用computed跟踪route.params，异步数据可watch特定参数或用路由更新守卫；避免把一次解构快照当实时路由。query与params各有用途，查询输入要处理string/string[]等实际形态。

守卫可返回重定向、false或允许，适合导航体验；不能把隐藏路由/重定向当服务端授权。路由懒加载写component: () => import(...)，不是直接在这里传defineAsyncComponent替代路由加载机制。返回/前进、刷新、未匹配路径都要验证，不能只测首页点击。

## 最小例子

```typescript
import { createMemoryHistory, createRouter } from 'vue-router'
const router = createRouter({ history: createMemoryHistory(), routes: [
  { path: '/items/:id', component: () => import('./pages/Detail.vue') }
] })
// 源码浏览器入口使用createWebHistory，测试用memory以控制历史。
```

片段用于解释本节规则；标注为setup或模板的代码需放进对应SFC。完整导入、类型与运行入口见[示例操作卡](../../../2-examples/04-frameworks/4.3-vue/4.3.2.1.vue-router-demo.md)。

## 运行与观察

进入详情1再详情2，内容和参数同步；刷新详情2可用；受限演示重定向并显示说明。实际路由文件生成独立懒加载chunk，TS/VTU/Chrome分别核对。

## 场景、边界与移动开发对照

类似命名路由和深链，但地址栏、历史、HTTP刷新和可复制URL是浏览器的公开契约，不能仅按移动页面栈理解。

演示守卫永远重定向，未实现登录；Vite开发fallback成功不等于生产托管已配置。
