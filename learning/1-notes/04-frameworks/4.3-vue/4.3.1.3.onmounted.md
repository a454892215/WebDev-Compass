# 4.3.1.3 Vue生命周期：挂载、更新、卸载与资源清理

## 前置与目标

SFC、响应式；KeepAlive激活/停用在4.3.1.7深化。

目标：能解释本节机制，运行对应实验，独立定位下述故障并说明边界。

## 解决什么问题与原理

在setup同步注册onMounted/onUnmounted等钩子，Vue才能关联当前实例。mounted表示组件初始DOM已挂载，可访问相应客户端DOM；不是所有异步子组件、图片、字体或远程数据均已就绪的保证。

创建监听器、计时器、观察器和请求时同时设计释放路径。onUnmounted清理手动注册的外部资源；同步setup中创建的watch通常随组件停止，但异步回调里稍后创建的侦听器可能需手动stop。不要把DOM移除等同所有外部资源自动停止。

普通更新可能频繁触发；onUpdated里无条件修改渲染依赖会产生循环。DOM读写可按目标使用nextTick或post-flush watcher。SSR不会运行onMounted/onUnmounted，服务端setup里不能启动一个指望onUnmounted关闭的永久计时器。

## 最小例子

```typescript
import { onMounted, onUnmounted } from 'vue'
function handleResize() { console.log(window.innerWidth) }
onMounted(() => window.addEventListener('resize', handleResize))
onUnmounted(() => window.removeEventListener('resize', handleResize))
// 在组件setup同步调用；不是服务端模块顶层代码。
```

片段用于解释本节规则；标注为setup或模板的代码需放进对应SFC。完整导入、类型与运行入口见[示例操作卡](../../../2-examples/04-frameworks/4.3-vue/4.3.1.3.onmounted-demo.md)。
