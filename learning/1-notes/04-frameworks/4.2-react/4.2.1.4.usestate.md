# 4.2.1.4 useState：快照、更新队列与不可变数据

**React选修**。前置为阶段1 JavaScript/DOM与阶段3 TypeScript/模块/测试；不阻塞Vue 3 + Nuxt主线。目标：能解释本节机制，完成一个变体并定位指定故障。

## 解决什么问题与原理

每次渲染看到自己的state快照。setter安排后续渲染，不同步改变当前闭包里的值；连续按旧快照计算会覆盖预期增量。

当新状态依赖旧状态，使用setCount(n=>n+1)。更新函数必须纯净；React会按队列计算，开发期还可能重复调用以检查纯度。

对象和数组state应创建替换值，保留未变化部分引用。直接push旧数组后传回相同引用，可能没有预期更新，还污染历史快照。

## 最小例子

```tsx
setCount(n=>n+1)
setCount(n=>n+1) // 一个点击，下一次渲染累计+2
```

片段只解释本节机制；需要的import、类型和组件上下文以[真实实验与操作](../../../2-examples/04-frameworks/4.2-react/4.2.1.4.usestate-demo.md)为准，不能把上下文片段当独立可运行文件。

## 操作、场景与边界

Counter一次点击调用两个函数更新，真实DOM由计数0变计数2；reducer测试另检查旧对象没变。

setter不是立即改写当前局部变量。
