# 4.2.3.3 Redux Toolkit：slice、异步action与中间件

**React选修**。前置为阶段1 JavaScript/DOM与阶段3 TypeScript/模块/测试；不阻塞Vue 3 + Nuxt主线。目标：能解释本节机制，完成一个变体并定位指定故障。

## 解决什么问题与原理

configureStore提供常用默认中间件与工具配置，createSlice生成reducer/actions。slice中的“修改”写法针对Immer草稿，不是普通对象随意可变的规则。

createAsyncThunk创建pending/fulfilled/rejected action；reducer应显式处理状态。dispatch返回的Promise通常以action完成，业务调用需要unwrap才能按异常处理拒绝。

异步竞态、取消和授权不会因使用RTK自动解决。中间件处理dispatch链路上的副作用/检查，不等同组件生命周期或服务端鉴权。

## 最小例子

```tsx
const load=createAsyncThunk("title/load",async()=>"Vue")
// 调用处：
await store.dispatch(load()).unwrap()
```
