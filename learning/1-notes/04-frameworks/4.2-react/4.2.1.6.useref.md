# 4.2.1.6 useRef：DOM引用与不参与渲染的可变值

**React选修**。前置为阶段1 JavaScript/DOM与阶段3 TypeScript/模块/测试；不阻塞Vue 3 + Nuxt主线。目标：能解释本节机制，完成一个变体并定位指定故障。

## 解决什么问题与原理

useRef返回稳定容器，current可跨渲染保存；写current不会触发重渲染，所以不适合承担需要显示变化的状态。

DOM ref在挂载提交后才指向元素，移除后可变回null；聚焦等操作放事件或适当Effect中，先检查存在。

不要在渲染中读写任意可变ref来决定结果，也不要用ref绕过Effect清理。ref像实例字段的部分用途，但React渲染/提交时机有自身规则。

## 最小例子

```tsx
const input=useRef<HTMLInputElement>(null)
// 事件处理：
input.current?.focus()
```

片段只解释本节机制；需要的import、类型和组件上下文以[真实实验与操作](../../../2-examples/04-frameworks/4.2-react/4.2.1.6.useref-demo.md)为准，不能把上下文片段当独立可运行文件。

## 操作、场景与边界

FocusInput真实DOM测试点击按钮后document.activeElement是对应输入；不是模拟focus字符串。

DOM ref不是可以提前取得的元素。
