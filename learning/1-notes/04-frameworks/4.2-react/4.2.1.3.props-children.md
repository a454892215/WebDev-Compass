# 4.2.1.3 Props与children：只读输入和组合

**React选修**。前置为阶段1 JavaScript/DOM与阶段3 TypeScript/模块/测试；不阻塞Vue 3 + Nuxt主线。目标：能解释本节机制，完成一个变体并定位指定故障。

## 解决什么问题与原理

Props是父组件传入的只读快照；子组件要请求父状态改变，应调用约定的回调，而不是修改props或其嵌套对象。类型readonly并不冻结实际对象。

children是传入组件标签内部的可渲染内容；ReactNode可包含元素、文本、空值等，不应该用string类型限制任意组件插槽。

组合让外壳提供布局而调用方决定内容；children不是Vue具名/作用域插槽的逐项同义替换，复杂契约可用命名props或render函数明确表达。

## 最小例子

```tsx
function Panel({title,children}:{title:string;children:ReactNode}) {
 return <section aria-label={title}><h2>{title}</h2>{children}</section>
}
```

片段只解释本节机制；需要的import、类型和组件上下文以[真实实验与操作](../../../2-examples/04-frameworks/4.2-react/4.2.1.3.props-children-demo.md)为准，不能把上下文片段当独立可运行文件。

## 操作、场景与边界

Panel真实挂载标题与p子节点；测试核对可访问名称和组合文本。

输入与回调形成公开组件契约。
