# 4.2.2.1 React Router：URL、路由声明与导航

**React选修**。前置为阶段1 JavaScript/DOM与阶段3 TypeScript/模块/测试；不阻塞Vue 3 + Nuxt主线。目标：能解释本节机制，完成一个变体并定位指定故障。

## 解决什么问题与原理

本实验采用React Router8.5.2的声明式模式；BrowserRouter提供浏览器history，Routes/Route匹配UI，Link保留链接语义，useNavigate用于交互后的程序导航。

useParams读取动态段，useSearchParams读写查询；动态参数仍是外部字符串，需校验。不要把路由URL与本地state做两份互不更新的真相。

声明式、数据和框架模式能力不同；本例没有loader/action服务器流程。生产静态托管还需深链回退，否则客户端能跳转但直接刷新404。

## 最小例子

```tsx
<Routes>
 <Route path="tasks/:id" element={<Details/>}/>
</Routes>
// Details内 useParams() 与 useSearchParams()
```
