# 4.2.1.5 useEffect：同步外部系统、依赖与清理

**React选修**。前置为阶段1 JavaScript/DOM与阶段3 TypeScript/模块/测试；不阻塞Vue 3 + Nuxt主线。目标：能解释本节机制，完成一个变体并定位指定故障。

## 解决什么问题与原理

Effect适合把组件与订阅、定时器等外部系统同步；由用户点击触发的提交通常放事件处理，不要为了派生一个可计算值增加Effect。

依赖列表必须包含Effect读取的响应值。React按Object.is比较依赖；旧清理先于相应新设置执行，组件卸载也需释放。不要靠删依赖压制重复。

异步请求还需取消或忽略迟到结果。Effect回调不直接async，因为返回值约定是清理函数；在内部启动异步过程并处理失败。Effect不在服务端渲染执行。

## 最小例子

```tsx
useEffect(()=>{
 const dispose=observe(topic)
 return dispose
},[topic,observe])
```

片段只解释本节机制；需要的import、类型和组件上下文以[真实实验与操作](../../../2-examples/04-frameworks/4.2-react/4.2.1.5.useeffect-demo.md)为准，不能把上下文片段当独立可运行文件。

## 操作、场景与边界

Subscription的真实回调记录start:A、stop:A、start:B；StrictMode实验另外检查额外设置/清理。不是连接外部消息服务。

依赖由实际读取决定，不能凭希望只运行一次填写。
