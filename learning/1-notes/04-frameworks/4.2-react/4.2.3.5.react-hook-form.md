# 4.2.3.5 React Hook Form + Zod：输入注册与运行校验

**React选修**。前置为阶段1 JavaScript/DOM与阶段3 TypeScript/模块/测试；不阻塞Vue 3 + Nuxt主线。目标：能解释本节机制，完成一个变体并定位指定故障。

## 解决什么问题与原理

React Hook Form管理表单注册、错误和提交状态；Zod对运行值校验并可变换。TypeScript注解只做静态约束，外部输入仍需真实schema验证。

本例register的validate调用Zod safeParse，提交再parse取得trim后的值；也可按对应版本接resolver，但本实验未安装resolver适配器。避免把校验后的类型与原始值混淆。

客户端校验用于反馈，服务端仍需再次验证与授权。标签、错误关联和提交中状态必须保留，不能为了自定义UI移除原生键盘能力。

## 最小例子

```tsx
const TaskSchema=z.object({title:z.string().trim().min(1).max(30)})
const parsed=TaskSchema.safeParse({title:input})
// register validate中将失败转成字段错误
```
