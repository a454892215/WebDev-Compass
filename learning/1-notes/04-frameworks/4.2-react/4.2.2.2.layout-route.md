# 4.2.2.2 嵌套与布局路由：Outlet和相对路径

**React选修**。前置为阶段1 JavaScript/DOM与阶段3 TypeScript/模块/测试；不阻塞Vue 3 + Nuxt主线。目标：能解释本节机制，完成一个变体并定位指定故障。

## 解决什么问题与原理

父路由可提供共同布局，子路由内容渲染到Outlet；index是父路径默认内容，不与另一个path同时混写。

路径嵌套表达URL结构，布局路由也可不增加路径段。导航可以相对当前路由解析，复杂层级应对照真实URL而非手拼字符串。

保留布局不等于所有子页状态永久保存；组件身份、key和挂载位置决定状态生命周期。路由边界也不自动等同权限边界。

## 最小例子

```tsx
<Route element={<Layout/>}>
 <Route index element={<Home/>}/>
 <Route path="tasks/:id" element={<Details/>}/>
</Route>
// Layout内包含 <Outlet/>
```
