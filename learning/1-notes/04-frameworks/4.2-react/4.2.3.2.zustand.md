# 4.2.3.2 Zustand：选择器、订阅与工厂隔离

**React选修**。前置为阶段1 JavaScript/DOM与阶段3 TypeScript/模块/测试；不阻塞Vue 3 + Nuxt主线。目标：能解释本节机制，完成一个变体并定位指定故障。

## 解决什么问题与原理

本节选Zustand，不要求同时学习Jotai。store维护状态与动作；React层可通过选择器订阅所需切片，vanilla createStore可在React之外测试核心行为。

默认set按第一层合并；深层对象仍要自己保持不可变更新。订阅返回取消函数，组件外手动订阅要按生命周期释放。

模块顶层store在单页应用中可用于应用共享，但SSR用户状态宜按请求/实例创建；持久化中间件不是秘密存储，hydration也需另行处理。

## 最小例子

```tsx
function makeSelectionStore(){
 return createStore<{selected:string|null;select:(id:string)=>void}>(set=>({
 selected:null,select:id=>set({selected:id})
 }))
}
```
