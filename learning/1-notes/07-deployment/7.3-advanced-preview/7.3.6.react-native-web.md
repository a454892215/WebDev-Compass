# 7.3.6 React Native Web/Expo Web：复用边界与平台行为

前置：阶段1原生HTML/JS、阶段3模块/测试、阶段4 Vue/Nuxt。业务选修，不阻塞首次交付；先读机制再按需实践。

## 解决什么问题与原理

React Native Web把一部分React Native组件映射到DOM能力，Expo提供跨平台开发/路由与Web发布工具。已有RN经验有助于复用业务逻辑，但Web仍有URL、语义、鼠标/键盘、复制选择、CSS布局与SEO等自身契约；不是把移动页面缩放就交付桌面。

共享领域模型/校验/请求协议通常比强制共享所有UI更稳定。平台特定文件和适配层用于隔离原生API，避免仅靠if分支却仍在模块顶层导入原生依赖。库支持Web不等于SSR安全；浏览器全局访问仍需合适生命周期。当前主线Vue/Nuxt，不把切换RNW作为复用既有经验的必需步骤。

## 最小片段与上下文

```javascript
// 依赖无关的复用边界示例；非Expo运行项目。
export function courseSummary(course) {
  if (!course || typeof course.title !== 'string') throw new TypeError('Invalid course');
  return {title:course.title, href:`/courses/${encodeURIComponent(course.id)}`};
}
console.log(courseSummary({id:'nuxt',title:'Nuxt'}));
```

## 应用与边界

类型：官方跨端观察。阅读Expo Web中RNW/DOM组件、Web依赖和发布模式说明，把课程目录按领域逻辑、路由、UI和系统能力分类。列出原生文件选择/浏览器下载、触摸/键盘的不同验收。未创建Expo工程或原生构建；不要把已有Flutter/RN经验当本轮已验证Web兼容。

## 移动开发对照

已有RN组件和领域模型能帮助复用；Web的链接、浏览器历史、键盘与鼠标行为不能由移动导航栈和触摸测试代替。Flutter/RN的原生插件不能因为同为JavaScript/跨端就直接在浏览器运行。
