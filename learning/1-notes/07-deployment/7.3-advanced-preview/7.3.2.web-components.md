# 7.3.2 Custom Elements与Shadow DOM：生命周期、语义和边界

前置：阶段1原生HTML/JS、阶段3模块/测试、阶段4 Vue/Nuxt。业务选修，不阻塞首次交付；先读机制再按需实践。

## 解决什么问题与原理

Custom Elements提供有连字符的自定义标签和生命周期；Shadow DOM提供DOM/样式封装。已有Vue组件体系时，站内UI优先保持Vue，跨框架嵌入或独立控件才考虑自定义元素，不为了换颜色重造button。

构造函数先super，再建立内部DOM；连接回调可能反复执行，必须可重入。断开时移除window监听、计时器和观察器，重连应恢复。Shadow DOM不是不可信脚本沙箱，open/closed也不构成授权；外部脚本仍处于页面的同源权限环境。属性、property、CustomEvent是明确契约，跨边界事件按需要设置bubbles/composed；跨树aria-id引用不能凭相同字符串建立关系。

## 最小片段与上下文

```javascript
// 在optional-lab/app.mjs中查看CourseCounter完整实现。
// 原生button承担键盘语义，内部label位于同一shadow tree。
const counter = document.querySelector('course-counter');
if (counter) {
  counter.addEventListener('count-change', e => console.log(e.detail.count));
  counter.remove();
  document.querySelector('#counter-mount').append(counter);
}
```

## 应用与边界

类型：真实原生浏览器实验。运行optional-lab后点击“课程计数”，观察父容器收到事件；点击重新连接后再计数，用DevTools查看open shadowRoot中的原生button。verify还会在断开时发stage7-tick，确认计数不变，重连后只增加一次，Enter能激活。

## 移动开发对照

可以把自定义元素理解为可重复连接的UI封装，但它不是Flutter Widget树：DOM节点可移动/断开后重连，原生button的键盘语义仍由浏览器负责，样式封装也不等于进程权限隔离。
