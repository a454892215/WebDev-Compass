# 6.3.8 缩放、重排、目标尺寸与运动偏好

前置：阶段1语义/样式、阶段3工程工具、阶段4Vue/Nuxt；本章是在已有能力上深化，不是首次才考虑质量。

## 解决什么问题

将“手机能显示”深化为可放大、可重排、可触达且尊重偏好的页面，而不靠缩小字体或禁止缩放掩盖布局。

## 机制与边界

WCAG1.4.4 AA关注文字放大到200%不丢内容/功能；1.4.10 AA对横向文字通常以320CSSpx宽等效条件检查不需双向滚动，数据表/地图等有必要二维布局例外。模拟窄视口与改根字体只是局部证据，不等于完整浏览器400%缩放认证。

WCAG2.5.8 AA目标尺寸通常至少24×24CSSpx，也有间距、等效、行内、用户代理或必要等例外；2.5.5增强44×44是AAA。实验统一44px按钮是较宽裕设计，不说明所有AA控件一律必须44px，也不对行内链接机械套正方形。

尊重prefers-reduced-motion可避免非必要动画，交互动效禁用的2.3.3属AAA；其他闪烁/自动播放/暂停等另有适用准则。减少动效不是全站任何动画都自动AA违规，但应按用户需求提供合理策略。

## 最小机制片段

```css
button { min-inline-size: 2.75rem; min-block-size: 2.75rem; }
img { max-inline-size: 100%; block-size: auto; }
@media (prefers-reduced-motion: reduce) { button { transition: none; } }
```

片段按注释提供上下文，完整可运行文件及操作条件见示例；不能把片段或观察清单当完整生产实现。

## 实际观察与适用场景

lab在390/1440控制按钮实际≥44px；320CSSpx与CSS根字体200%条件不横溢、表单仍可用；模拟reduce后transition为0。没有操作真实浏览器zoom UI。

## 移动经验对照

移动端dp/系统字号经验有帮助，但CSSpx、浏览器zoom、文本缩放和设备像素不是同一单位；不能用一个390px截图替代验收。
