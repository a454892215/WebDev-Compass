# 6.3.3 替代文本、可访问名称和ARIA的正确边界

前置：阶段1语义/样式、阶段3工程工具、阶段4Vue/Nuxt；本章是在已有能力上深化，不是首次才考虑质量。

## 解决什么问题

为图像与控件提供有用名称，避免没有名称或重复/误导播报。

## 机制与边界

信息图像的alt描述其在当前任务的意义；装饰图像可用alt=""，复杂图表还需等价文字/数据说明。不能机械把文件名当alt，也不是所有图标都应加同一名称。

控件优先用可见文字/label命名。aria-label可以提供或覆盖名称，aria-labelledby引用已有可见文案；描述用aria-describedby，不要把长说明全部塞进名称。aria-hidden只隐藏辅助技术可见性，不等于视觉隐藏或禁用交互。

不要把aria-hidden=true放在可聚焦元素或其仍可聚焦祖先。原生button已有正确role通常不重复role=button；按钮中的装饰SVG隐藏而按钮保留可见文字。

## 最小机制片段

```html
<img src="./cover.svg" width="320" height="160" alt="蓝色课程卡片封面">
<button type="button"><svg aria-hidden="true"><!-- 装饰图形 --></svg>打开帮助</button>
```

片段按注释提供上下文，完整可运行文件及操作条件见示例；不能把片段或观察清单当完整生产实现。

## 实际观察与适用场景

lab信息图有具体alt，帮助按钮SVG装饰隐藏但可见文字命名；坏样本缺alt/按钮名称时真实axe报告失败。

## 移动经验对照

移动端contentDescription/语义标签的目标相似，但HTML alt、名称计算与描述关系不是任意同义替换。
