这是本地教学验收，不是未经测量的生产SLA。背景、触发、响应、度量和未测范围应一起读。

| 情景/刺激                                | 要求与证据                                                                      | 范围限制                                    |
| ---------------------------------------- | ------------------------------------------------------------------------------- | ------------------------------------------- |
| 四个并发SSR请求交替选择alice/bob         | HTML/DTO只含所选scope，不含另一个标签或内部标记，no-store/cache:false；HTTP测试 | scope公开非认证，未做负载/生产多租户        |
| 必需课程DTO缺字段                        | 应用服务抛错，API映射502，不返回空成功；unit故障注入                            | API固定正常fixture，真实HTTP上游错误另在lab |
| 可选进度不可用                           | 课程仍展示，completed=null与可读warning；unit+HTTP+浏览器                       | 不把缺失当0，没有完整监控/重试预算          |
| 页面、domain或shared违规导入server/outer | pnpm boundaries非零；正反例回归                                                 | 只覆盖明确源码图，不是安全sandbox           |
| 搜索/样例切换/详情刷新                   | URL可复现，key包含远程结果维度，收藏scope区分；浏览器                           | 收藏刷新清空，非离线/账号同步               |

性能不预设“所有请求100ms”或“SSR一定快”；此阶段只验证机制，不构建生产CWV/容量保证。需要性能预算时按阶段9选真实目标、环境和样本。
