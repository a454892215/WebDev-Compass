# RFC：模块化学习工作台

状态：本地教学实现已采用；不代表生产上线。读者已有移动端模块化经验，需验证Vue/Nuxt的运行、数据与部署边界。

目标：一个课程目录，URL可分享scope/搜索，课程与可选进度可分别失败，DTO有明确公开字段；模块依赖方向可机械检查，SSR不同请求不串数据。非目标：真实登录、账户权限、远程微服务、持久化收藏、完整微前端或CRDT、生产容量承诺。

约束：单个小团队/一个发布单元（教学假设），本地Node SSR；只有合成公开数据，无外部凭据。reuse已验证Nuxt4.7/Vue3/TS工具链，不机械照搬Flutter全局单例。

| 候选              | 收益                                           | 代价与适用条件                                               |
| ----------------- | ---------------------------------------------- | ------------------------------------------------------------ |
| 模块化Nuxt单体    | 运行/发布简单，feature内聚，SSR与BFF可一起验证 | 同一进程故障边界，需要请求状态与明确缓存策略                 |
| 独立前端与BFF服务 | 后端可独立伸缩/发布，职责更独立                | 多部署单元、接口和网络运维；有独立团队/后端需求再评估        |
| 微前端            | 业务团队可独立交付                             | 远端契约、路由、依赖、故障与体验协调成本；当前无相应组织收益 |

选择第一种。按业务feature聚合，内部保留纯domain/application与框架composables/组件；server API组装端口与fixture adapter，应用服务不导入具体infra。公开shared只放契约/解码，不塞客户端状态或私有基础设施。

状态归属：URL是scope和已提交搜索的唯一来源；input draft为组件ref；服务器课程由useAsyncData按scope+失败情景建key；收藏是每Nuxt应用useState且key值按scope:slug区分，刷新丢失，不称持久化或跨设备同步。scope只是公开fixture选择，任意人可更改，不是身份认证。

验证：10unit含边界正反例/DTO/降级/隔离；生产构建、原始HTTP与后台浏览器、依赖检查。详细NFR和边界见同目录文件。移除失败可选数据时保留课程，进度为null+warning；不能用0冒充失败。必要DTO错误由应用服务拒绝；主API配置固定合成源，不接用户URL。

后果：增加少量端口/映射，换取可测试依赖；没有为每函数建立类或完整DDD层。主端口立即返回合成Promise，无真实网络deadline，超时/取消在BFF独立lab验证。真实认证/授权、DB和数据治理需以后根据产品完善。

重新评估触发：真实独立团队发布、外部接口SLA、离线写入/协作冲突或生产容量瓶颈；有证据再决定，不因为知识地图出现技术名就安装。
