# 学习资料

知识地图的每个阶段按四部分组织：

| 目录 | 职责 |
| --- | --- |
| [1-notes](./1-notes/) | 原理、机制、场景、对照与误区 |
| [2-examples](./2-examples/) | 观察单个机制的可运行实验或明确观察清单 |
| [3-exercises](./3-exercises/) | 独立修改、排错任务、验收与参考要点 |
| [4-practice](./4-practice/) | 多知识点组合项目、任务与覆盖映射 |

每个知识点关联四部分，多个知识点可以共享综合项目。文件存在、自动检查通过和学习者真正掌握分别记录；不为满足数量创建空文件。
