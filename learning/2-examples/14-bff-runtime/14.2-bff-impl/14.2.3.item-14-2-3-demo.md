# 14.2.3 会话校验、JWT验证与请求级身份：本地实测入口

类型：Nuxt4.7.0 + Vue3.5.46 + Node26的真实本地HTTP/SSR项目；两个合成用户及固定loopback上游。不是生产登录/真实业务API。

## 运行

在[实践目录](../../../4-practice/14-bff-runtime/README.md)先执行pnpm install --frozen-lockfile、pnpm build，然后pnpm test:e2e。开发交互需两个终端：pnpm upstream和pnpm dev。详细命令、端口与限制以实践README为准。

## 观察和解释

分别建立两个独立请求上下文选择alice/bob，并发请求dashboard与SSR首页，核对没有混入另一用户数据。

先预测状态、数据和边界，再看tests/e2e/http.spec.ts、flow.spec.ts及tests/unit/contracts.test.ts里的断言。主API和SSR都实际执行；只检查文件存在不能代替这些行为证据。

## 变体

在隔离副本给合成会话增加退出接口和服务端撤销，写接口遵守同源校验。

成功标准：退出后旧SID实际401，另一个用户会话仍有效。；说明本地身份选择非生产登录、JWT解析非校验及Map跨实例限制。。变体是要求学习者新增的任务，主项目未声称已经实现通知服务、退出或SDK生成。
