# 14.4.1 Edge 与 Node：按平台、数据位置和 API 选运行时：操作卡

类型：Node Web API实际运行 + 明确标注的官方平台观察，未部署Edge。运行条件Node26，无第三方依赖；先读[实验入口](./edge-lab/README.md)。

~~~bash
node --test learning/2-examples/14-bff-runtime/14.4-edge-runtime/edge-lab/policy.test.mjs
~~~

命令从仓库根目录执行；policy.mjs及policy.test.mjs都在edge-lab目录，测试名含本编号。

## 操作与预期

运行命名含 14.4.1 的测试，观察实际 Request 到 Response JSON；随后列出主 BFF 的 Node 依赖和数据库区域。

本地返回200和公开商品，平台兼容性保持“待部署验证”；把 Node 能力、部署位置、数据位置分栏，不混成“Edge快/Node慢”。

## 排查与边界

先问依赖与数据在哪里，再问运行时；兼容日期是部署契约的一部分，不能只记录包版本。 实验使用合成数据，无真实Cookie凭据、账号或云存储；Request使用local.invalid但没有发外网请求。不会测得网络时延、云配额或真实多区域行为。
