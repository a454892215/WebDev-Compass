# 14.4.5 CDN 缓存与 SWR：公开内容、键和过期边界：操作卡

类型：Node Web API实际运行 + 明确标注的官方平台观察，未部署Edge。运行条件Node26，无第三方依赖；先读[实验入口](./edge-lab/README.md)。

~~~bash
node --test learning/2-examples/14-bff-runtime/14.4-edge-runtime/edge-lab/policy.test.mjs
~~~

命令从仓库根目录执行；policy.mjs及policy.test.mjs都在edge-lab目录，测试名含本编号。

## 操作与预期

运行含14.4.5的四项测试：9999/10000毫秒fresh切换、40000过期重取、失败不无限续旧、并发miss合并与有凭据绕过。

10秒旧值先返回、settle后新版本；30秒后失败抛错；相同公开键并发只load一次，语言隔离且凭据请求不读公共Map。

## 排查与边界

缓存策略必须同时描述可缓存对象、键、TTL、并发、失效、失败和隐私。HTTP指令是否被平台执行需要真实部署证据。 实验使用合成数据，无真实Cookie凭据、账号或云存储；Request使用local.invalid但没有发外网请求。不会测得网络时延、云配额或真实多区域行为。
