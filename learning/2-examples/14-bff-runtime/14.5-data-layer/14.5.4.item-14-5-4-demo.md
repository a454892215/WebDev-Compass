# 14.5.4 Prisma schema 与迁移：读懂约束，保护 API 兼容性：可运行实验与观察

## 运行条件

进入[data-lab](./data-lab/README.md)，Node26/pnpm11，先pnpm install --frozen-lockfile，再pnpm test。运行全部8项便于交叉比较，测试名称标明本点机制；无真实账户、Redis、数据库或云端。第八项仅临时回环端口，退出清理。

## 操作与实际预期

阅读schema.prisma和migration-plan.md，再运行第六项测试：displayName=null时严格DTO拒绝，回填后映射为{id,name}且passwordHash不会外露。测试证明DTO切换前置条件，不是Prisma生成、SQL执行或真实数据库迁移。

## 证据边界

未安装Prisma CLI、未生成客户端、未执行SQL。数据库版本、锁表/大表性能、回填并发及生产恢复不在本轮实测范围。对外DTO变更仍需14.2.6契约测试和旧客户端兼容评审。 参考实现位于lab.mjs，测试在test.mjs。先预测结果，再读断言核对；修改只能在隔离副本，避免破坏其他知识点。不要把assert数量当性能或生产可靠性证明。
