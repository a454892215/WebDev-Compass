# 14.5.5 WebSocket / SSE：心跳、重连、游标与连接资源：可运行实验与观察

## 运行条件

进入[data-lab](./data-lab/README.md)，Node26/pnpm11，先pnpm install --frozen-lockfile，再pnpm test。运行全部8项便于交叉比较，测试名称标明本点机制；无真实账户、Redis、数据库或云端。第八项仅临时回环端口，退出清理。

## 操作与实际预期

第七项确定性测试backoff范围和A/B游标过滤。第八项真实Node回环HTTP SSE：发送心跳、Last-Event-ID=1时只收到A-two/id=3，读取真实Response.body直到目标事件，再cancel并验证服务端close清理心跳。身份A在测试服务器固定，仅用于协议fixture，不是认证接口。

## 证据边界

未运行浏览器EventSource或真实WebSocket握手/ping，未经过CDN/移动网络/长时运行。Node fetch测试验证SSE字节/重放/关闭，不等于浏览器原生自动重连验证；生产需另测鉴权、游标过期、队列上限与扩容。 参考实现位于lab.mjs，测试在test.mjs。先预测结果，再读断言核对；修改只能在隔离副本，避免破坏其他知识点。不要把assert数量当性能或生产可靠性证明。
