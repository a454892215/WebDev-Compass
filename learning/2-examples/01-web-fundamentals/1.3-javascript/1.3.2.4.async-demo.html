async / await

async 函数总返回Promise；await暂停当前async函数的后续执行，不阻塞整个浏览器。

只在本页观察，不上传数据；请通过本地 HTTP 服务打开。先预测，再运行并解释。

核心代码

const wait = ms => new Promise(resolve => setTimeout(resolve, ms));
async function task(value) {
  await wait(20);
  return value * 2;
}
const results = await Promise.all([task(2), task(3)]);
console.log(results); // [4, 6]
