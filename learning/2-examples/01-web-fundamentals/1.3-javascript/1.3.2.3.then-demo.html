Promise 基础：then、catch、finally

Promise 表示将来完成或失败的一次结果；then 返回新的Promise，用于组合后续步骤。

只在本页观察，不上传数据；请通过本地 HTTP 服务打开。先预测，再运行并解释。

const wait = ms => new Promise(resolve => setTimeout(resolve, ms));
wait(20)
  .then(() => 2)
  .then(value => value * 3)
  .then(console.log)
  .catch(error => console.log(error.message))
  .finally(() => console.log('结束'));
