# 9.3.4 推测加载：预取、预渲染与无副作用边界：操作与观察

## 条件与运行类型

按[loading-lab](./loading-lab/README.md)冻结安装、运行pnpm test与pnpm verify；本地Chrome两视口，主Nuxt仅SSR主题，不虚构其已有字体/CDN功能。

## 操作与实际机制

lab仅在用户动作后探测HTMLScriptElement.supports(speculationrules)，Save-Data跳过，插入固定公开next.html的prefetch建议并保留正常链接；单测验证不支持/节流回退。浏览器验证规则与导航，没有声称实际prefetch/prerender、命中或带宽收益。

阅读lab对应index.html/app.mjs/server.mjs及verify断言；先预测结果再运行，保存原始资源/状态/协议与限制。

## 预期与验收

- 规则不含账号/支付/退出/带秘密查询URL，普通链接无建议时仍可用。
- 分别记录支持、建议发出、实际网络行为和激活，不能把第一项当最后一项。

## 反例与定位

故障：用所有a.href生成prerender列表，退出GET或计数脚本被提前运行。只在合成副本审查与复现；删副作用候选，后台控制台检查，不在真实账户上试错。

把节省等待与额外网络/内存/隐私成本一起纳入预算，不以“API存在”默认全站开启。

## 未测范围

无公网H3/TLS/CDN、真实用户流量、多浏览器/真机/读屏；支持和建议发出不是执行/激活证明。lab资源与结果不能替代真实业务素材和网络测量。
