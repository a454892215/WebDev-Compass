# 7.3.6 React Native Web/Expo Web：复用边界与平台行为 — 操作卡

## 条件与入口

先读[理论](../../../1-notes/07-deployment/7.3-advanced-preview/7.3.6.react-native-web.md)；原生实验运行[optional-lab](./optional-lab/README.md)，官方观察无需安装全部框架。

## 操作与可核对结果

类型：官方跨端观察。阅读Expo Web中RNW/DOM组件、Web依赖和发布模式说明，把课程目录按领域逻辑、路由、UI和系统能力分类。列出原生文件选择/浏览器下载、触摸/键盘的不同验收。未创建Expo工程或原生构建；不要把已有Flutter/RN经验当本轮已验证Web兼容。

## 失败与恢复

故障：Web条件分支不执行原生代码，但文件顶层仍导入仅原生模块，构建已失败。将导入移动到平台入口/适配层，分别检查Web与原生打包路径；未实际构建必须标观察方案。
