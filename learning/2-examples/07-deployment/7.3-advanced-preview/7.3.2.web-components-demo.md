# 7.3.2 Custom Elements与Shadow DOM：生命周期、语义和边界 — 操作卡

## 条件与入口

先读[理论](../../../1-notes/07-deployment/7.3-advanced-preview/7.3.2.web-components.md)；原生实验运行[optional-lab](./optional-lab/README.md)，官方观察无需安装全部框架。

## 操作与可核对结果

类型：真实原生浏览器实验。运行optional-lab后点击“课程计数”，观察父容器收到事件；点击重新连接后再计数，用DevTools查看open shadowRoot中的原生button。verify还会在断开时发stage7-tick，确认计数不变，重连后只增加一次，Enter能激活。

## 失败与恢复

故障：connectedCallback每次创建新箭头window监听但断开用另一个函数移除，重连后一次事件累计多次。将处理函数保存为稳定引用，在disconnectedCallback匹配移除；重复两次重连后单次变化仍为1。
