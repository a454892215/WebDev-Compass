# 7.3.3 GraphQL客户端：查询、部分错误与身份缓存 — 操作卡

## 条件与入口

先读[理论](../../../1-notes/07-deployment/7.3-advanced-preview/7.3.3.graphql.md)；原生实验运行[optional-lab](./optional-lab/README.md)，官方观察无需安装全部框架。

## 操作与可核对结果

类型：官方文档/合成响应观察。阅读GraphQL response与Apollo errorPolicy，比较none/all/ignore；为片段标注HTTP错误、请求验证错误、字段错误与正常空值。画出两个用户请求的两个独立客户端及注销后缓存清理。没有建立GraphQL服务，也没有安装Apollo/urql，不把JSON分析称接口实测。

## 失败与恢复

故障：将errorPolicy:ignore用于必须成功的权限字段，界面吞掉错误。对照data/errors/path恢复明确错误分支；分别列出网络失败与字段失败的预期，未接真实服务只提交响应fixture分析。
