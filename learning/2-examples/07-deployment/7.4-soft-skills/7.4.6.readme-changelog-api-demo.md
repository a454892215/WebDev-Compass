# 7.4.6 交付文档：README、CHANGELOG与API契约：操作示例

类型：本地项目阅读与实际命令观察，不冒充远程CI/团队协作。

## 条件与操作

先按[综合项目](../../../4-practice/07-deployment/README.md)安装并构建相应profile。

按主README依次安装、三个profile构建、HTTP与浏览器验证；再核对docs/CHANGELOG.md和API_CONTRACT.md。产物不提交，命令应从项目根执行；静态public不能用Nitro server入口运行，但可用Node静态文件服务器托管；SSR不能只上传public。

## 预期与边界

命令可复现、环境和输出目录明确；不依赖全局旧版本或隐藏文件。

变更说明包含兼容影响与恢复，接口例子与真实返回一致，秘密只写占位。

不把运行结果和判断混写：记录命令、状态/内容、预期与差异。人工阅读不是自动证明全部安全；真实发布/第三方账号未运行。

## 对照与排错

故障：README仍写node .output/server但最近运行generate覆盖了.output。改用保存的artifacts/ssr/server，并重新核对实际产物。

文档针对最终版本重写，不保留弃用方案冒充现行步骤；日期/版本与真实验证分开。
