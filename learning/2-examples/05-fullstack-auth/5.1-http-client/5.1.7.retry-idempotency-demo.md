# 5.1.7 操作卡：安全重试与幂等：限额、退避和重复写入边界

类型：真实源码/HTTP/浏览器实验，按下方具体范围操作。先阅读[HTTP实验运行说明](./http-lab/README.md)；工程需要Node26，浏览器专项需要可用的本机Chrome与已有Playwright。

## 源码与步骤

本组源码：`http-lab/client.mjs:safeRead、server.mjs:retry/create、tests/http.test.mjs`。文件路径以当前章节及实验README为准。

429+Retry-After:0的真实HTTP在第二次成功；503+120秒只请求一次；403不重试；自动POST被策略拒绝。相同key/body创建返回同id，不同body同key409。

## 预期与证据

先预测，再运行并记录真实状态/返回值。`pnpm check`运行9组实际Node HTTP与受控异步测试；`pnpm test:browser`检查390/1440的真实XHR传输与Blob下载。各点只采用相关证据，不把Node通过当浏览器CORS/真机通过。

本轮GraphQL/gRPC-Web只有明确观察样本，不含服务执行；OpenAPI检查只覆盖本地已知契约，不是完整规范校验器。Nuxt综合项目的身份/SSR由主工程另验。
