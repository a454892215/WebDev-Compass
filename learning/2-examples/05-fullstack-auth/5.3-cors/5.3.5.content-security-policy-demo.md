# 5.3.5 实验：HTTPS与安全响应头：按部署能力逐步收紧

类型：真实本地Node双端口与后台Chrome观察；HTTPS/生产部署部分为明确清单，不冒称实测。

## 运行条件

按[network-lab README](./network-lab/README.md)安装固定依赖并启动。页面4404、API/WS/SSE/Socket.IO4405；只访问loopback，不需真实账号/Token，不关闭浏览器安全策略。

## 对照源码与操作

- [服务器](./network-lab/server.mjs)：响应头、请求计数、协议端点与连接清理。
- [页面控制器](./network-lab/public/client.mjs)：Fetch、WS/SSE启动/停止、有限重连。
- [浏览器验收](./network-lab/verify.mjs)：实际条件断言，预期CORS/CSP拒绝不算pageerror业务崩溃。

进入4404/csp：同源外部allowed.js设置externalRan，内联inlineRan被阻止；自动检查真实CSP响应头。HTTPS证书、混合内容、HSTS按部署观察清单另核对，本轮未做公网验证。

运行`pnpm test`，本点对应报告组`csp-390/csp-1440`；一组含多个断言，不等于学习者已掌握。本地数据是fixture，验证认证/生产TLS/真正推送需另外环境。
