# 3.1.2 实验：npm、Yarn、pnpm：安装、脚本与本地打包

[理论](../../../1-notes/03-engineering/3.1-package-management/3.1.2.npm-yarn-pnpm.md) · [独立练习](../../../3-exercises/03-engineering/3.1-package-management/3.1.2.npm-yarn-pnpm.md) · [示例目录](./README.md)

类型：真实本地CLI／构建实验，含适用浏览器观察。

## 环境和入口

前置：3.1.1与命令行；本库默认pnpm，npm/Yarn作为对照。 本机验证Node26.0.0、pnpm11.4.0，工具固定版本见manifest。

本点复用[package-lab项目](./package-lab/README.md)，重点阅读[packages/app/index.js](./package-lab/packages/app/index.js)。先阅读命令和源码，使用演示数据；不真实publish、不上传凭据。

## 操作与预期

在package-lab运行默认脚本、filter子包与本地pack；检查tarball清单。npm/Yarn只阅读对应命令映射，本轮不声称全部工具安装实测。

1. 能区分安装、运行、归档与发布。
2. filter仅运行预期包，pack清单无凭据/缓存和node_modules。

## 排错观察

在副本错写filter包名，观察未匹配或失败信息；不能把没有执行任何包当任务通过。

## 证据边界

本轮实际执行和可复跑命令以组内[验证报告](../../../../docs/audits/stage-3-build-review.md)为准。静态阅读、CLI、浏览器HMR与产物断言分别记录；不把Webpack阅读、预览、source map存在称完整部署或GPU/性能验证。不要提交node_modules、dist或本地.env。
