# 3.1.1 实验：package.json：依赖、脚本与运行环境

[理论](../../../1-notes/03-engineering/3.1-package-management/3.1.1.package.json.md) · [独立练习](../../../3-exercises/03-engineering/3.1-package-management/3.1.1.package.json.md) · [示例目录](./README.md)

类型：真实本地CLI／构建实验，含适用浏览器观察。

## 环境和入口

前置：阶段0包管理与阶段2模块；先阅读manifest再执行命令。 本机验证Node26.0.0、pnpm11.4.0，工具固定版本见manifest。

本点复用[package-lab项目](./package-lab/README.md)，重点阅读[package.json](./package-lab/package.json)。先阅读命令和源码，使用演示数据；不真实publish、不上传凭据。

## 操作与预期

进入package-lab，阅读根manifest及packages/app/package.json，再运行pnpm check与pnpm workspace；分别观察工具依赖和workspace运行依赖。

1. 能说明typecheck、build、test各检查什么，错误退出能被发现。
2. 依赖版本和运行环境有记录，private防误发布且不把它当秘密保护。

## 排错观察

在副本把check脚本改成不存在文件，运行并记录退出码；恢复路径后同一命令通过。

## 证据边界

本轮实际执行和可复跑命令以组内[验证报告](../../../../docs/audits/stage-3-build-review.md)为准。静态阅读、CLI、浏览器HMR与产物断言分别记录；不把Webpack阅读、预览、source map存在称完整部署或GPU/性能验证。不要提交node_modules、dist或本地.env。
