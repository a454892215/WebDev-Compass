## 看哪段代码

核心在 [src/experiments.ts](./src/experiments.ts) 的 `generics()`；模块契约见 [contracts.ts](./src/contracts.ts)，声明见 [build-meta.d.ts](./types/build-meta.d.ts)。共享runner只调用各函数并记录返回值，核心类型与运行操作不是预填答案。

单独运行本点（先执行pnpm build）：

```bash
node --input-type=module -e "import { generics } from './dist/experiments.js'; console.log(generics())"
```

## 预期与反例

- 返回类型保留各模型特有字段。
- 缺id的输入被拒绝，找不到时有undefined分支。
- 工具类型没有被误当运行期对象变换。

`verify.mjs`会生成本点编译反例，用真实tsc确认被拒绝；正例编译后运行实际函数断言。错误源码只放临时目录，验证后删除，不通过永久any或关闭strict制造全绿。

## 边界

当多个模型共享查询、映射关系时有价值；不为每个函数都设计“通用框架”。Partial也不能直接当未经验证的更新协议。

本点UI/移动端行为不在Node编译实验中冒充已验证；Vue实际挂载另见3.5/阶段4。
