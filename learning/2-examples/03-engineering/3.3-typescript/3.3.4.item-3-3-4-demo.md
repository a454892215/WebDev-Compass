## 看哪段代码

核心在 [src/experiments.ts](./src/experiments.ts) 的 `unions()`；模块契约见 [contracts.ts](./src/contracts.ts)，声明见 [build-meta.d.ts](./types/build-meta.d.ts)。共享runner只调用各函数并记录返回值，核心类型与运行操作不是预填答案。

```bash
node --input-type=module -e "import { unions } from './dist/experiments.js'; console.log(unions())"
```

## 预期与反例

- 未收窄直接访问专属value被拒绝。
- 新增状态后穷尽分支检查失败，补齐后恢复。
- 解释冲突交叉字段为何不能赋值。

`verify.mjs`会生成本点编译反例，用真实tsc确认被拒绝；正例编译后运行实际函数断言。错误源码只放临时目录，验证后删除，不通过永久any或关闭strict制造全绿。

## 边界

用于加载/错误等互斥状态，优于多个可能互相矛盾的布尔值；不要求小页面过度状态机化。

本点UI/移动端行为不在Node编译实验中冒充已验证；Vue实际挂载另见3.5/阶段4。
