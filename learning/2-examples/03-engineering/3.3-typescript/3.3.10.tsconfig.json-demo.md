## 预期与反例

- null/undefined错误能被检查，边界输入仍运行期验证。
- paths编译通过但Node失败可复现，补运行时解析后再验收。
- 高版本lib没有被说成安装了旧浏览器polyfill。

`verify.mjs`会生成本点编译反例，用真实tsc确认被拒绝；正例编译后运行实际函数断言。错误源码只放临时目录，验证后删除，不通过永久any或关闭strict制造全绿。

## 边界

修改配置后要运行tsc与真实构建/运行。单独传文件可能不按预期读取项目tsconfig；使用tsc -p。版本升级的废弃选项需查对应版本文档。

本点UI/移动端行为不在Node编译实验中冒充已验证；Vue实际挂载另见3.5/阶段4。
