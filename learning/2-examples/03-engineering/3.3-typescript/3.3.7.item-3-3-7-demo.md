## 看哪段代码

核心在 [src/experiments.ts](./src/experiments.ts) 的 `functions()`；模块契约见 [contracts.ts](./src/contracts.ts)，声明见 [build-meta.d.ts](./types/build-meta.d.ts)。共享runner只调用各函数并记录返回值，核心类型与运行操作不是预填答案。

```bash

```

## 预期与反例

- 错误参数类型的回调不能赋给正确契约。
- 省略/undefined/null的行为按明确约定处理。

`verify.mjs`会生成本点编译反例，用真实tsc确认被拒绝；正例编译后运行实际函数断言。错误源码只放临时目录，验证后删除，不通过永久any或关闭strict制造全绿。

## 边界

为模块协作固定最小契约。异步函数显式Promise<Result>，注意reject不是类型中的自动错误分支，错误处理另设计。

本点UI/移动端行为不在Node编译实验中冒充已验证；Vue实际挂载另见3.5/阶段4。
