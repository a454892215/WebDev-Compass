## 看哪段代码

核心在 [src/experiments.ts](./src/experiments.ts) 的 `basics()`；模块契约见 [contracts.ts](./src/contracts.ts)，声明见 [build-meta.d.ts](./types/build-meta.d.ts)。共享runner只调用各函数并记录返回值，核心类型与运行操作不是预填答案。

单独运行本点（先执行pnpm build）：

```bash
node --input-type=module -e "import { basics } from './dist/experiments.js'; console.log(basics())"
```

## 预期与反例

- unknown未收窄访问属性被拒绝。
- 元组位置错误被拒绝，数组不存在元素有显式回退。
- 记录enum输出JS对象与type擦除的不同。

`verify.mjs`会生成本点编译反例，用真实tsc确认被拒绝；正例编译后运行实际函数断言。错误源码只放临时目录，验证后删除，不通过永久any或关闭strict制造全绿。

## 边界

本包由真实tsc编译enum，不把Node直接剥离TS或Vite的所有配置都称支持。对象包装类型String/Number通常不用于普通值注解。

本点UI/移动端行为不在Node编译实验中冒充已验证；Vue实际挂载另见3.5/阶段4。
