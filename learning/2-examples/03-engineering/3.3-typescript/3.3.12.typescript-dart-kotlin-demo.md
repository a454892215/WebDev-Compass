## 看哪段代码

核心在 [src/experiments.ts](./src/experiments.ts) 的 `mobileBoundary()`；模块契约见 [contracts.ts](./src/contracts.ts)，声明见 [build-meta.d.ts](./types/build-meta.d.ts)。共享runner只调用各函数并记录返回值，核心类型与运行操作不是预填答案。

单独运行本点（先执行pnpm build）：

```bash
node --input-type=module -e "import { mobileBoundary } from './dist/experiments.js'; console.log(mobileBoundary())"
```

## 预期与反例

- 能给出两个编译期拒绝与两个运行期仍需验证的例子。
- 未把TS断言等同转换或Dart/Kotlin运行期类型检查。

`verify.mjs`会生成本点编译反例，用真实tsc确认被拒绝；正例编译后运行实际函数断言。错误源码只放临时目录，验证后删除，不通过永久any或关闭strict制造全绿。

## 边界

本章只在TS编译器与Node运行，不建立Dart/Android工程，也不声称跨平台运行验证。需要迁移具体框架时查目标版本官方文档。

本点UI/移动端行为不在Node编译实验中冒充已验证；Vue实际挂载另见3.5/阶段4。
