## 看哪段代码

核心在 [src/experiments.ts](./src/experiments.ts) 的 `modules()`；模块契约见 [contracts.ts](./src/contracts.ts)，声明见 [build-meta.d.ts](./types/build-meta.d.ts)。共享runner只调用各函数并记录返回值，核心类型与运行操作不是预填答案。

单独运行本点（先执行pnpm build）：

```bash
node --input-type=module -e "import { modules } from './dist/experiments.js'; console.log(modules())"
```

## 预期与反例

- 输出JS没有import type和interface。
- 能解释声明存在但运行值缺失的失败，并修复真实实现/加载方式。

`verify.mjs`会生成本点编译反例，用真实tsc确认被拒绝；正例编译后运行实际函数断言。错误源码只放临时目录，验证后删除，不通过永久any或关闭strict制造全绿。

## 边界

实验types/build-meta.d.ts声明BUILD_META；Node里typeof BUILD_META仍是undefined。真实代码直接读取未实现的变量会ReferenceError，类型检查通过不补运行时。

本点UI/移动端行为不在Node编译实验中冒充已验证；Vue实际挂载另见3.5/阶段4。
