## 预期与反例

- 外部访问private/protected在tsc失败。
- readonly可经反射改变而#private品牌仍检查，能解释它们不是同一保障。

`verify.mjs`会生成本点编译反例，用真实tsc确认被拒绝；正例编译后运行实际函数断言。错误源码只放临时目录，验证后删除，不通过永久any或关闭strict制造全绿。

## 边界

可用于实例状态，但不要求为了学修饰符把清晰纯函数重写成类。秘密不能只靠前端private字段保护，浏览器代码仍由用户掌控。

本点UI/移动端行为不在Node编译实验中冒充已验证；Vue实际挂载另见3.5/阶段4。
