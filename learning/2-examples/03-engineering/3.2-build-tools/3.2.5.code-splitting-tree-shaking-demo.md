## 环境和入口

前置：ESM、dynamic import、3.2.1。 本机验证Node26.0.0、pnpm11.4.0，工具固定版本见manifest。

本点复用[vite-lab项目](./vite-lab/README.md)，重点阅读[scripts/check-output.mjs](./vite-lab/scripts/check-output.mjs)。先阅读命令和源码，使用演示数据；不真实publish、不上传凭据。

## 操作与预期

运行vite-lab build及check:output；检查至少两个JS资产，动态统计点击前后真实网络请求不同，唯一unused标记不在运行JS中。

1. 构建生成独立按需JS，按钮首次点击后实际加载并运行。
2. 明确本例纯导出被删，不宣称所有副作用/依赖都自动安全裁剪。

## 排错观察

把初始化副作用加入模块并在副本观察产物；说明为什么不能为缩包盲目声明所有sideEffects:false。

## 证据边界

本轮实际执行和可复跑命令以组内[验证报告](../../../../docs/audits/stage-3-build-review.md)为准。静态阅读、CLI、浏览器HMR与产物断言分别记录；不把Webpack阅读、预览、source map存在称完整部署或GPU/性能验证。不要提交node_modules、dist或本地.env。
