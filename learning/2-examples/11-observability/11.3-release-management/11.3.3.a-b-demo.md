# 11.3.3 示例：A/B实验：分配、可见曝光、转化与污染控制

## 类型与运行条件

真实本地代码实验；[release-lab运行入口](./release-lab/README.md)。Node26/pnpm11；pnpm verify使用后台Chrome390/1440，端口4534仅loopback；合成fixture，不接真实身份或第三方上报。

## 操作与真实预期

运行node server.mjs，读分配后查看exposed仍0；显示卡片进入视口后为1，重复显示仍1，转化为1。pnpm verify自动用390/1440视口复验，并用HTTP验证无曝光转化409/额外字段400。

先预测，运行后保存自己的输出；本轮证据见[组运行记录](../../../../docs/audits/stage-11-release-runtime.json)。

## 改变一个条件

把event(exposure)移入assignment接口或组件setup，刷新/预取会计数。复现“未显示卡片但exposed增长”，恢复到实际展示触发并保留服务端幂等。

## 边界

移动分析SDK常有屏幕曝光回调，Web路由、DOM渲染与视口可见是不同事件；Nuxt SSR完成也不代表用户看到。两端都应明确单位/版本/归因，不把生命周期回调当真实注意力。 示例既不连接LaunchDarkly/Unleash，也不证明真实RUM、显著性、数据库回滚、云部署或值班通知。
