# 13.3.4 持久产物缓存与构建测量：键、输出恢复和失效证据：操作卡

## 类型与准备

真实本地构建/Node/浏览器型。在本组[build-lab](./build-lab/README.md)按固定Node/pnpm安装；输出仅dist/artifacts，端口4553 loopback。

~~~bash
pnpm build
pnpm test
pnpm verify
~~~

## 操作与预期

cache.mjs是显式本地产物缓存wrapper，固定清单哈希app/CSS/HTML/plugin/config/cache代码/package/lock，并纳入Node/Vite/platform/arch与公开label。verify实际cold未命中构建，删除输出后warm命中恢复；改label、改源均失效；篡改缓存audit后校验失败并重建。输出记录每次durationMs，但不承诺warm一定更快。

固定清单适合这个小实验，不是通用依赖图：新增import/文件/构建环境必须扩展输入或改用成熟编排工具。hash是内容一致性，不是来源认证；不能把不可信PR/跨租户远程缓存当可信产物。cold这里只指本地wrapper条目缺失，不是清空OS/Node/包管理器所有缓存，也不是生产profile。

记录输入、实际输出、诊断与未测；不要用理论预期代替本轮运行。
