# 13.3.2 Vite插件最小闭环：虚拟模块、构建钩子与公开Manifest：操作卡

## 类型与准备

真实本地构建/Node/浏览器型。在本组[build-lab](./build-lab/README.md)按固定Node/pnpm安装；输出仅dist/artifacts，端口4553 loopback。

~~~bash
pnpm build
pnpm test
pnpm verify
~~~

## 操作与预期

真实build-lab/plugin.mjs精确处理virtual:build-info，只把允许格式的公开label用JSON.stringify变成模块；generateBundle emitFile写build-audit.json。Vite另输出.vite/manifest.json，两个manifest职责不同。390/1440浏览器读到build-lab-v1、实际请求audit/内建manifest200，键盘计数可用。

插件运行在构建机权限下，不可随意读取凭据/把process.env全部注入浏览器。此例返回新虚拟常量，无原始源码映射需要保留；改写真实TS/CSS的插件应提供正确map、限制id并考虑SSR/client差异。没有实现Webpack loader/plugin，二者扩展点不能直接复制接口。

记录输入、实际输出、诊断与未测；不要用理论预期代替本轮运行。
