# 13.4.6 CSS @supports与JS能力检查：各管各层，保留默认样式：操作卡

类型：本地compat-lab实际观察，legacy插件/其他引擎等未运行部分明确列出。Node26/pnpm11，Chrome现有安装；在[lab目录](./compat-lab/README.md)冻结安装后执行：

~~~bash
pnpm test
pnpm build
pnpm verify
~~~

## 操作与预期

lab默认.layout display:block，在@supports(display:grid)下改grid；当前Chrome真实CSS.supports为true且computed display=grid，非法值为false。print媒体覆盖回block；另把supports条件替成非法值的隔离CSS配置，真实观察默认block仍无溢出。说明条件/级联都参与最终样式，不能只读一个supports结果推断实际效果。

## 限制与排查

支持某CSS语法不保证特定结构无bug、可读或不溢出；包含布局、RTL、缩放、颜色与输入状态仍要验证。本轮未让真实旧引擎执行不支持grid路径，默认CSS规则与原理审阅不冒称该环境实测。

不得以UA伪装/能力注入/模拟视口推导真实旧浏览器或手机通过。
