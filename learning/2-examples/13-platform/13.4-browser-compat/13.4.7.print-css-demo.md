# 13.4.7 Print CSS：打印媒体、折叠内容与PDF边界：操作卡

类型：本地compat-lab实际观察，legacy插件/其他引擎等未运行部分明确列出。Node26/pnpm11，Chrome现有安装；在[lab目录](./compat-lab/README.md)冻结安装后执行：

~~~bash
pnpm test
pnpm build
pnpm verify
~~~

## 操作与预期

lab真实emulateMedia(print)断言header/按钮隐藏、print-only正文副本出现、布局变block，并生成headless A4 PDF检查头和字节。已查看390打印媒体截图，正文完整无截断。闭合details内容不依赖一个display:block就保证打印，因此用明确print-only文字保留必要说明。

## 限制与排查

PDF头/文件存在不能证明每页分页和全文语义都正确；本轮截图检查与media computed是有限证据，未做物理打印/系统打印对话框、复杂长表或机密导出。静态副本需与正文同步；真实项目更适合共享数据生成专用打印视图。

不得以UA伪装/能力注入/模拟视口推导真实旧浏览器或手机通过。
