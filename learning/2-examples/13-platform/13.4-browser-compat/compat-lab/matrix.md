# 支持矩阵模板与本轮证据

日期2026-11-25；目标策略、实际运行与模拟需要分栏。下表是教学记录，不替所有产品承诺。

| 环境/能力                            | 支持决策             | 本轮证据                             | 尚缺                          |
| ------------------------------------ | -------------------- | ------------------------------------ | ----------------------------- |
| 本机Chrome158，390/1440              | 实验支持             | native/注入fallback/失败、CSS/无溢出 | 真机/其他版本                 |
| 当前Chrome禁JS                       | 阅读/原生details基线 | javascriptEnabled:false实际操作      | 完整业务表单/后台流程         |
| 当前Chrome伪装UA                     | 仅能力判断对照       | 仍走native                           | 不是旧浏览器                  |
| 当前Chrome注入API缺失                | 仅回退分支验证       | 本地模块请求/结果/失败               | 真正缺失实现的引擎解析与运行  |
| Safari/iOS、Firefox、Android WebView | 产品按需求选择目标   | 本轮未运行                           | 版本/设备/输入/权限/辅助技术  |
| Print媒体/headless PDF               | 有限导出检查         | computed/截图/PDF头与大小            | 长表分页、物理打印/系统对话框 |

.browserslistrc是显式query教学：Chrome>=111/Safari>=16.4被解析，不等于这两类浏览器都通过。若实际产品选Baseline Widely available或固定年，需核日期、工具消费链、产品用户及适用回退，再写目标矩阵。

变更流程：提出目标→确认用户/风险→实现原生/回退→专项验证→记录负责人/日期→对停止支持通知与回退。未验不自动绿色，UA/project命名/viewport都不能替代实测。
