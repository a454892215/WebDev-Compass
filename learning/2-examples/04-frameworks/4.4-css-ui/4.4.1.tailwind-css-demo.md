# 4.4.1 实验：Tailwind CSS 4：真实工具类构建与响应式前缀

类型：真实Tailwind CLI构建 + 本地静态页面/后台Chrome；四点共享theme-lab。

## 运行条件

在本章`theme-lab/`目录执行：

```bash
pnpm install --frozen-lockfile
pnpm build
pnpm preview
# 另一个终端：pnpm verify
```

预览仅 http://127.0.0.1:4306 。verify自动启停自己的服务器，运行前关闭手动preview。固定Node/pnpm条件见[实验README](./theme-lab/README.md)，需要已有Chrome或按Playwright官方方式准备浏览器。

## 关键源码

- [src/theme.css](./theme-lab/src/theme.css)
- [src/index.html](./theme-lab/src/index.html)
- [build.mjs](./theme-lab/build.mjs)

## 操作与真实预期

1. 在theme-lab执行冻结安装与pnpm build，查看真实dist/theme.css；源码CSS不是可直接当成已编译产物的证明。
2. 运行pnpm preview，在390px和1440px观察同一grid从一列变两列；查看computed样式和md规则。
3. 在副本新增一个完整工具类再构建，比较产物；动态拼接类失败时用静态映射修正。

## 验收

- [ ] 实际构建生成grid与md断点规则，HTML引用的是本地编译CSS。
- [ ] 390与1440宽度分别一列/两列，无横向溢出；能解释移动优先。

## 故障对照

把完整text-brand改成运行时拼接的类名，清理dist重建后定位未生成的规则；修复为完整类名映射，再核对产物和computed样式。

## 范围说明

构建成功不保证设计一致、可访问性或所有浏览器支持。v4依赖较现代浏览器能力，兼容要求应查官方Compatibility并按项目目标决定；不把本机Chrome通过当全平台认证。样式引擎与业务组件库是不同层，Nuxt UI/Vant不要求一起装。
