# 4.4.3 实验：本地SVG图标：装饰、名称与外部资源边界

类型：真实Tailwind CLI构建 + 本地静态页面/后台Chrome；四点共享theme-lab。

## 运行条件

在本章`theme-lab/`目录执行：

```bash
pnpm install --frozen-lockfile
pnpm build
pnpm preview
# 另一个终端：pnpm verify
```

预览仅 http://127.0.0.1:4306 。verify自动启停自己的服务器，运行前关闭手动preview。固定Node/pnpm条件见[实验README](./theme-lab/README.md)，需要已有Chrome或按Playwright官方方式准备浏览器。

## 关键源码

- [src/index.html](./theme-lab/src/index.html)
- [src/info.svg](./theme-lab/src/info.svg)

## 操作与真实预期

1. 查看收藏按钮中aria-hidden图标与文字，按钮可按“收藏卡片”定位。
2. 查看纯图标按钮的aria-label和img空alt，再查看独立role=img及title关系。
3. 离线观察两个SVG都是本地资源；深色模式核对内联和外部图标都有可辨识对比。

## 验收

- [ ] 装饰图标不重复命名，纯图标动作仍有明确按钮名称。
- [ ] 独立信息图标有名称，图标加载失败时关键按钮含义不丢失。

## 故障对照

移除纯图标按钮aria-label后观察它失去动作名称；恢复名称，而不是仅给SVG添加“图标”这样的无意义描述。

## 范围说明

Lucide/Heroicons是可选图标资源，不是无障碍机制；本实验使用自有本地SVG，没有安装或验证这两套库。外部不可信SVG不能未经审查作为HTML注入，v-html不是图标消毒器。SVG标题id在重复组件内应避免冲突。
