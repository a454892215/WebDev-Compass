# 4.2.3.3 示例：Redux Toolkit：slice、异步action与中间件

类型：真实React/生态机制实验；不是伪终端。

## 运行条件与步骤

先读[共享实验说明](./react-lab/README.md)，在react-lab安装锁定依赖。Node26.0.0、pnpm11.4.0；没有全局安装。

```bash
# 从仓库根目录进入
cd learning/2-examples/04-frameworks/4.2-react/react-lab
pnpm install --frozen-lockfile
pnpm exec vitest run -t "4.2.3.3"
```

stores.ts真实configureStore/createSlice/createAsyncThunk；测试成功与fixture失败、unwrap拒绝以及最终状态。未接真实HTTP或react-redux Provider。

完整源码：[Core.tsx](./react-lab/src/Core.tsx)、[路由](./react-lab/src/RoutesDemo.tsx)、[数据工具](./react-lab/src/stores.ts)、[表单](./react-lab/src/FormDemo.tsx)、[编号测试](./react-lab/tests/mechanisms.test.tsx)。

## 预期与对照

- 成功与拒绝路径分别可验证，loading最终结束。
- 调用端正确处理unwrap拒绝，不把rejected action当业务成功。

先预测，再运行并解释差异。在自己的副本重现：await dispatch后直接提示成功而没有检查拒绝；改unwrap+catch，用fail:true证明不再误报。

jsdom验证组件契约，不是布局/真机认证；纯工具测试不冒充React整页集成。
