# 4.2.1.11 示例：错误边界：渲染失败的局部回退

类型：真实React/生态机制实验；不是伪终端。

## 运行条件与步骤

先读[共享实验说明](./react-lab/README.md)，在react-lab安装锁定依赖。Node26.0.0、pnpm11.4.0；没有全局安装。

```bash
# 从仓库根目录进入
cd learning/2-examples/04-frameworks/4.2-react/react-lab
pnpm install --frozen-lockfile
pnpm exec vitest run -t "4.2.1.11"
```

RenderBoundary包裹受控BrokenCard并真实显示alert；测试只为该预期故障屏蔽console.error，其他测试仍正常报告错误。

完整源码：[Core.tsx](./react-lab/src/Core.tsx)、[路由](./react-lab/src/RoutesDemo.tsx)、[数据工具](./react-lab/src/stores.ts)、[表单](./react-lab/src/FormDemo.tsx)、[编号测试](./react-lab/tests/mechanisms.test.tsx)。

## 预期与对照

- 受控子组件渲染失败时其他页面区域可用。
- 事件/异步失败有自己的处理，不假设边界兜底。

先预测，再运行并解释差异。在自己的副本重现：在按钮onClick里抛错并期待边界接管；改为事件处理中的失败状态/try-catch，并说明捕获范围。

jsdom验证组件契约，不是布局/真机认证；纯工具测试不冒充React整页集成。
