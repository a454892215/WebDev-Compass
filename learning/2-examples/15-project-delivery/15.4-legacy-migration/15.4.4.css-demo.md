# 15.4.4 遗留 CSS：命名范围、层叠与可达性：运行与观察

类型：真实本地Nuxt/旧MPA切片或受限AST实验，生产决策另需自己的证据。先读[理论](../../../1-notes/15-project-delivery/15.4-legacy-migration/15.4.4.css.md)。

## 运行条件与入口

从[实践目录](../../../4-practice/15-project-delivery/README.md)执行pnpm install --frozen-lockfile、pnpm check、pnpm test:e2e；交互用pnpm dev，固定127.0.0.1:4571。旧页面、Nuxt和API都在同一Node教学服务，合成只读数据，没有真实账号/写入/云切流。codemod单独pnpm test:migration。

## 操作与可核对预期

打开/comparison，核对旧按钮rgb(117,68,0)、新按钮rgb(0,93,168)，再缩窄视口并用Tab看焦点。阅读SFC scoped与旧MPA stylesheet的文档边界。

先预测，再读tests/unit/migration.test.ts、tests/e2e和migration/codemod/verify.mjs里的具体断言；脚本成功不代表任意旧系统迁移完成。

## 独立变体与排错

在隔离副本新增一个旧button全局背景故障，先用Computed定位，再收窄为旧范围；另写普通声明与!important的层叠判断说明。

故障：把旧规则改为button { background: ... !important }会覆盖新按钮。记录获胜规则与来源，修复命名范围并移除不必要important；不能只给新版再叠更强important。

计算样式证明两个按钮保持各自颜色，窄屏无溢出且焦点可见。；能解释scoped不阻止所有外部样式/继承，层叠上下文与z-index边界明确。 未实际执行的变体不得填写已验证。
