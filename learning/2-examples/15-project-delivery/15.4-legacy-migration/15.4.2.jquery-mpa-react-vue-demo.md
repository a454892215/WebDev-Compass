# 15.4.2 旧 MPA / jQuery 到 Vue 3：DOM所有权与兼容窗口：运行与观察

类型：真实本地Nuxt/旧MPA切片或受限AST实验，生产决策另需自己的证据。先读[理论](../../../1-notes/15-project-delivery/15.4-legacy-migration/15.4.2.jquery-mpa-react-vue.md)。

## 运行条件与入口

从[实践目录](../../../4-practice/15-project-delivery/README.md)执行pnpm install --frozen-lockfile、pnpm check、pnpm test:e2e；交互用pnpm dev，固定127.0.0.1:4571。旧页面、Nuxt和API都在同一Node教学服务，合成只读数据，没有真实账号/写入/云切流。codemod单独pnpm test:migration。

## 操作与可核对预期

对照旧GET表单与新catalog.vue：过滤、空结果、详情路径与错误退回。确认初始加载不抢焦点，路径切换后标题获焦，搜索更新不强移焦。

先预测，再读tests/unit/migration.test.ts、tests/e2e和migration/codemod/verify.mjs里的具体断言；脚本成功不代表任意旧系统迁移完成。

## 独立变体与排错

写一个旧插件清理清单，并在隔离副本用有界原生事件订阅模拟挂载/卸载两轮，证明一次操作只触发一次；不额外安装全局jQuery。

故障：把旧全局click监听每次挂载都add却不remove，两轮后一次点击执行两次。用计数和监听引用定位，再在卸载时移除同一函数引用；once不等于完整生命周期管理。

新旧渲染器不争用同一DOM，挂载两轮后无重复事件。；URL、过滤、深链和关键键盘行为有证据；本例未实际运行jQuery的边界写清。 未实际执行的变体不得填写已验证。
