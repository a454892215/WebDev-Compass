# 15.4.3 只读双跑、稳定分组与可执行回退：运行与观察

类型：真实本地Nuxt/旧MPA切片或受限AST实验，生产决策另需自己的证据。先读[理论](../../../1-notes/15-project-delivery/15.4-legacy-migration/15.4.3.parallel-run.md)。

## 运行条件与入口

从[实践目录](../../../4-practice/15-project-delivery/README.md)执行pnpm install --frozen-lockfile、pnpm check、pnpm test:e2e；交互用pnpm dev，固定127.0.0.1:4571。旧页面、Nuxt和API都在同一Node教学服务，合成只读数据，没有真实账号/写入/云切流。codemod单独pnpm test:migration。

## 操作与可核对预期

运行/api/shadow与?mismatch=1，看到一致和p1 changed；请求/entry的0/99/rollback输入核对302和固定Location，q保留。

先预测，再读tests/unit/migration.test.ts、tests/e2e和migration/codemod/verify.mjs里的具体断言；脚本成功不代表任意旧系统迁移完成。

## 独立变体与排错

给只读比较增加新增/删除商品差异，并把百分比边界改为25做0/24/25/99测试；给生产开关写负责人、到期和回退触发条件。

故障：仅比较数组长度会漏掉p1差1分钱。先注入mismatch=1观察旧比较错误通过，再恢复按id/公开语义比较；不能让新旧共享同一已损坏适配结果后自我证明一致。

新增、缺失、内容变化均识别，差异记录只含允许的公开字段。；分流边界和退回旧入口实际通过，不双写、不将请求级fixture当生产开关或授权。 未实际执行的变体不得填写已验证。
