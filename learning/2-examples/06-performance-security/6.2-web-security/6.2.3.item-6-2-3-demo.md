# 6.2.3 实验：点击劫持：frame-ancestors与嵌入需求

类型：真实本地安全/国际化共享工程；6.2.7另有明确平台对照，6.4.2的Nuxt SSR由主工程单独验证。

## 运行与操作

先读[lab README](./security-i18n-lab/README.md)，执行固定锁安装、pnpm check和pnpm verify:browser。HTTP只在4503/4504；不要用file://或外网站点执行攻击输入。

4504同时嵌入4503的allowed-frame与protected。允许页能postMessage确认加载，protected被浏览器frame-ancestors拒绝且未执行其脚本，HTTP头另行核实。

## 具体源码

security-entry.js、server.mjs、verify-browser.mjs；map/依赖另看check-artifacts.mjs和audit快照。每项真实预期由脚本或说明对应，不把一个总分当全部正确。

## 综合关联与限制

核对Nuxt主响应的frame-ancestors子策略，并在独立lab用真实父iframe检验拒绝/允许对照；主目录不需要第三方嵌入。

[主Nuxt工程](../../../4-practice/06-performance-security/README.md)。本独立lab无真实账号、密码或第三方凭据；当前Chrome/Node与固定依赖实测不等于真机/跨浏览器/生产安全/翻译质量认证。
