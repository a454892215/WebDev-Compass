## 操作与预期

Nuxt原始HTML和客户端详情切换核对title/description，canonical以https://compass.example为保留域名占位且无q，hreflang覆盖三语与x-default；不外网请求占位域名。

先预测再执行，保留命令/状态/DOM或源码片段和实际差异；不要只记录通过。

## 分别检查SSR、查询和路由切换

```bash
curl --fail-with-body --silent --show-error \
  'http://127.0.0.1:4500/zh-CN?q=Vue' -o /tmp/stage6-search.html
```

在保存的HTML中核对`title`、`meta[name=description]`、`link[rel=canonical]`、`link[rel=alternate][hreflang]`和`meta[name=robots]`。查询页为noindex,follow；canonical不带q，且origin为可信配置的保留域名。再从首页点击真实课程链接，在不刷新页面的情况下检查head同步更新；把当前locale切换为en/ar后，canonical应自指新语言，而hreflang保留互返三语和x-default。
