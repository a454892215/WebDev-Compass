# 6.3.1 操作卡：WCAG 2.2：等级、范围与验收证据

类型：真实本地HTML/axe/键盘实验，含明确人工未测边界。

## 运行条件与文件

在本组a11y-lab执行pnpm install --frozen-lockfile，再pnpm verify；脚本自建4505服务并在finally关闭，使用本机后台Chrome和本实验固定的Playwright工具。可用PLAYWRIGHT_MODULE/CHROME_PATH覆盖路径。

`a11y-lab/index.html、main.js、style.css、bad.html与verify.mjs`。

## 操作与预期

独立lab正确页面axe零违规，坏样本仍报button-name/image-alt/label；比较两类结果，说明“零检测”不等于所有准则已审。

先预测再执行，保留命令/状态/DOM或源码片段和实际差异；不要只记录通过。

## 证据与限制

本组运行见docs/audits/stage-6-a11y-lab-runtime.json：正确页两视口扫描和交互、320CSSpx与根字号200%、受控坏样本。CSS文字缩放不是浏览器zoom；AX/DOM不是屏幕阅读器，未称完整WCAG符合。
