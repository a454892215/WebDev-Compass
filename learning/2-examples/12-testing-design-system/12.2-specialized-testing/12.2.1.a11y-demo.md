# 12.2.1 操作卡：无障碍验收：自动规则、键盘行为与辅助技术分层

## 类型与运行条件

本地真实构建/后台Chrome专项型；未测读屏/多引擎/真机单列。 Node26.0.0/pnpm11.4.0，在specialized-lab执行：

~~~bash
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm verify
~~~

[实验说明](./specialized-lab/README.md)。本地4543，只用合成数据；后台Chrome不抢前台，结束自动关闭。

## 操作与真实预期

specialized-lab先扫正常页面，取消label的for后只跑label规则，必须出现label违规；恢复关联再次零违规。键盘单独验证跳到正文、原生dialog打开后焦点、Esc关闭与回到触发按钮。这些是实际浏览器行为，不能用jsdom里手工赋focus假装跨浏览器行为。

## 观察记录与边界

保存输入/状态/输出/修复，不只截图。本轮只有后台Chrome与模拟宽窄视口，没有屏幕阅读器或残障用户试学；不能写VoiceOver/JAWS/NVDA通过。读屏清单应具体到浏览器/AT版本、导航方式、名称/角色/状态、错误宣读和恢复位置。不要为消除axe红灯给无行为div机械加role。
