# 12.2.3 操作卡：国际化测试：文本扩展、RTL与混合方向标识

## 类型与运行条件

本地真实构建/后台Chrome专项型；未测读屏/多引擎/真机单列。 Node26.0.0/pnpm11.4.0，在specialized-lab执行：

~~~bash
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm verify
~~~

[实验说明](./specialized-lab/README.md)。本地4543，只用合成数据；后台Chrome不抢前台，结束自动关闭。

## 操作与真实预期

lab切换中文、en-XA伪本地化与阿拉伯文fixture。html lang/dir随选择改变，description与按钮扩展后必须无横溢出；RTL下ORDER-123通过bdi dir=ltr保持标识方向，布局用inline/block逻辑属性。保存pseudo/RTL截图供人工观察，但不把当前截图当已审批视觉基线。

## 观察记录与边界

保存输入/状态/输出/修复，不只截图。本lab只验证小型布局/方向与长文本，没有完整翻译、日期/复数库或真实母语审校。中文导航仍是教学支架，不是全站阿拉伯语本地化。截图属于当前运行观察；自动语言切换成功不等于翻译准确或读屏语言正确。
