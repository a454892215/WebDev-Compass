# 小型测试策略示例

这是本lab实际证据的约定，不代表所有项目需要固定比例或工具全集。

| 风险                                 | 本地证据                                         | 失败退出条件                                 | 责任/未测                             |
| ------------------------------------ | ------------------------------------------------ | -------------------------------------------- | ------------------------------------- |
| R-contract：提供者字段变更破坏消费者 | core.test.mjs decoder负例、真实本地provider HTTP | 类型/状态不符则失败                          | lab作者；Pact/Broker未跑              |
| R-boundary：零库存仍可预约           | 原实现/手工>=0变体与弱/强断言                    | 合法变体必须被具体AssertionError发现         | lab作者；无Stryker score              |
| R-visual：可见padding变化被遗漏      | 固定环境只读PNG比较与变化检测                    | 未审变化不匹配即失败，不能自动更新           | 作者本轮目视，不是SaaS/真实学习者审批 |
| R-async：结果未到就断言              | 实际80ms状态变化，expect自动重试                 | 业务目标不到时有界超时                       | 无固定sleep、无长期flaky发生率        |
| R-isolation：并行测试共享Cookie      | 两shard各2workers、每test请求context             | A/B读回不符即失败                            | 同机顺序跑两片，未多机CI/容器         |
| R-SSR：空壳/接管重复请求/凭据串扰    | 主Nuxt专项，读主README与实际tests                | 内容、网络范围、双fixture与凭据/缓存各有断言 | 本静态lab不提供SSR证据                |

coverage预期：本轮不采集line/branch数字；对声明风险用具体正反断言验证，不用80%替代缺失的SSR或键盘证据。新增风险先补计划/owner/最小证据，不机械扩大整套E2E。

失败保留首次日志、输入、运行版本/viewport和产物；重试与首次失败分列。quarantine必须有owner、期限和替代关键覆盖；不能以“重试绿了”关闭产品问题。所有fixture为合成，不带真实账号/Token。
