# 12.3.4 操作卡：Vue组件API：原生语义、属性事件和slot组合

## 运行条件与类型

本地真实SDK/构建/浏览器与明确官方观察。Node26.0.0/pnpm11.4.0；按[storybook-lab说明](./storybook-lab/README.md)冻结安装，再依次tokens/test/build/verify；仅loopback4544，未接Figma/SaaS账号。

## 操作与真实预期

共享UiButton的variant是primary/secondary，disabled/type有默认值，default slot提供可见名称，单原生button根节点承接class/aria属性及原生click。故事Primary验证type=button与点击，Disabled验证不能激活。slot不是任意HTML字符串；本例不使用v-html。

先保存输入/预期，再记录产物或浏览器输出。包分发、SSR和远程平台能力按各自范围另验。

## 排查与限制

Vue透传属性与显式emits会影响监听器落点，多根组件需明确绑定位置。不能把link与button混成靠颜色区分的万能组件；导航用a/NuxtLink。Compound组件适合确实共享上下文的结构，不要只因术语时髦拆出十个子组件；受控/非受控模式、focus与错误状态要写清。
