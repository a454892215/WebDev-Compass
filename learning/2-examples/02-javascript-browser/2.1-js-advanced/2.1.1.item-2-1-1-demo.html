多个对象需要共享方法，如何解释一个对象上不存在却可以读取的属性？

const shared = { kind: "article" };
const item = Object.create(shared);
item.title = "原型实验";
console.log(item.kind, Object.hasOwn(item, "kind")); // article false
item.kind = "draft";

delete item.kind;
