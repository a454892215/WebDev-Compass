2.1.2 this：由调用方式决定的接收者

同一方法通过对象调用正常，传给回调后却读不到状态，原因在哪里？

先预测，再运行。结果来自当前浏览器；不代表其他平台实测。

尚未运行。

运行后在此显示真实结果。
本点最小代码（完整实验实现见源码）
const counter = { value: 2, add(n) { return this.value + n; } };
console.log(counter.add(3)); // 5
const detached = counter.add;
console.log(detached.call({ value: 10 }, 3)); // 13
const bound = detached.bind(counter);
console.log(bound(4)); // 6
function makeReader() { return () => this.value; }
const read = makeReader.call(counter);
console.log(read.call({ value: 99 })); // 2
