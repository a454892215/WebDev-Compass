# 8.2.3 独立练习：容器与展示组件：按变化原因分职责

先阅读理论与操作卡，再关闭参考在隔离副本完成。新增能力明确为练习，不虚构原项目已有功能。

## 动手任务

把一个课程卡独立展示，增加空标题回退与select事件，不读取全局路由或直接写父对象。

## 验收标准

- [ ] 组件可用固定props展示并键盘触发意图，父层决定实际状态改变。
- [ ] 加载/空/错仍在容器有明确表达，不因拆组件消失。

## 排错任务

故障：子卡直接改course.selected并发起请求，父层失去一致更新入口；改为emit意图，由容器处理并覆盖失败状态。

## 参考要点

按实际变更边界拆，不以文件数衡量架构；可读的小组件保留局部状态是合理的。

保留修改/输入/实际响应或观察/原因/修复证据。未真实安装的工具用明确官方观察与设计产出，不报告虚假部署成功。
