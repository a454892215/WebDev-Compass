# 8.2.5 独立练习：配置驱动UI：受限schema、解释器与安全边界

先阅读理论与操作卡，再关闭参考在隔离副本完成。新增能力明确为练习，不虚构原项目已有功能。

## 动手任务

新增required布尔字段及最多三个控件的业务限制，先验证后渲染；为未知版本做可读错误。

## 验收标准

- [ ] 类型、长度、未知属性和非法节点在DOM变化前拒绝。
- [ ] label关联正确，文本不变成HTML，错误不只靠颜色。

## 排错任务

故障：直接把配置label写innerHTML或执行onClick字符串；用同一恶意输入复现后改textContent与显式事件白名单。

## 参考要点

Schema约束不是安全沙箱；服务端还要核对调用者权限/数据规则，超复杂配置可能比普通组件更难维护。

保留修改/输入/实际响应或观察/原因/修复证据。未真实安装的工具用明确官方观察与设计产出，不报告虚假部署成功。
