# 9.1.4 Performance API：时间原点、缓冲区与跨源限制：独立练习

前置：读理论与操作卡，先独立尝试再对照。全部变体在副本及合成数据上执行，不制造真实用户隐私风险。

## 动手任务

在副本分别记录冷资源和再次加载的条目，说明哪些是观测、哪些缓存推断；模拟不支持longtask的分支。

## 验收标准

- [ ] supportedEntryTypes与条目存在性明确，unsupported不假装计时0。
- [ ] 不将startTime当UNIX时间，Observer与记录有上限/销毁，跨源字段限制有说明。

## 排错任务

故障：从getEntriesByType一次快照推断整个长会话，或把0 transferSize断言必命中缓存。改Observer并记录头/请求上下文，保留不确定性。

## 参考要点

工具用于定位，不按一个字段推断因果；原始entry.name通常含URL，上传前必须最小化。

保留自己的输入/命令/实际结果/原因与恢复；未运行的工具或环境列为观察，不改写为已通过。
