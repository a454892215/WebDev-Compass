# 9.3.3 图片管线：真实候选、占位与CDN变换契约：独立练习

前置理论与操作卡。先在副本独立完成，不对真实用户或生产缓存制造错误。

## 动手任务

给副本增加一个更宽容器与DPR2场景，按实际布局改sizes并补合适候选；若设计CDN变换，仅允许固定尺寸/格式集合，不接任意远程源URL。

## 验收标准

- [ ] currentSrc属于真实存在且可解码候选，尺寸比例/占位稳定，alt对应实际内容。
- [ ] 首屏候选不lazy，不将测试几何图的字节优势直接套所有业务素材。

## 排错任务

故障：CSS把图片限制640px，sizes却写100vw且无上限，宽屏选择过大资源。记录容器宽度与currentSrc，修正sizes后对照；不要靠删除所有大图掩盖DPR需求。

## 参考要点

按视觉质量、解码、传输与缓存综合测量，不盲目一律转同一格式。

保存改动、命令、原始输出、解释和恢复；未做公网或格式回退测试时如实标注，不能由一次资源200推断已掌握。
