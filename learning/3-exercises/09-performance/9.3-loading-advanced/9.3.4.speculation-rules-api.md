# 9.3.4 推测加载：预取、预渲染与无副作用边界：独立练习

前置理论与操作卡。先在副本独立完成，不对真实用户或生产缓存制造错误。

## 动手任务

在副本把候选从全部链接改成有限公开内容白名单；为Save-Data/不支持与未命中设计正常导航，说明激活前哪些业务动作必须延后。

## 验收标准

- [ ] 规则不含账号/支付/退出/带秘密查询URL，普通链接无建议时仍可用。
- [ ] 分别记录支持、建议发出、实际网络行为和激活，不能把第一项当最后一项。

## 排错任务

故障：用所有a.href生成prerender列表，退出GET或计数脚本被提前运行。只在合成副本审查与复现；删副作用候选，后台控制台检查，不在真实账户上试错。

## 参考要点

把节省等待与额外网络/内存/隐私成本一起纳入预算，不以“API存在”默认全站开启。

保存改动、命令、原始输出、解释和恢复；未做公网或格式回退测试时如实标注，不能由一次资源200推断已掌握。
