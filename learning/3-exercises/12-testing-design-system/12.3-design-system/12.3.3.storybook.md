# 12.3.3 独立练习：Storybook Vue3：真实组件状态、交互play与文档基线

先读理论与操作卡，再在隔离副本改动，不能修改真实设计项目或发布账号。

## 动手任务

为Secondary增加长中文label与只读说明story，写一个键盘Space激活的play，说明native disabled为何不应收到click。

## 验收标准

- [ ] Story引用真实UiButton API，play使用角色/名称和可观察行为，不以query内部Vue实现为主。
- [ ] 保存一项独立失败→修复记录；注明截图本地/源码展示与主dist消费、平台视觉回归的区别。

## 排错任务

在隔离副本给Primary传type=submit并保留其type=button期望，play应失败；确认测试揭示的是契约变化，决定修输入还是正式改API，不能只删除断言。

## 参考要点

Story是一个明确的组件状态，不是整站截图列表。CSF的meta/component、args、render与play分别描述组件、输入、上下文和用户行为；同一个公开API应覆盖默认、禁用、边界内容和关键状态。Storybook隔离环境便于讨论与复现，但不能替代真实Nuxt SSR/路由/服务端授权测试。

本例用源SFC便于组件文档，不等于验证打包后的exports/peer/runtime；真实dist消费由主项目单独验证。视觉基线要记录字体/浏览器/viewport并人工审批差异，不能自动更新让测试变绿。没有Chromatic账户、未上传SaaS。配置core.disableTelemetry且命令设STORYBOOK_DISABLE_TELEMETRY=true，避免配置读取前boot事件。
