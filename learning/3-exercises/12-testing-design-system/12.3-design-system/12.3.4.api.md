# 12.3.4 独立练习：Vue组件API：原生语义、属性事件和slot组合

先读理论与操作卡，再在隔离副本改动，不能修改真实设计项目或发布账号。

## 动手任务

在隔离副本为UiButton补一项loading需求：明确是禁用、保持可聚焦还是只显示状态；先写API/事件和a11y行为表，再实现最小变体。

## 验收标准

- [ ] 调用方式能解释状态优先级、原生type/disabled与可访问名称，不能只有视觉spinner。
- [ ] 保留原variant与slot调用；若必须改变行为，记录兼容/迁移而不是隐式改默认。

## 排错任务

把根节点换为div并保留click，鼠标可能还能触发而Space/Enter/type/disabled契约失效。用真实键盘和角色断言定位，再恢复原生button；不要用补role而不补完整行为应付。

## 参考要点

先写调用方需要完成的任务，再设计最小稳定API。prop承载有限状态与数据，event表达意图，slot容纳内容组合；不要用几十个布尔值组合出无法定义的状态。封装button应保留type、disabled、可访问名称和键盘语义；默认type=button避免放入表单时意外提交。

Vue透传属性与显式emits会影响监听器落点，多根组件需明确绑定位置。不能把link与button混成靠颜色区分的万能组件；导航用a/NuxtLink。Compound组件适合确实共享上下文的结构，不要只因术语时髦拆出十个子组件；受控/非受控模式、focus与错误状态要写清。
