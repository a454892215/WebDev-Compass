# 15.2.4 渐进重构：先保行为，再做有界改进：独立练习

先读理论和操作卡，在隔离副本完成；先预测、再修改/执行、最后保存输入与证据，不只复制成功输出。

## 动手任务

在副本给两条合法路径提取一个重复的公开DTO投影，先加特征测试再小步替换；另列一个想改但本次不处理的相邻问题及原因。

## 验收标准

- [ ] 前后公开字段、值及错误行为在声明输入域内一致，故意改一字段的负例能失败。
- [ ] 说明提取实际收益和停止边界；输入契约改变另记行为变更，受影响UI/SSR按需补验。

## 排错任务

把multiplyCents改为quantity*unitCents+1，12组前后比较应失败；核对差异而不是更新旧期望。恢复同值后通过。若确需新舍入策略，另开有契约和迁移说明的行为修改。

保存失败输入、实际现象、定位依据、修复及同输入复验；静态推演与真实执行分开标注。

## 参考要点

先绿测试和定义可观察边界，再改结构；特征测试不是保留Bug的命令。重构与新行为分开说明，但每片都包含相关测试。
