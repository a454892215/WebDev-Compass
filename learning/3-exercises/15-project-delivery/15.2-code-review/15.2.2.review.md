# 15.2.2 评审规模与LGTM：完整的小改动，不是行数竞赛：独立练习

先读理论和操作卡，在隔离副本完成；先预测、再修改/执行、最后保存输入与证据，不只复制成功输出。

## 动手任务

将“提取计算+校验输入+切换文案”拆成能说明兼容性与测试归属的切片，为每片列目的、依赖、检查和回退；在清单测试新增localize并验证漏项被拒绝。

## 验收标准

- [ ] 每片包含相关测试和可理解上下文，契约变化/特征重构分别标清，不能先部署不兼容的一半。
- [ ] 缺localize或依赖逆序会被脚本拒绝；人的LGTM声明范围与未测，不用行数作为唯一依据。

## 排错任务

把validate切片放在extract前面，validateSlices返回false；核depends和实际计划顺序，修复排序。若只是删depends让脚本变绿，却未解释真实依赖，仍不满足评审。

保存失败输入、实际现象、定位依据、修复及同输入复验；静态推演与真实执行分开标注。

## 参考要点

先定义独立行为目的，再确认前后提交均可用。脚本检查集合/顺序不等于语义正确，不能用一条LGTM跳过阻断项。
