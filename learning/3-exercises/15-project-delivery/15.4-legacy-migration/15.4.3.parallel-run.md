# 15.4.3 只读双跑、稳定分组与可执行回退：独立练习

先读[理论](../../../1-notes/15-project-delivery/15.4-legacy-migration/15.4.3.parallel-run.md)和[操作卡](../../../2-examples/15-project-delivery/15.4-legacy-migration/15.4.3.parallel-run-demo.md)，在隔离副本操作。

## 动手任务

给只读比较增加新增/删除商品差异，并把百分比边界改为25做0/24/25/99测试；给生产开关写负责人、到期和回退触发条件。

## 验收标准

- [ ] 新增、缺失、内容变化均识别，差异记录只含允许的公开字段。
- [ ] 分流边界和退回旧入口实际通过，不双写、不将请求级fixture当生产开关或授权。

## 排错任务

仅比较数组长度会漏掉p1差1分钱。先注入mismatch=1观察旧比较错误通过，再恢复按id/公开语义比较；不能让新旧共享同一已损坏适配结果后自我证明一致。

保存失败输入、状态/输出、定位和修复后证据；不删除断言或修改预期掩盖问题。

## 参考要点

运行/api/shadow与?mismatch=1，看到一致和p1 changed；请求/entry的0/99/rollback输入核对302和固定Location，q保留。 区分现有教学源码、学习者新增与生产待验。只读模型成立的结论不能直接推到写数据/多实例/真实用户。
