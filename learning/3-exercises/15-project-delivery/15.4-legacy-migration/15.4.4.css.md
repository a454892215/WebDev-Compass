# 15.4.4 遗留 CSS：命名范围、层叠与可达性：独立练习

先读[理论](../../../1-notes/15-project-delivery/15.4-legacy-migration/15.4.4.css.md)和[操作卡](../../../2-examples/15-project-delivery/15.4-legacy-migration/15.4.4.css-demo.md)，在隔离副本操作。

## 动手任务

在隔离副本新增一个旧button全局背景故障，先用Computed定位，再收窄为旧范围；另写普通声明与!important的层叠判断说明。

## 验收标准

- [ ] 计算样式证明两个按钮保持各自颜色，窄屏无溢出且焦点可见。
- [ ] 能解释scoped不阻止所有外部样式/继承，层叠上下文与z-index边界明确。

## 排错任务

把旧规则改为button { background: ... !important }会覆盖新按钮。记录获胜规则与来源，修复命名范围并移除不必要important；不能只给新版再叠更强important。

保存失败输入、状态/输出、定位和修复后证据；不删除断言或修改预期掩盖问题。

## 参考要点

打开/comparison，核对旧按钮rgb(117,68,0)、新按钮rgb(0,93,168)，再缩窄视口并用Tab看焦点。阅读SFC scoped与旧MPA stylesheet的文档边界。 区分现有教学源码、学习者新增与生产待验。只读模型成立的结论不能直接推到写数据/多实例/真实用户。
