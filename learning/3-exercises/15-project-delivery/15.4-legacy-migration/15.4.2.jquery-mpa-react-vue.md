# 15.4.2 旧 MPA / jQuery 到 Vue 3：DOM所有权与兼容窗口：独立练习

先读[理论](../../../1-notes/15-project-delivery/15.4-legacy-migration/15.4.2.jquery-mpa-react-vue.md)和[操作卡](../../../2-examples/15-project-delivery/15.4-legacy-migration/15.4.2.jquery-mpa-react-vue-demo.md)，在隔离副本操作。

## 动手任务

写一个旧插件清理清单，并在隔离副本用有界原生事件订阅模拟挂载/卸载两轮，证明一次操作只触发一次；不额外安装全局jQuery。

## 验收标准

- [ ] 新旧渲染器不争用同一DOM，挂载两轮后无重复事件。
- [ ] URL、过滤、深链和关键键盘行为有证据；本例未实际运行jQuery的边界写清。

## 排错任务

把旧全局click监听每次挂载都add却不remove，两轮后一次点击执行两次。用计数和监听引用定位，再在卸载时移除同一函数引用；once不等于完整生命周期管理。

保存失败输入、状态/输出、定位和修复后证据；不删除断言或修改预期掩盖问题。

## 参考要点

对照旧GET表单与新catalog.vue：过滤、空结果、详情路径与错误退回。确认初始加载不抢焦点，路径切换后标题获焦，搜索更新不强移焦。 区分现有教学源码、学习者新增与生产待验。只读模型成立的结论不能直接推到写数据/多实例/真实用户。
