# 2.3.2 练习：Cookie：传输属性、脚本可见性与认证边界

[原理](../../../1-notes/02-javascript-browser/2.3-browser-storage/2.3.2.cookie.md) · [示例](../../../2-examples/02-javascript-browser/2.3-browser-storage/2.3.2.cookie-demo.html)

## 动手任务

在本地教学服务增加一对普通/HttpOnly偏好Cookie，页面显示脚本可读名称，服务端只回显是否收到测试Cookie。

## 验收标准

- [ ] document.cookie看不到HttpOnly测试值，而服务端收到它；输出不泄露任何其他Cookie。
- [ ] 清除后刷新服务端状态为false；能说明Secure/SameSite在本机HTTP未全面验证。

## 排错任务

尝试document.cookie="stage2_http=client; HttpOnly"，检查它不能设置真正的HttpOnly属性；改由Set-Cookie，再验证脚本不可读。

记录输入/动作、预期、实际证据、定位、修复和复验；权限/外部条件未测时明确边界，不伪造通过。

## 参考要点

HTTP响应中的Set-Cookie不对浏览器脚本直接开放；不要把HttpOnly解释成请求也不会携带。

先独立实现再看参考；必要环境与官方解释见对应原理页。
