## 动手任务

独立实现按id存取两份草稿，保存提示等事务complete；增加明确取消事务并保留旧内容的流程。

## 验收标准

- [ ] 提交后刷新恢复；abort后旧记录保持，失败不能显示保存成功。
- [ ] 有open/error/blocked和versionchange关闭处理；仅删除本练习数据库。

## 排错任务

在request.onsuccess直接显示全部保存成功，再让同事务第二个写入触发约束错误；应改等transaction.complete，并在abort说明回滚。

记录输入/动作、预期、实际证据、定位、修复和复验；权限/外部条件未测时明确边界，不伪造通过。

## 参考要点

请求成功与事务提交不是同一个时刻；准备好外部数据后再开事务，避免无关await使事务失活。
