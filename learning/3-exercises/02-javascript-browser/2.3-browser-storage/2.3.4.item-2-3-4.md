# 2.3.4 练习：浏览器存储选型：按数据与访问需求选择

[原理](../../../1-notes/02-javascript-browser/2.3-browser-storage/2.3.4.item-2-3-4.md) · [示例](../../../2-examples/02-javascript-browser/2.3-browser-storage/2.3.4.item-2-3-4-demo.html)

## 动手任务

为阅读队列的主题、筛选、草稿和会话写一张选型表，每项列丢失后果、错误恢复、是否需要服务器与迁移策略。

## 验收标准

- [ ] 每项选择解释数据访问方式与敏感度，不以“容量最大”作唯一理由。
- [ ] 给出用户清理或写入失败后的回退；区分HTTP缓存、Cache Storage与IndexedDB。

## 排错任务

把服务端授权位isAdmin存入localStorage并由页面读取决定权限，说明用户修改后为什么不能获得真实权限，改由服务端授权。

记录输入/动作、预期、实际证据、定位、修复和复验；权限/外部条件未测时明确边界，不伪造通过。

## 参考要点

选择表只是设计证据；真正API正确性需按对应实验验证，不把navigator.storage.estimate当永久配额承诺。

先独立实现再看参考；必要环境与官方解释见对应原理页。
