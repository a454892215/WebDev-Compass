# 2.1.2 独立练习：this：由调用方式决定的接收者

[理论](../../../1-notes/02-javascript-browser/2.1-js-advanced/2.1.2.this.md) · [实验](../../../2-examples/02-javascript-browser/2.1-js-advanced/2.1.2.this-demo.html)

## 动手任务

建立一个有value的方法对象，分别通过对象、提取后call/apply/bind、new和箭头调用，并预测每个输出。

先写预期，再运行自己的实现；不要只复制演示输出。

## 验收标准

- [ ] 脱离对象的方法能复现严格模式错误，call/apply/bind能得到约定值。
- [ ] 能解释箭头call不改this、new使用实例接收者，而不是背口诀。
- [ ] 保存一个变体输入的结果与因果解释，区分实测和推断。

## 排错任务

注册监听时bind一次、移除时再次bind，复现移除失败；保存同一函数引用或使用AbortSignal修复。

记录触发条件、实际现象、定位依据、修复和复验；预期错误显式捕获，禁止无限循环或污染真实业务数据。

## 参考要点

先在调用点标出接收者；再判断普通函数/箭头、严格模式及new，最后核对参数。

参考用于核对自己的推理，不表示已替学习者完成练习。
