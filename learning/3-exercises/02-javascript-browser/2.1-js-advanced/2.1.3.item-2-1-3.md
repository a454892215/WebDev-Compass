# 2.1.3 独立练习：执行上下文、调用栈与异常展开

[理论](../../../1-notes/02-javascript-browser/2.1-js-advanced/2.1.3.item-2-1-3.md) · [实验](../../../2-examples/02-javascript-browser/2.1-js-advanced/2.1.3.item-2-1-3-demo.html)

## 动手任务

写三层函数调用记录进入、返回或抛错路径；再使用DevTools断点观察真实Call Stack，比较日志与栈。

先写预期，再运行自己的实现；不要只复制演示输出。

## 验收标准

- [ ] 正常路径与异常路径顺序都能预测，异常后不可达语句确实未执行。
- [ ] 能指出词法作用域和调用链不同，finally清理后错误仍能被上层观察。
- [ ] 保存一个变体输入的结果与因果解释，区分实测和推断。

## 排错任务

在finally里return成功文本，复现上层catch看不到原异常；移除覆盖语句后复验。

记录触发条件、实际现象、定位依据、修复和复验；预期错误显式捕获，禁止无限循环或污染真实业务数据。

## 参考要点

从最内层开始标注throw/return出口。日志只是函数执行路径证据，不等同于直接打印引擎内部执行上下文。

参考用于核对自己的推理，不表示已替学习者完成练习。
