# 2.1.6 独立练习：防抖与节流：频繁事件的调度与取消

[理论](../../../1-notes/02-javascript-browser/2.1-js-advanced/2.1.6.debounce-throttle.md) · [实验](../../../2-examples/02-javascript-browser/2.1-js-advanced/2.1.6.debounce-throttle-demo.html)

## 动手任务

独立实现带cancel的trailing防抖和leading节流；记录密集输入最终值，再为页面离开和重新进入设计清理。

先写预期，再运行自己的实现；不要只复制演示输出。

## 验收标准

- [ ] 同一突发调用在防抖中只输出最后值，leading节流只保留窗口首个值。
- [ ] cancel后待执行工作不再运行；如有请求，还能解释取消与迟到处理。
- [ ] 保存一个变体输入的结果与因果解释，区分实测和推断。

## 排错任务

把防抖包装器放进input监听函数体，每次新建；复现连续输入触发多次，再改成装配时创建一次。

记录触发条件、实际现象、定位依据、修复和复验；预期错误显式捕获，禁止无限循环或污染真实业务数据。

## 参考要点

先明确产品想保留首值还是末值，然后测试单次、连续、跨窗口和取消四类输入，不依赖精确毫秒断言。

参考用于核对自己的推理，不表示已替学习者完成练习。
