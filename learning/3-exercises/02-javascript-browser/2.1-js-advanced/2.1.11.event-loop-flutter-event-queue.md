## 动手任务

在Web主页面保留一个计数变量，把数组发送到真实Worker并返回统计结果，比较Worker修改输入副本与主页面状态。再写一张三平台对照。

先写预期，再运行自己的实现；不要只复制演示输出。

## 验收标准

- [ ] 真实Worker返回结果且document不可用，主页面输入数据未被Worker普通修改共享。
- [ ] 平台对照明确宿主、DOM、消息和清理差异，不把浏览器结果称移动端已验证。
- [ ] 保存一个变体输入的结果与因果解释，区分实测和推断。

## 排错任务

在Worker里访问document，捕获错误并解释其环境边界；改为主线程更新DOM，同时补Worker错误/终止处理。

记录触发条件、实际现象、定位依据、修复和复验；预期错误显式捕获，禁止无限循环或污染真实业务数据。

## 参考要点

先确认代码运行在哪个宿主和执行代理，再谈事件队列、共享数据与UI。不要用同名API推断完全相同机制。

参考用于核对自己的推理，不表示已替学习者完成练习。
