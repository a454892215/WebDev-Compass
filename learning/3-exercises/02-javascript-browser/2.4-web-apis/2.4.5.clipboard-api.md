# 2.4.5 练习：Clipboard：用户动作、权限与拒绝回退

[原理](../../../1-notes/02-javascript-browser/2.4-web-apis/2.4.5.clipboard-api.md) · [示例](../../../2-examples/02-javascript-browser/2.4-web-apis/2.4.5.clipboard-api-demo.html)

## 动手任务

给阅读器副本增加复制当前筛选链接按钮，复制失败仍显示可选择的链接文本；不添加后台readText。

## 验收标准

- [ ] 只有主动点击后写入，等待Promise后报告成功。
- [ ] 拒绝/缺API时文本可手动复制，自动化模拟不宣称验证了系统剪贴板。

## 排错任务

不await writeText就显示成功，再让writer拒绝；修复为await/catch，并确保失败后没有误导成功提示。

记录输入/动作、预期、实际证据、定位、修复和复验；权限/外部条件未测时明确边界，不伪造通过。

## 参考要点

许可和用户激活规则需目标浏览器核对；测试适配器只用于确定性测试，不要在生产改写navigator能力。

先独立实现再看参考；必要环境与官方解释见对应原理页。
