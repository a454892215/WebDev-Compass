# 2.4.9 练习：Notification：权限与站内提示的边界

[原理](../../../1-notes/02-javascript-browser/2.4-web-apis/2.4.9.notification-api.md) · [示例](../../../2-examples/02-javascript-browser/2.4-web-apis/2.4.9.notification-api-demo.html)

## 动手任务

为阅读器写通知取舍说明，保留站内保存结果；只有明确用户需求才设计可关闭的通知增强，不默认引入Push。

## 验收标准

- [ ] 页面加载不弹权限请求，拒绝/不支持时仍有站内反馈。
- [ ] 区分Notification、SW通知和Push；自动化模拟不声称OS送达。

## 排错任务

让页面加载立刻requestPermission并拒绝后循环重试，分析为何打扰用户；改为明确按钮与拒绝后的站内回退，不实际循环触发系统请求。

记录输入/动作、预期、实际证据、定位、修复和复验；权限/外部条件未测时明确边界，不伪造通过。

## 参考要点

通知能力检测和permission只是前置；真正平台送达应单独授权、实测并记录，不在本轮宣称完成。

先独立实现再看参考；必要环境与官方解释见对应原理页。
