# 2.4.2 练习：ResizeObserver：组件尺寸变化与反馈环

[原理](../../../1-notes/02-javascript-browser/2.4-web-apis/2.4.2.resize-observer.md) · [示例](../../../2-examples/02-javascript-browser/2.4-web-apis/2.4.2.resize-observer-demo.html)

## 动手任务

给阅读器的统计画布监听容器宽度，输出缓冲区尺寸；纯卡片列数仍用CSS处理。

## 验收标准

- [ ] 容器变化而窗口不变时仍能更新，说明content-box与border-box差异。
- [ ] 回调不会继续改变被测宽度；销毁后监听停止。

## 排错任务

在回调把目标width设为当前宽度+1，说明循环风险；改为只更新独立输出或有界不回写的尺寸计算。

记录输入/动作、预期、实际证据、定位、修复和复验；权限/外部条件未测时明确边界，不伪造通过。

## 参考要点

如果需要写布局先判断变更是否必要并避免环；requestAnimationFrame不是无条件消除逻辑循环的万能补丁。
