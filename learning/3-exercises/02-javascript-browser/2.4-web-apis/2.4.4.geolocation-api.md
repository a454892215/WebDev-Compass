## 动手任务

在阅读器副本设计可选地区筛选，默认手工选择；定位只作用户主动增强，拒绝后保留核心功能。

## 验收标准

- [ ] 未点击不请求位置，拒绝/超时有可理解提示与手工地区入口。
- [ ] 不把accuracy当保证精度，不保存或上传定位数据；持续监听版本有clearWatch。

## 排错任务

删除失败回调，模拟拒绝后页面永远等待；恢复错误分类与结束加载，确认不循环弹权限请求。

记录输入/动作、预期、实际证据、定位、修复和复验；权限/外部条件未测时明确边界，不伪造通过。

## 参考要点

自动化虚拟位置只验证分支与参数，不证明真实设备精度或系统授权体验。

先独立实现再看参考；必要环境与官方解释见对应原理页。
