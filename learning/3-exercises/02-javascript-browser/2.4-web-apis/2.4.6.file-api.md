# 2.4.6 练习：File API：用户提供文件、异步读取与安全展示

[原理](../../../1-notes/02-javascript-browser/2.4-web-apis/2.4.6.file-api.md) · [示例](../../../2-examples/02-javascript-browser/2.4-web-apis/2.4.6.file-api-demo.html)

## 动手任务

在阅读器副本加JSON草稿导入，限制大小、校验id/text，再由用户确认保存进IndexedDB。

## 验收标准

- [ ] 只读取主动选择的文件，坏JSON/错协议/超限分别拒绝。
- [ ] 含HTML的文本不生成DOM；取消选择不会继续显示为刚刚导入成功。
- [ ] 延迟读取A期间清空或选B，A迟到不能覆盖新状态；离开页面也令旧读取失效。

## 排错任务

把文件内容赋给innerHTML，在隔离无执行事件的标记样本中观察产生节点；改textContent，并说明为何文件是输入而非可信模板。

记录输入/动作、预期、实际证据、定位、修复和复验；权限/外部条件未测时明确边界，不伪造通过。

## 参考要点

不要用真实恶意文件；测试用内存File样本，导入和上传是不同动作。

先独立实现再看参考；必要环境与官方解释见对应原理页。
