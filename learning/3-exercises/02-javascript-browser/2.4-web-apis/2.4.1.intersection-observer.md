# 2.4.1 练习：IntersectionObserver：按交叉状态触发工作

[原理](../../../1-notes/02-javascript-browser/2.4-web-apis/2.4.1.intersection-observer.md) · [示例](../../../2-examples/02-javascript-browser/2.4-web-apis/2.4.1.intersection-observer-demo.html)

## 动手任务

为阅读器末尾添加加载提示哨兵，真实进入后只触发一次请求，并保留手动加载与错误重试。

## 验收标准

- [ ] 进入/离开与计数可观察，重复交叉时不并发重复请求。
- [ ] 断开观察后无继续回调；不支持时仍能手动获得内容。

## 排错任务

让每次回调直接追加哨兵并请求，复现重复触发；增加loading/已结束标志，成功后unobserve或移动稳定哨兵。

记录输入/动作、预期、实际证据、定位、修复和复验；权限/外部条件未测时明确边界，不伪造通过。

## 参考要点

交叉比例不等于阅读完成；root必须是目标的适合祖先容器，阈值和rootMargin按实际布局验证。

先独立实现再看参考；必要环境与官方解释见对应原理页。
