## 动手任务

为阅读器卡片区域添加一个仅调试用的DOM记录器，日志放在区域外；说明正式业务为何不依赖它计算收藏数。

## 验收标准

- [ ] childList与attributes分别可复现，只观察明确范围。
- [ ] 日志不造成自我触发，销毁断开后无新增回调。

## 排错任务

把日志追加到watched内部并在回调继续写日志，分析为什么循环；改放树外并缩小attributeFilter。

记录输入/动作、预期、实际证据、定位、修复和复验；权限/外部条件未测时明确边界，不伪造通过。

## 参考要点

不要在真实页面运行无限写入故障；用有限计数副本复现，确保可以停止。
