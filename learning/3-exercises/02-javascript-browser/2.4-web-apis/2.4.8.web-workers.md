# 2.4.8 练习：Web Worker：消息、计算与终止

[原理](../../../1-notes/02-javascript-browser/2.4-web-apis/2.4.8.web-workers.md) · [示例](../../../2-examples/02-javascript-browser/2.4-web-apis/2.4.8.web-workers-demo.html)

## 动手任务

给阅读队列统计增加requestId与销毁逻辑，忽略旧返回结果；记录为何小列表也许无需Worker。

## 验收标准

- [ ] 计算由独立脚本返回，主线程更新UI；消息字段经过校验。
- [ ] 终止/错误有反馈，旧requestId不覆盖当前结果，不声称小样本证明性能提升。

## 排错任务

在Worker访问document，观察error并保持界面可用；改为返回数据，由主线程操作DOM。

记录输入/动作、预期、实际证据、定位、修复和复验；权限/外部条件未测时明确边界，不伪造通过。

## 参考要点

用浏览器HTTP加载模块Worker；直接file://的限制和404不能当作Worker本身失效。

先独立实现再看参考；必要环境与官方解释见对应原理页。
