# 2.2.5 独立练习：合成与will-change：提示不是GPU加速开关

[理论](../../../1-notes/02-javascript-browser/2.2-browser-internals/2.2.5.will-change.md) · [实验](../../../2-examples/02-javascript-browser/2.2-browser-internals/2.2.5.will-change-demo.html) · [本章练习](./README.md)

## 动手任务

1. 选择一个真实交互元素，分别实现无提示与临时提示，保持位移相同。
2. 在交互结束、取消或离开时移除提示，判断项目是否真的需要该优化。

## 验收标准

- [ ] 提示能清理，重复操作不会永久给整页元素加will-change。
- [ ] 位移和减少动效终态正确，未测GPU就不作加速保证。

## 排错任务

给列表所有项长期设置will-change:transform；改为仅作用于当前交互目标并及时恢复auto，解释资源成本而不伪造内存数字。

记录输入/操作、实际现象、原因、修正和复验。需要Performance/任务管理器等手动证据的地方不能用页面数字冒充。

## 参考要点

先测热点再提示；声明、合成层与真实性能分别是三层证据。
