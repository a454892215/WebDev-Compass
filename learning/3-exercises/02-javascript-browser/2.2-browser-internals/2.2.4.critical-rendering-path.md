# 2.2.4 独立练习：关键渲染路径：先交付可见内容，再安排非关键资源

## 动手任务

1. 在目录副本画出首屏HTML、CSS、脚本、封面的依赖链。
2. 选一个真实非关键资源延后加载，核对功能及无脚本内容，保留前后观察。

## 验收标准

- [ ] 能区分解析阻塞、渲染阻塞与网络慢，不把它们统称加载慢。
- [ ] 至少一个非关键依赖调整后功能正确，并准确声明指标边界。

## 排错任务

将控制主标题可见性的唯一样式完全延后，再观察无样式闪烁；恢复必要基础样式，非关键部分才延后。

记录输入/操作、实际现象、原因、修正和复验。需要Performance/任务管理器等手动证据的地方不能用页面数字冒充。

## 参考要点

先明确关键内容及其依赖，再优化链路。功能可用、可见反馈和测量指标需要分别检查。

先独立尝试，再对照原理与实验。未执行的真实网络、辅助技术或设备验证如实说明，不把资料验收当个人掌握。
