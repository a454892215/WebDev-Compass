# 1.4.1 练习：为课程目录选择能力并写出回退

[对应笔记](../../../1-notes/01-web-fundamentals/1.4-quality-basics/1.4.1.standards-baseline.md) · [观察示例](../../../2-examples/01-web-fundamentals/1.4-quality-basics/1.4.1.standards-baseline-demo.html) · [练习目录](./README.md)

先用演示数据完成自己的实现，再与示例比较。不要上传真实凭据；过程中的失败和修复同样需要保留说明。

## 动手任务

1. 写下桌面浏览器与手机WebView目标，查一项能力的Baseline/兼容信息。
2. 给Grid增强提供内容完整的单列回退，并在实验里主动触发。

## 验收标准

- [ ] 能够区分规范、语法支持、项目矩阵与行为验证。
- [ ] 关闭增强后仍可阅读与导航。
- [ ] 不以CSS.supports=true推导所有环境通过。
- [ ] 能说明本次验证的浏览器/视口与未覆盖范围，不能以模拟冒充真机或正式服务。

## 排错任务

把User-Agent中出现Chrome当作全部能力支持，指出旧WebView和嵌入容器风险。

记录“复现步骤 → 观察证据 → 原因 → 修正 → 复验”，不要只写问题已经消失。

## 参考要点

- 支持标准不等于实现完全一致。
- 回退保核心任务，不必逐像素一致。

这部分提供判断方向，不替代自己的实现与排错。更完整机制和官方来源见对应笔记。
