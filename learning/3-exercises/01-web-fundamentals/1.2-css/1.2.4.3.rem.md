## 排错任务

故意制造这个问题：把em视为永远相对父元素。

按“元素是否匹配 → 声明是否生效 → 参照/约束是否正确 → 最终尺寸/绘制”的顺序定位，截取或抄录关键计算值，并用最小修改修复。不要用全局important或overflow:hidden掩盖现象。

## 思考题

为什么“所有height:100%都能填满屏幕。”会造成误判？它在综合项目中可能影响哪些内容或用户操作？

## 参考要点

- rem相对根元素字号，em用于font-size时相对父字号，用在其他属性通常相对当前元素字号。
- clamp可组合相对和视口尺寸，但保留可读最小值与缩放效果，避免纯vw字体在放大时抵消。
- 与逻辑像素/比例尺寸有相似目标；rem对应根字号而非固定dp换算，用户字号会改变它。
- 验收记录需要实际修改与观测，不把一次自动检查等同于所有浏览器/辅助技术验收。
