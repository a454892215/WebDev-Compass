## 参考要点

- color、font 等通常继承；margin、padding、border 等通常不继承，需按属性定义判断。
- revert-layer 只撤销当前层的贡献；与 revert、清空 style 或删除整个类不是同一种操作。
- 与 Flutter 继承主题有相似性，但 CSS 每个属性有自己的继承/初始行为；all 可能同时重置交互外观，需谨慎。
- 验收记录需要实际修改与观测，不把一次自动检查等同于所有浏览器/辅助技术验收。
