## 验收标准

- [ ] 用自己的话解释：background负责盒子背后的装饰；承载内容信息的图片通常仍应使用img及替代文本。
- [ ] 执行对照操作后，从目标元素的 Computed 面板读出 `backgroundSize`，解释原因，而非只复述输出。
- [ ] 恢复语义文本或合适img/alt；背景失效仍知道内容，关键图表不被cover裁掉。
- [ ] 能复现并修正本页下一节的排错任务；没有对应工具链或真机证据时不声称通过。

## 排错任务

1. 故障注入：删除真实说明文字，改用含文字的背景图充当唯一信息，再禁用背景图片。
2. 定位并修正：恢复语义文本或合适img/alt；背景失效仍知道内容，关键图表不被cover裁掉。
3. 保存故障前、修复后的代码差异与实际读数/行为；说明为什么这项修改解决原因。

## 参考要点

- background-color在图像未加载时提供底色；多个背景层按列表前者在上叠放。
- CSS背景没有alt，关键信息不能只藏在背景；高对比/打印/加载失败也应可理解。
- 与BoxDecoration背景类似，但background-image参与资源下载，内容语义和alt不能靠装饰层补齐。
- 验收记录需要实际修改与观测，不把一次自动检查等同于所有浏览器/辅助技术验收。
