- [ ] 用自己的话解释：transition描述两个可动画状态间的插值，不创造状态，也不保证所有属性都能平滑变化。

- [ ] 能复现并修正本页下一节的排错任务；没有对应工具链或真机证据时不声称通过。

## 排错任务

故意制造这个问题：有transition就会自动播放，不改变值。

按“元素是否匹配 → 声明是否生效 → 参照/约束是否正确 → 最终尺寸/绘制”的顺序定位，截取或抄录关键计算值，并用最小修改修复。不要用全局important或overflow:hidden掩盖现象。

## 参考要点

- 需有实际起始/结束值和属性变化；transition-property、duration、timing-function、delay分别控制范围和时间。
- 保留prefers-reduced-motion路径，并确保动画不是传达结果的唯一方式。
- 类似隐式动画，但CSS监听的是样式状态差异；Web还需考虑动画偏好和主线程布局代价。
- 自动检查应等待过渡结束；减少动态效果时立即到达终态。
