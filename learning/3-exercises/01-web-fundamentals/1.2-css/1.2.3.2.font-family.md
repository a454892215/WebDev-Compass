# 1.2.3.2 练习：字体、行高与文字间距

[返回理论](../../../1-notes/01-web-fundamentals/1.2-css/1.2.3.2.font-family.md) · [打开实验](../../../2-examples/01-web-fundamentals/1.2-css/1.2.3.2.font-family-demo.html)

## 动手任务

1. 观察目标字号和行高计算值。
2. 切换局部字号，确认无单位行高按新字号缩放。
3. 浏览器放大，检查文本是否仍完整可达。

在独立副本中修改目标规则，先写下预测，再运行和测量。不得仅复制切换后的CSS并宣布完成。

## 验收标准

- [ ] 用自己的话解释：字号决定字形尺度，行高决定行盒节奏；字体回退和内容长度都会改变布局。
- [ ] 执行对照操作后，从目标元素的 Computed 面板读出 `lineHeight`，解释原因，而非只复述输出。
- [ ] 完成一次与原例不同的条件变化，记录预期与实际结果；保留键盘焦点、可读文字与必要滚动。
- [ ] 能复现并修正本页下一节的排错任务；没有对应工具链或真机证据时不声称通过。

## 排错任务

故意制造这个问题：固定容器高度，字体变大后把内容裁掉。

按“元素是否匹配 → 声明是否生效 → 参照/约束是否正确 → 最终尺寸/绘制”的顺序定位，截取或抄录关键计算值，并用最小修改修复。不要用全局important或overflow:hidden掩盖现象。

## 思考题

为什么“所有元素都继承固定px行高，放大标题时行间重叠。”会造成误判？它在综合项目中可能影响哪些内容或用户操作？

## 参考要点

- font-family按列表选择可用字体，最后用通用族作为回退；系统字体在不同平台上外观和字宽不一致。
- font-weight的可用值受字体文件支持影响；letter-spacing过大可能伤害阅读，尤其是长文。
- 类似TextStyle，但CSS行盒、继承与字体回退会影响整段文档，不是只计算单个Text控件。
- 验收记录需要实际修改与观测，不把一次自动检查等同于所有浏览器/辅助技术验收。

## 关联综合实践

调整综合页h1/h2/h3和正文的字号、无单位行高与最大阅读宽度，用长标题复验。

- [ ] 缩放与长文案时不固定高度裁字
- [ ] 解释字号和行高的继承参照
