## 参考要点

- static 留在正常流，top 等 inset 通常不生效；relative 仍保留原位置，视觉偏移不推动相邻元素。
- sticky 需要对应轴的 inset；祖先 overflow 与容器高度常是失效排查点。
- 接近 Stack/Positioned，但 CSS 包含块与滚动祖先并不是 Widget 父节点的简单映射。
- 验收记录需要实际修改与观测，不把一次自动检查等同于所有浏览器/辅助技术验收。
