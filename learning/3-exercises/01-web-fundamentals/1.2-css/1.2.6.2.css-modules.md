## 参考要点

- 常见*.module.css约定由构建工具识别；import styles后以styles.title取实际类名，映射命名由工具决定。
- 测试应包含构建输出和组件引用一致性；静态演示只能解释编译后行为。
- 与代码生成的资源名称映射相似，但不等于Dart库私有或Widget树隔离；必须验证宿主构建链。
- 本页为手工标注的编译结果fixture，原始.module.css在assets/source；未执行CSS Modules构建器，不把fixture当完整工具链验收。
