## 参考要点

- block/inline 描述外部流；flex/grid 建立内部格式化上下文，不能只理解成“横向/纵向”。
- 切成 flex 不会自动把按钮、链接变得可访问；语义仍来自 HTML。
- Flex/Grid 与 Row/Column 目标相似，但 Web 的 DOM 源顺序、行内文字和盒生成行为需要单独理解。
- 验收记录需要实际修改与观测，不把一次自动检查等同于所有浏览器/辅助技术验收。
