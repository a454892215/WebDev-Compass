## 参考要点

- Row/Column/RN Flexbox与CSS Flex有共同轴模型；CSS默认收缩、内在最小尺寸和书写方向不能直接照搬。
- Web保留DOM阅读和键盘顺序；不能仅为了布局美观用order打乱交互顺序。
- 已有移动开发经验可以帮助判断布局目的，但不能把CSS当另一套Widget属性字典；应测量实际盒模型。
- 验收记录需要实际修改与观测，不把一次自动检查等同于所有浏览器/辅助技术验收。
