## 参考要点

- flex-direction 规定主轴；justify-content 沿主轴，align-items 沿交叉轴，不能固定翻译成水平/垂直。
- 长文本项目常需 min-inline-size:0；DOM 交互顺序不应为视觉重排而使用 order/reverse 随意改变。
- 与 RN Flexbox、Flutter Row/Column 有关联，但 CSS 默认收缩、内在最小尺寸和源顺序规则需重新验证。
- 验收记录需要实际修改与观测，不把一次自动检查等同于所有浏览器/辅助技术验收。
