## 参考要点

- cursor只改变指针外观，不让div自动成为按钮；动作应使用button，导航用a。
- 触控没有传统鼠标光标，hover策略必须有键盘/触控等效路径。
- 与IgnorePointer有相关性，但CSS pointer-events不是完整的输入禁用模型，也不等价于按钮enabled=false。
- 切换后目标仍可通过Tab聚焦；本例故意说明pointer-events不是完整禁用。

## 关联综合实践

核对 #cancel 的disabled状态与cursor显示，证明pointer-events:none不能代替禁用。
