## 参考要点

- font-family是自定义家族名，src指向local或url来源；font-style/weight需要与真实字体文件能力匹配。
- 预加载仅用于首屏关键且确实会使用的字体；避免重复下载错误weight或预加载所有文件。
- 与Flutter字体资源声明目标类似，但Web有网络、缓存、CORS和回退交换过程；不能只验本机存在字体。
- 只验证本地声明与回退，不包含授权字体下载资源，不宣称已验收Web字体网络加载。
