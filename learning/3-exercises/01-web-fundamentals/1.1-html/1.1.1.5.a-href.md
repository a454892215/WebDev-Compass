## 动手任务

1. 写出同目录、父目录、根相对地址与页内锚点四种链接。
2. 用 URL 构造器解析带查询参数的地址，避免手工拼接转义；动作保留为按钮。

## 验收标准

- [ ] 点击锚点后 URL 的 hash 正确，浏览器后退可恢复地址状态。
- [ ] 链接具备可理解的名称，带 href 的 a 与动作 button 用途明确。
- [ ] 能说明当前相对路径以哪个文档地址为基准。
- [ ] 能说明本次验证的浏览器/视口与未覆盖范围，不能以模拟冒充真机或正式服务。

## 排错任务

将 ../ 改为 ./，用 Network 和解析出的绝对地址定位错误目录。

记录“复现步骤 → 观察证据 → 原因 → 修正 → 复验”，不要只写问题已经消失。

## 参考要点

- 导航改变位置，动作触发当前页面行为。
- hash 不会随 HTTP 请求发往服务器。
