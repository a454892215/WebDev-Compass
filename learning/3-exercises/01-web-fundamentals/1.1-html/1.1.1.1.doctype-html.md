# 1.1.1.1 练习：用最小文档建立自己的学习首页

[对应笔记](../../../1-notes/01-web-fundamentals/1.1-html/1.1.1.1.doctype-html.md) · [观察示例](../../../2-examples/01-web-fundamentals/1.1-html/1.1.1.1.doctype-html-demo.html) · [练习目录](./README.md)

先用演示数据完成自己的实现，再与示例比较。不要上传真实凭据；过程中的失败和修复同样需要保留说明。

## 动手任务

1. 新建一个独立 HTML 文件，设置 doctype、主语言、编码、viewport 和有意义的 title。
2. 把正文放入 main，保留一个页面 h1，并通过本机 HTTP 打开。

## 验收标准

- [ ] document.compatMode 为 CSS1Compat，characterSet 为 UTF-8。
- [ ] 浏览器标签标题与页面 h1 各自表达用途，能说明它们为什么不是同一节点。
- [ ] 窄视口可读且没有 user-scalable=no 或 maximum-scale 限制。
- [ ] 能说明本次验证的浏览器/视口与未覆盖范围，不能以模拟冒充真机或正式服务。

## 排错任务

临时移除 doctype，再比较 compatMode；不要把浏览器容错后的 DOM 当作原始源码。

记录“复现步骤 → 观察证据 → 原因 → 修正 → 复验”，不要只写问题已经消失。

## 参考要点

- doctype 选择标准模式；语言、编码和视口分别解决不同问题。
- DOM 是解析结果，错误嵌套可能被浏览器修复。

这部分提供判断方向，不替代自己的实现与排错。更完整机制和官方来源见对应笔记。
