# 1.1.1.6 练习：交付一张稳定且可理解的内容图片

[对应笔记](../../../1-notes/01-web-fundamentals/1.1-html/1.1.1.6.img.md) · [观察示例](../../../2-examples/01-web-fundamentals/1.1-html/1.1.1.6.img-demo.html) · [练习目录](./README.md)

先用演示数据完成自己的实现，再与示例比较。不要上传真实凭据；过程中的失败和修复同样需要保留说明。

## 动手任务

1. 使用本地图片，写出符合上下文的 alt、尺寸和必要的 figcaption。
2. 通过 picture 提供宽窄不同构图，并说明音频/视频需要哪些文字替代。

## 验收标准

- [ ] 图片加载前预留比例，窄视口不发生整页水平溢出。
- [ ] 禁用或阻断图片后仍能理解主要信息。
- [ ] 首屏关键图不误用 lazy，媒体不自动有声播放。
- [ ] 能说明本次验证的浏览器/视口与未覆盖范围，不能以模拟冒充真机或正式服务。

## 排错任务

只删 alt 与设 alt="" 分别观察含义；装饰图和信息图不能混为一谈。

记录“复现步骤 → 观察证据 → 原因 → 修正 → 复验”，不要只写问题已经消失。

## 参考要点

- caption 不一定替代 alt，字幕也不等于完整音频描述。
- 提供 source 不保证当前设备支持该编码。

这部分提供判断方向，不替代自己的实现与排错。更完整机制和官方来源见对应笔记。
