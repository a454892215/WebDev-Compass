# 1.1.2.1 练习：构造可解释的表单数据集

[对应笔记](../../../1-notes/01-web-fundamentals/1.1-html/1.1.2.1.form.md) · [观察示例](../../../2-examples/01-web-fundamentals/1.1-html/1.1.2.1.form-demo.html) · [练习目录](./README.md)

先用演示数据完成自己的实现，再与示例比较。不要上传真实凭据；过程中的失败和修复同样需要保留说明。

## 动手任务

1. 实现演示邮箱、数量、checkbox、同名 radio 和可选本地文件输入。
2. 拦截提交，只在本页展示脱敏后的 entries，保留重复字段。

## 验收标准

- [ ] 每个可见输入有标签，协议字段有 name。
- [ ] 未选 checkbox 不出现，重复键可用 getAll 读取。
- [ ] 无效邮箱/越界数量被阻止，密码不显示在输出中。
- [ ] 能说明本次验证的浏览器/视口与未覆盖范围，不能以模拟冒充真机或正式服务。

## 排错任务

把 FormData 直接 Object.fromEntries 后比较重复键为何丢失。

记录“复现步骤 → 观察证据 → 原因 → 修正 → 复验”，不要只写问题已经消失。

## 参考要点

- id 关联界面，name 参与协议。
- password/hidden 不提供秘密存储或传输加密。

这部分提供判断方向，不替代自己的实现与排错。更完整机制和官方来源见对应笔记。
