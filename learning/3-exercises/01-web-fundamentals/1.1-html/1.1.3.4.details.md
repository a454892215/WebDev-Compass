## 动手任务

1. 添加 details/summary 和使用 showModal 打开的确认对话框。
2. 提供取消/确认按钮，观察 returnValue，再区分progress和meter的用途。

## 验收标准

- [ ] 键盘可展开折叠，模态打开后背景不可操作。
- [ ] Esc或取消关闭后焦点回到触发按钮。
- [ ] progress、meter和可见数值同步，方法缺失时给明确回退。
- [ ] 能说明本次验证的浏览器/视口与未覆盖范围，不能以模拟冒充真机或正式服务。

## 排错任务

只设置dialog.open=true，解释为什么它不是模态展示。

记录“复现步骤 → 观察证据 → 原因 → 修正 → 复验”，不要只写问题已经消失。

## 参考要点

- 原生模态已管理顶层和焦点约束，不叠加第二套焦点陷阱。
- meter为测量值，progress为任务进度。

这部分提供判断方向，不替代自己的实现与排错。更完整机制和官方来源见对应笔记。
