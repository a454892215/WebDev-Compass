# 1.1.1.2 练习：为学习目录划分有意义的文档区域

## 动手任务

1. 给目录建立页面 header/nav/main/footer，并为可独立阅读的内容选择 article。
2. 添加一条键盘可操作的跳转链接，指向主标题；用 aside 表达补充说明而非固定右栏。

## 验收标准

- [ ] 页面只有一个可见 main，多个 nav 的用途可区分。
- [ ] 按 Tab/Enter 可跳过重复导航进入主内容。
- [ ] 移除 CSS 后，内容顺序仍可理解。
- [ ] 能说明本次验证的浏览器/视口与未覆盖范围，不能以模拟冒充真机或正式服务。

## 排错任务

把每个 div 全部替换成 section，观察为什么没有标题的装饰盒子不会自动更有语义。

记录“复现步骤 → 观察证据 → 原因 → 修正 → 复验”，不要只写问题已经消失。

## 参考要点

- 语义首先表达内容职责，不强制视觉位置。
- header/footer 可以属于 article，但不因此成为额外的页面级区域。

这部分提供判断方向，不替代自己的实现与排错。更完整机制和官方来源见对应笔记。
