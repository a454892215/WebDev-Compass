# 1.1.3.2 练习：制作可缩放且有名称的 SVG 数据图

先用演示数据完成自己的实现，再与示例比较。不要上传真实凭据；过程中的失败和修复同样需要保留说明。

## 动手任务

1. 用 viewBox 绘制条形完成度，关联 title/desc。
2. 滑块修改图形尺寸与可见数值，装饰性图标另用适当方式隐藏。

## 验收标准

- [ ] 改变容器宽度时图形仍保持合理比例。
- [ ] 图形、可见百分比与描述同步。
- [ ] 信息图有可访问名称，装饰图不重复制造无意义朗读。
- [ ] 能说明本次验证的浏览器/视口与未覆盖范围，不能以模拟冒充真机或正式服务。

## 排错任务

只修改 rect.width 而不更新文字/desc，说明视觉用户与读屏用户为何得到不同信息。

记录“复现步骤 → 观察证据 → 原因 → 修正 → 复验”，不要只写问题已经消失。

## 参考要点

- SVG 是矢量节点，viewBox 与CSS显示尺寸不同。
- 复杂可视化还需要等价数据或说明，不止一个title。
