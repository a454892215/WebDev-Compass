## 动手任务

1. 用 template 和 Custom Element 建立一个带命名及默认 slot 的卡片。
2. 创建两个实例，给普通DOM克隆分别生成唯一id。

## 验收标准

- [ ] 模板本身不直接显示，插入克隆后才出现。
- [ ] 命名/默认slot分配符合预期，缺失时显示后备内容。
- [ ] 实例不依赖重复的全局id，能解释Shadow DOM不是安全沙箱。
- [ ] 能说明本次验证的浏览器/视口与未覆盖范围，不能以模拟冒充真机或正式服务。

## 排错任务

将slot放在普通DOM中，说明为什么它不会像Shadow DOM插槽那样分发内容。

记录“复现步骤 → 观察证据 → 原因 → 修正 → 复验”，不要只写问题已经消失。

## 参考要点

- template提供可重复克隆的惰性结构。
- Vue插槽和原生slot有相似组合目的，运行机制不同。
