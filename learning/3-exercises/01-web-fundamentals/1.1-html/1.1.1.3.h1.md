## 动手任务

1. 创建页面主题、两个章节和一个子节，选择连续的 h1/h2/h3 层级。
2. 分别使用 strong、em、段落和真正的主题分隔，说明为何不以 br 代替布局。

## 验收标准

- [ ] 仅浏览标题即可判断内容层级。
- [ ] 调整 CSS 字号后，标题语义和文档顺序仍保持不变。
- [ ] 能给出 strong 与 em 的不同使用理由，而非都解释为加粗。
- [ ] 能说明本次验证的浏览器/视口与未覆盖范围，不能以模拟冒充真机或正式服务。

## 排错任务

把所有标题改成大字号 span，再检查可访问性树中丢失的标题导航。

记录“复现步骤 → 观察证据 → 原因 → 修正 → 复验”，不要只写问题已经消失。

## 参考要点

- 标题级别服务结构；视觉字号由 CSS 决定。
- p 不能容纳任意块结构，br 不应堆成段落间距。

这部分提供判断方向，不替代自己的实现与排错。更完整机制和官方来源见对应笔记。
