# 1.1.2.2 练习：用分组与标签表达一份学习偏好表单

## 动手任务

1. 增加 textarea、带 optgroup 的 select，以及包含 radio 的 fieldset/legend。
2. 加入一个只填入示例文本的辅助按钮，显式设置 type。

## 验收标准

- [ ] label 点击能够关联对应控件。
- [ ] 辅助按钮不会触发表单提交，提交按钮会执行验证。
- [ ] radio 组有可理解的组名，select option 的提交值与可见文案可区分。
- [ ] 能说明本次验证的浏览器/视口与未覆盖范围，不能以模拟冒充真机或正式服务。

## 排错任务

删去辅助按钮的 type，说明为什么在 form 中可能变成提交操作。

记录“复现步骤 → 观察证据 → 原因 → 修正 → 复验”，不要只写问题已经消失。

## 参考要点

- label 不等于 placeholder，legend 提供组的含义。
- textarea 的初始值来自内容，运行期值读取 value。

这部分提供判断方向，不替代自己的实现与排错。更完整机制和官方来源见对应笔记。
