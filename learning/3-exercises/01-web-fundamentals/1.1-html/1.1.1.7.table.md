## 动手任务

1. 为三项课程的学习时间写 table、caption、列头与行头。
2. 让窄屏只在表格区域滚动，该区域可用键盘到达且有名称。

## 验收标准

- [ ] caption 说明主题与单位，表头使用正确 scope。
- [ ] 页面整体不因表格过宽而横向溢出。
- [ ] 能按行头和列头解释一个数据单元格。
- [ ] 能说明本次验证的浏览器/视口与未覆盖范围，不能以模拟冒充真机或正式服务。

## 排错任务

去掉表头只保留加粗 td，观察视觉相似为何不能保证语义关系。

记录“复现步骤 → 观察证据 → 原因 → 修正 → 复验”，不要只写问题已经消失。

## 参考要点

- 表格用于数据关系，不用于页面布局。
- 复杂跨行跨列结构需额外设计关联并实际验证。

这部分提供判断方向，不替代自己的实现与排错。更完整机制和官方来源见对应笔记。
