# 1.1.3.1 练习：把同一数据同时交付为 Canvas 与文字

先用演示数据完成自己的实现，再与示例比较。不要上传真实凭据；过程中的失败和修复同样需要保留说明。

## 动手任务

1. 绘制课程完成度，依据 devicePixelRatio 配置缓冲区，并用滑块修改值。
2. 独立更新可见文字，2D上下文不可用时也能知道当前数据。

## 验收标准

- [ ] 图形与文字显示同一百分比。
- [ ] 缓冲区像素与CSS尺寸职责可解释，窄屏不整页溢出。
- [ ] 禁用2D上下文后仍能读取并更新文字数据。
- [ ] 能说明本次验证的浏览器/视口与未覆盖范围，不能以模拟冒充真机或正式服务。

## 排错任务

将文字更新放在 getContext 成功分支之后，复现无绘图时文字滞后的问题。

记录“复现步骤 → 观察证据 → 原因 → 修正 → 复验”，不要只写问题已经消失。

## 参考要点

- Canvas 是位图绘图面，不是每个图形各一个DOM节点。
- 清晰度、性能和替代内容分别验证。

这部分提供判断方向，不替代自己的实现与排错。更完整机制和官方来源见对应笔记。
