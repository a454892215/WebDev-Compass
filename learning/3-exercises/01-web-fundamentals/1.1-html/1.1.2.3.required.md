# 1.1.2.3 练习：比较约束、只读与禁用的提交行为

## 动手任务

1. 给昵称设置 required/pattern，给数量设 min/max/step。
2. 并排设置一个 readonly 和一个 disabled 字段，用按钮切换 disabled。

## 验收标准

- [ ] 默认收集只读字段而不收集禁用字段。
- [ ] readonly 不参与原生约束验证，仍需服务端校验其可信性。
- [ ] disabled="false" 仍禁用的原因能够解释；移除属性或设属性为false后恢复。
- [ ] 能说明本次验证的浏览器/视口与未覆盖范围，不能以模拟冒充真机或正式服务。

## 排错任务

将 inputmode=numeric 当成强制数字限制，尝试非数字输入并说明为何仍需要验证。

记录“复现步骤 → 观察证据 → 原因 → 修正 → 复验”，不要只写问题已经消失。

## 参考要点

- 布尔属性以存在为真，而不是字符串内容。
- 约束适用于特定 input 类型；readonly 不是 select 的通用能力。
