## 动手任务

1. 用无序列表记录主题，用有序列表写操作步骤，用描述列表解释术语。
2. 给每个列表添加真实内容，避免把无关的视觉卡片一律做成编号步骤。

## 验收标准

- [ ] 能够解释三种列表的选择依据。
- [ ] li 的父容器正确，dt 与 dd 的含义对应。
- [ ] 隐藏列表样式后，DOM 仍表达集合与顺序。
- [ ] 能说明本次验证的浏览器/视口与未覆盖范围，不能以模拟冒充真机或正式服务。

## 排错任务

把一个 li 移到列表外，再观察 Elements 修复行为与文档结构差异。

记录“复现步骤 → 观察证据 → 原因 → 修正 → 复验”，不要只写问题已经消失。

## 参考要点

- ol 的顺序有意义，ul 只是集合。
- dl 的术语/描述关系不同于两列表格。
