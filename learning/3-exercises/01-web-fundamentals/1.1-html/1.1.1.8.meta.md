## 动手任务

1. 为学习页面配置 title、description、viewport 和本地 stylesheet。
2. 用 defer 外部脚本读取已解析 DOM；OG 信息只写真实内容，不编造正式站点地址。

## 验收标准

- [ ] 脚本可以查询按钮并注册监听，没有依赖 DOM 过早访问。
- [ ] title、h1 和 meta description 的职责可分别解释。
- [ ] viewport 保留用户缩放，页面无远程字体或分析上报依赖。
- [ ] 能说明本次验证的浏览器/视口与未覆盖范围，不能以模拟冒充真机或正式服务。

## 排错任务

移除 defer 后把脚本移到 head，复现空查询，再说明两种合理修复而非盲目加延时。

记录“复现步骤 → 观察证据 → 原因 → 修正 → 复验”，不要只写问题已经消失。

## 参考要点

- defer 保持解析后的执行时机及脚本顺序；async 不保证依赖顺序。
- 分享卡片、SEO 摘要和可见正文不是同一层内容。
