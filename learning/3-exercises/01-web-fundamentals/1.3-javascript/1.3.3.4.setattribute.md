# 1.3.3.4 独立练习

[配套笔记](../../../1-notes/01-web-fundamentals/1.3-javascript/1.3.3.4.setattribute.md) · [配套实验](../../../2-examples/01-web-fundamentals/1.3-javascript/1.3.3.4.setattribute-demo.html)

## 动手任务

1. 点击状态按钮，同时观察class、aria-pressed和dataset。

2. 给禁用属性写字符串false，再用removeAttribute恢复。

3. 项目应用：同步综合项目收藏按钮的class、aria-pressed与数据属性。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 外观与可访问状态一致。

- [ ] data-*仅放公开标识，不放机密或唯一业务状态。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

设置disabled="false"后发现控件仍禁用，解释布尔属性。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 能用样式类表达的外观通常优先classList，避免散落内联样式。

- 布尔属性以存在与否表达真/假，setAttribute("disabled","false")仍然禁用。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
