# 1.3.5.4 独立练习

[配套笔记](../../../1-notes/01-web-fundamentals/1.3-javascript/1.3.5.4.try-catch-finally.md) · [配套实验](../../../2-examples/01-web-fundamentals/1.3-javascript/1.3.5.4.try-catch-finally-demo.html)

## 动手任务

1. 模拟失败，确认finally仍恢复loading。

2. 把失败改为成功，确认状态恢复逻辑只需一处。

3. 项目应用：为综合项目异步操作统一恢复loading与安全提示。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 成功、失败、取消后均无悬挂loading。

- [ ] 用户提示不暴露原始凭据或敏感堆栈。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

在finally里return，说明原本异常或返回值为何被覆盖。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 不要空catch吞掉失败；区分用户可重试错误、程序错误与主动取消。

- 错误消息显示到页面要用textContent，不直接展示凭据、堆栈或服务器敏感内容。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
