## 动手任务

1. 预测块内 var 与 let 变量能否在块外访问。

2. 运行示例，确认属性修改成功、TDZ 错误被捕获而页面继续运行。

3. 项目应用：为综合项目区分固定配置const与可变筛选条件let，说明收藏数组的更新方式。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 列出至少两个固定绑定和两个变化状态。

- [ ] 说明const不冻结商品或收藏对象。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

把const对象重新赋值，比较它与修改属性分别是否报错。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 默认使用 const；确需重新赋值才用 let，维护旧代码时认识 var。

- 同一块内重复 let 声明是语法错误；读取 TDZ 中的绑定是 ReferenceError。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
