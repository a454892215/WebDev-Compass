## 动手任务

1. 用 typeof 观察各类原始值，特别检查 null。

2. 将 alias 改为新对象，验证 source 不会随绑定替换。

3. 项目应用：核对API项目id、数量、收藏状态的运行期类型，区分引用共享与值复制。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 记录当前API字符串id、字符串搜索词与布尔收藏状态的实际类型，再加入数字id变体验证协议。

- [ ] 指出一次共享对象修改可能影响原列表的位置。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

用重新绑定参数的方式试图替换调用方对象，找出未生效原因。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- number 为双精度浮点，整数精确范围受 Number.MAX_SAFE_INTEGER 限制。

- bigint 用于较大整数，不能直接与 number 做算术混用。
