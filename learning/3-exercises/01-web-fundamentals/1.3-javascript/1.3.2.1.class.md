# 1.3.2.1 独立练习

[配套笔记](../../../1-notes/01-web-fundamentals/1.3-javascript/1.3.2.1.class.md) · [配套实验](../../../2-examples/01-web-fundamentals/1.3-javascript/1.3.2.1.class-demo.html)

## 动手任务

1. 创建两个实例，验证私有计数各自独立。

2. 增加子类并用 super 调用父类逻辑，解释构造顺序。

3. 项目应用：比较综合项目状态用class还是模块/组合函数组织的成本，给出小型重构方案。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 解释实例状态、静态工具与私有字段的归属。

- [ ] 不为使用class而重写已经清楚的纯函数。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

在实例上调用静态方法，定位方法归属而不是加无意义兼容层。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 静态方法属于类本身，不能通过普通实例直接调用。

- 私有字段使用 #name，访问受类定义约束，不等同于普通命名约定。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
