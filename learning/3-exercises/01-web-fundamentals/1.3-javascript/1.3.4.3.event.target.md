# 1.3.4.3 独立练习

[配套笔记](../../../1-notes/01-web-fundamentals/1.3-javascript/1.3.4.3.event.target.md) · [配套实验](../../../2-examples/01-web-fundamentals/1.3-javascript/1.3.4.3.event.target-demo.html)

## 动手任务

1. 点击按钮内span，确认target为SPAN而currentTarget为父容器。

2. 把按钮移动到容器外，说明为什么还需contains检查。

3. 项目应用：先在练习副本给收藏按钮加入span或图标，再比较图标、按钮和列表空白处点击的target与动作识别；必要时修复定位。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 点击图标和按钮都命中同一动作。

- [ ] 使用currentTarget或有边界的closest。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

直接读取target.dataset却点击了按钮内span，定位动作识别失败。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 委托处理时用target.closest寻找业务按钮，再校验它确属当前容器。

- target可能不是Element，调用closest前需判断类型。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
