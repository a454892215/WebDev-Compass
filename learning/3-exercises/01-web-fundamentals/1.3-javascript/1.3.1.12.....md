# 1.3.1.12 独立练习

[配套笔记](../../../1-notes/01-web-fundamentals/1.3-javascript/1.3.1.12.....md) · [配套实验](../../../2-examples/01-web-fundamentals/1.3-javascript/1.3.1.12....-demo.html)

## 动手任务

1. 修改 copy.prefs.theme，解释原对象为何也改变。

2. 用逐层复制生成独立 prefs，再验证结果。

3. 项目应用：更新综合项目嵌套筛选配置，验证浅展开不会自动隔离嵌套对象。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 更新前后的对象共享关系可解释。

- [ ] 不把任意外部键无约束合并到配置。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

只做一层展开后修改嵌套配置，复现原数据被改变。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- {...source} 复制自身可枚举属性，不复制原型，也不深拷贝嵌套对象。

- 使用可选键时先校验外部输入，避免无约束地把任意键合并到配置对象。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
