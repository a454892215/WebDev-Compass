# 1.3.1.7 独立练习

## 动手任务

1. 比较 for...in 和 for...of 的索引/值以及类型。

2. 为对象添加继承属性，解释 Object.keys 与 for...in 的差异。

3. 项目应用：为综合项目列表处理选择合适遍历方式，并解释为何不for...in数组值。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 索引和值不混用。

- [ ] 如有异步批量操作，明确串行或并发选择。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

把for...of误改for...in，记录拿到的值与类型差异。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 数组里的 index 与 value 不同，for...in 的索引还是字符串。

- 异步循环里 forEach 不等待返回的 Promise；串行处理用 for...of + await，并发可用 Promise.all。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
