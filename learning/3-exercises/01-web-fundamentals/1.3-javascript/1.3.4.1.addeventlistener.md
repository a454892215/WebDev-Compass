# 1.3.4.1 独立练习

[配套笔记](../../../1-notes/01-web-fundamentals/1.3-javascript/1.3.4.1.addeventlistener.md) · [配套实验](../../../2-examples/01-web-fundamentals/1.3-javascript/1.3.4.1.addeventlistener-demo.html)

## 动手任务

1. 运行后点击触发按钮一次，再点解除监听，确认后续点击不增加。

2. 把两个监听器交给同一个AbortController，验证共同清理。

3. 项目应用：给综合项目视图装配统一的事件订阅与清理入口。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 重复装配不叠加监听。

- [ ] 销毁后旧监听不能再修改界面。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

用新建箭头函数removeEventListener，复现监听未解除。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 重复创建的箭头函数不是同一个引用，无法靠相同源码正确remove。

- 组件卸载、页面切换或实验重跑时清理监听器。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
