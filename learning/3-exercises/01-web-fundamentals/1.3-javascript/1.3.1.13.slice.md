## 动手任务

1. 比较 A😀 的 length 和码点数。

2. 输入中文/emoji，观察 trim、split、replaceAll 生成的新值。

3. 项目应用：处理综合项目搜索词和长文本展示，区分正规化、截断与安全输出。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 中文和emoji搜索不因简单索引切割而损坏。

- [ ] 所有搜索输入经textContent展示。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

按UTF-16索引截断emoji，解释字符破损和用户可见字符边界。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 用户可见文本截断要考虑 emoji、组合音标与字素分割，不能盲按 length 切。

- replace 的字符串模式只替换首个匹配；全替换可用 replaceAll 或合适的全局正则。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
