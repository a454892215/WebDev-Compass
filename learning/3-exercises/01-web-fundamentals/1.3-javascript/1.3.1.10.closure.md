# 1.3.1.10 独立练习

[配套笔记](../../../1-notes/01-web-fundamentals/1.3-javascript/1.3.1.10.closure.md) · [配套实验](../../../2-examples/01-web-fundamentals/1.3-javascript/1.3.1.10.closure-demo.html)

## 动手任务

1. 独立创建 a/b，验证计数互不影响。

2. 为其中一个闭包增加 reset，解释变量为何仍可访问。

3. 项目应用：用工厂闭包为两个独立列表建立独立筛选/计数环境。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 两个实例状态互不影响。

- [ ] 说明闭包引用DOM和订阅时的清理责任。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

把两个计数器改为共享同一个外层绑定，复现互相影响。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 闭包适合私有计数器、参数化回调与组合式逻辑，但不是安全隔离边界。

- 长期保存回调可能同时保留 DOM 或大对象，清理订阅仍然必要。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
