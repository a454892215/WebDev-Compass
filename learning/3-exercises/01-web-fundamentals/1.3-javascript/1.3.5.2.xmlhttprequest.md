# 1.3.5.2 独立练习

## 动手任务

1. 读取本地fixture并观察status与responseText。

2. 把URL改为不存在资源，确认load与HTTP成功是不同判断。

3. 项目应用：分析综合项目若接入旧XHR接口的适配边界。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] load中检查status，能取消并区分超时。

- [ ] 不为新代码默认重写为XHR。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

只检查onload而忽略status，复现404被当成功。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 使用异步XHR，避免同步请求阻塞页面。

- load中检查status范围，不能见到onload就当业务成功。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
