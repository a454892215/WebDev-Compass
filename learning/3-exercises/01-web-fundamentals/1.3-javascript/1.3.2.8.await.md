# 1.3.2.8 独立练习

[配套笔记](../../../1-notes/01-web-fundamentals/1.3-javascript/1.3.2.8.await.md) · [配套实验](../../../2-examples/01-web-fundamentals/1.3-javascript/1.3.2.8.await-demo.html)

## 动手任务

1. 点击实验，观察真正导入ready.mjs后取得的ready值。

2. 查看Network与源码，确认await发生在被导入模块顶层而非伪造字符串。

3. 项目应用：评估综合项目初始化是否适合顶层await，对关键路径和失败回退做说明。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 能演示真实依赖模块等待。

- [ ] 不为每个请求强行引入顶层await。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

在模块初始化依赖中加入失败，观察导入者的错误边界。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 浏览器代码必须使用type=module；经典script里直接写await会语法错误。

- 启动关键路径不要无边界等待远程服务，超时、失败回退和依赖关系要明确。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
