## 动手任务

1. 比较200px border-box元素的offset、client与缩放后rect。

2. 滚动页面后重测rect.top，解释变化来源。

3. 项目应用：测量综合项目卡片和滚动区域，定位窄屏溢出。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 明确offset/client/rect各自用途。

- [ ] 不在循环里反复交错布局读写。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

用offsetWidth判断transform后的视觉宽度，定位测量API选错。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 需要文档坐标时可结合scrollX/scrollY，而不是假设rect.top固定不变。

- 频繁交错写样式与同步读布局可能触发额外布局，集中读写并基于测量优化。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
