## 动手任务

1. 用同一个对象与新建对象分别get Map。

2. 给WeakMap传字符串并捕获TypeError；不编写等待GC通过的测试。

3. 项目应用：为综合项目收藏去重选择Set，为按id查找选择Map，评估WeakMap是否需要。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 对象身份、字符串id和序列化策略明确。

- [ ] 不写依赖GC时机的验收。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

把两个同字段对象当作同一Map键，记录查找失败原因。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- Map/Set按插入顺序迭代；对象键比较的是身份，不是字段深相等。

- Weak集合没有可靠size/遍历接口，不能观察或依赖GC何时运行。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
