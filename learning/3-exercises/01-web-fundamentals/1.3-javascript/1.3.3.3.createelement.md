# 1.3.3.3 独立练习

[配套笔记](../../../1-notes/01-web-fundamentals/1.3-javascript/1.3.3.3.createelement.md) · [配套实验](../../../2-examples/01-web-fundamentals/1.3-javascript/1.3.3.3.createelement-demo.html)

## 动手任务

1. 用创建、插入、移动、删除构造可观察列表。

2. 给节点加监听器后克隆，验证其交互并讨论事件委托。

3. 项目应用：为综合项目新增一条列表项，完成安全创建、插入与移除。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 输入不经innerHTML执行。

- [ ] 能解释append现有节点是移动而非复制。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

把已有节点append到新位置却期望复制，定位节点为何消失。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 少量节点用清晰DOM操作即可，不为性能猜测过早批量优化。

- removeChild要求节点确实属于该父节点，element.remove可更直接移除自己。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
