# 1.3.4.4 独立练习

[配套笔记](../../../1-notes/01-web-fundamentals/1.3-javascript/1.3.4.4.preventdefault.md) · [配套实验](../../../2-examples/01-web-fundamentals/1.3-javascript/1.3.4.4.preventdefault-demo.html)

## 动手任务

1. 运行后提交本地表单，确认URL不变且defaultPrevented=true。

2. 点击停止冒泡按钮，确认父容器日志没有对应事件。

3. 项目应用：为综合项目搜索表单取消默认导航，保留键盘提交与父层事件协作。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 提交不会意外刷新页面。

- [ ] 说明preventDefault与stopPropagation的不同。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

只stopPropagation却期望阻止表单默认提交，解释两个维度。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 先看event.cancelable和具体浏览器默认行为；不能取消的事件调用preventDefault无效。

- 表单本地预览可取消submit默认导航，但仍应保留原生输入验证。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
