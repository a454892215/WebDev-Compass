# 1.3.4.5 独立练习

[配套笔记](../../../1-notes/01-web-fundamentals/1.3-javascript/1.3.4.5.click.md) · [配套实验](../../../2-examples/01-web-fundamentals/1.3-javascript/1.3.4.5.click-demo.html)

## 动手任务

1. 输入文本再移开焦点，比较input与change。

2. 按Enter提交并确认本地处理，不产生真实请求。

3. 项目应用：完善综合项目搜索输入、Enter提交及焦点事件，考虑中文输入法。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] input/change/submit职责清楚。

- [ ] 不只用keydown拼接文本，组合输入期间策略明确。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

只用keydown追踪文字，说明粘贴或输入法为何遗漏。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 文本输入与中文输入法组合过程需考虑isComposing等状态，不应只用keydown推断文本。

- 按钮用click支持鼠标与键盘激活，避免只监听mousedown/touchstart。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
