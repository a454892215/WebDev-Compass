# 1.3.2.2 独立练习

[配套笔记](../../../1-notes/01-web-fundamentals/1.3-javascript/1.3.2.2.import.md) · [配套实验](../../../2-examples/01-web-fundamentals/1.3-javascript/1.3.2.2.import-demo.html)

## 动手任务

1. 通过Network观察首次点击触发实际math.mjs请求。

2. 对比静态import与示例动态import的加载时机，确认模块命名导出。

3. 项目应用：把综合项目数据请求与UI渲染拆为真实ESM模块。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 导出契约清楚且没有跨模块改只读导入绑定。

- [ ] 通过HTTP观察正确的模块URL与加载行为。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

把type=module改为经典script，记录静态import语法错误并恢复。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- HTML 用 script type="module"；浏览器模块路径须是正确URL，裸包名需要构建工具或import map。

- 浏览器跨源模块需要合适CORS；本地教学用HTTP同源服务，避免file URL限制。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
