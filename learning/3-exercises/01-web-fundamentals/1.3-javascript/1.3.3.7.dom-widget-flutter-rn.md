# 1.3.3.7 独立练习

## 动手任务

1. 比较只修改模型与调用render后的画面差异。

2. 解释在Vue中应把哪部分变为响应式状态和模板，而不是复制整套手动render。

3. 项目应用：分析综合项目手动render与声明式UI的职责；Vue模板仅作后续预告，不要求本阶段先掌握Vue实现。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 模型和DOM能保持一致。

- [ ] 第三方DOM控制限定在适配边界。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

只修改模型不调用render，解释界面没有同步的原因。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 以DOM实验认识底层机制，不把手写查询散落到每个Vue组件。

- 第三方图表、焦点和测量等场景可通过明确引用适配，并在卸载时清理。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
