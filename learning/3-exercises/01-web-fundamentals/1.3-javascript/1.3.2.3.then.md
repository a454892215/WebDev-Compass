## 动手任务

1. 观察同步开始/结束与then回调的先后。

2. 在链中抛错，再catch恢复为数值，预测后续then和finally。

3. 项目应用：在练习分支把一次load流程改写为Promise链，返回调用方可检查的结果，并安排catch提示和finally恢复；参考实现使用async/await。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 错误可被调用方观察。

- [ ] 请求结束后loading恢复且无未处理拒绝。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

then里漏return异步步骤，复现外层链过早结束。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 在then内启动异步步骤时return它，否则外层链不会等待该步骤。

- catch处理前面链上的拒绝；catch正常返回值会把链恢复成fulfilled。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
