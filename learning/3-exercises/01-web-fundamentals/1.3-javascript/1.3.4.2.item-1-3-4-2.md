# 1.3.4.2 独立练习

[配套笔记](../../../1-notes/01-web-fundamentals/1.3-javascript/1.3.4.2.item-1-3-4-2.md) · [配套实验](../../../2-examples/01-web-fundamentals/1.3-javascript/1.3.4.2.item-1-3-4-2-demo.html)

## 动手任务

1. 点击内层按钮，预测外捕获、内目标、外冒泡的顺序。

2. 将外层处理改为只捕获，确认日志变化。

3. 项目应用：跟踪综合项目卡片与收藏按钮的传播路径，解释事件阶段。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 能复现捕获/目标/冒泡顺序。

- [ ] 不依赖不必要的全局事件拦截。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

假定focus会像click冒泡，解释应选capture或focusin。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 用capture:true订阅捕获阶段，默认通常在冒泡阶段处理。

- 注册顺序会影响同一节点同阶段监听器顺序，目标阶段仍需区分capture注册。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
