# 1.3.5.5 独立练习

## 动手任务

1. 观察同步代码先于零延迟回调。

2. 等待三次interval后确认它停止，rAF只报告调度并可清理。

3. 项目应用：在项目副本新增可取消的延迟搜索或定时刷新，另可选加入动画帧；实现销毁清理，不假定参考项目已有这些计时器。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 离开视图后无继续更新。

- [ ] 不以精确毫秒作为后台页面正确性依据。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

不清理interval并重复进入视图，复现重复更新后修复。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 组件卸载或任务失效时clearTimeout/clearInterval/cancelAnimationFrame。

- 频繁异步请求不宜无边界setInterval堆叠，可在上次结束后再调度。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
