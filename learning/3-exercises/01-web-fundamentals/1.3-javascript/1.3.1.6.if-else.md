# 1.3.1.6 独立练习

[配套笔记](../../../1-notes/01-web-fundamentals/1.3-javascript/1.3.1.6.if-else.md) · [配套实验](../../../2-examples/01-web-fundamentals/1.3-javascript/1.3.1.6.if-else-demo.html)

## 动手任务

1. 选择加载、失败和就绪状态，检查只有一个结果。

2. 移除一处 break，在单独实验中观察贯穿并恢复。

3. 项目应用：把综合项目loading/empty/error/success转换为互斥界面状态。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 每个状态有清楚反馈且不会同时显示冲突面板。

- [ ] 未知状态有安全的降级分支。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

删除switch分支的break/return，观察意外贯穿并修复。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 多个互斥条件用 else if 或提前返回，避免多个独立 if 意外叠加。

- switch 的 case 后通常需要 break；有意贯穿时应注释意图。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
