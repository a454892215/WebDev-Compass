## 动手任务

1. 为p增加一段文本和strong元素，对比两种集合。

2. 在Elements里观察空白Text节点，解释firstChild为何可能不是标签。

3. 项目应用：用DevTools审查综合项目列表中的Element/Text与实际渲染结构。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 能解释children与childNodes差异。

- [ ] 没有用firstChild盲目假定标签节点。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

用firstChild读取标签属性，但源代码前有文本，定位节点类型。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 不能假设firstChild一定是元素，按目标选择firstElementChild或明确查询。

- textContent汇总后代文本；修改它会替换该节点的子节点。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
