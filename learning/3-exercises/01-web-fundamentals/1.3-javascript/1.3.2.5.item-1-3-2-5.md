# 1.3.2.5 独立练习

[配套笔记](../../../1-notes/01-web-fundamentals/1.3-javascript/1.3.2.5.item-1-3-2-5.md) · [配套实验](../../../2-examples/01-web-fundamentals/1.3-javascript/1.3.2.5.item-1-3-2-5-demo.html)

## 动手任务

1. 连续调用next直到done=true，观察最终return值。

2. 用展开语法消费同一生成器两次，解释第二次为何为空。

3. 项目应用：评估综合项目分页是否需要生成器，给出适用性分析和一个小序列实现。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 明确生成器是按需取值，不是后台线程。

- [ ] 允许结论为无需生成器，并有理由。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

重复消费同一个生成器，说明第二次序列为何为空。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- for...of消费可迭代协议，普通对象不会因为有属性就自动可迭代。

- 生成器return值出现在最终next结果，但不会被普通for...of当作序列元素。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
