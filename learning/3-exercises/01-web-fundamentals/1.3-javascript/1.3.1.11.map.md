# 1.3.1.11 独立练习

## 动手任务

1. 对空数组计算 sum，解释初始值的作用。

2. 筛选商品后改变其中一个对象，观察原数据是否也变化。

3. 项目应用：用filter/find/some/reduce实现综合项目筛选、详情查找和统计。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 空列表统计有初始值。

- [ ] 不为获得新数组而意外修改领域对象。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

移除reduce初始值后给空数组，解释异常与边界修复。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- map 返回新数组不代表元素深拷贝；对象引用可能仍共享。

- reduce 尽量提供初始值，否则空数组可能抛错。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
