# 1.3.1.4 独立练习

[配套笔记](../../../1-notes/01-web-fundamentals/1.3-javascript/1.3.1.4.number.md) · [配套实验](../../../2-examples/01-web-fundamentals/1.3-javascript/1.3.1.4.number-demo.html)

## 动手任务

1. 分别输入空串、2、abc，观察空值、有效值和无效值分支。

2. 比较直接 raw+1 与 Number(raw)+1。

3. 项目应用：在项目副本新增可选页码/数量参数，再校验文本，区分空串、0和无效数字；参考项目尚无分页功能。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 空页码有明确默认策略，abc被拒绝。

- [ ] 不因字符串加法把2+1变成21。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

把数量文本直接加1，输入2与空串，定位拼接和空值转换问题。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- Number("") 和 Number(" ") 为 0，空输入需要先单独判断。

- Boolean("false") 为 true，非空字符串不按单词含义转换。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
