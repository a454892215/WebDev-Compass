# 1.3.1.9 独立练习

[配套笔记](../../../1-notes/01-web-fundamentals/1.3-javascript/1.3.1.9.item-1-3-1-9.md) · [配套实验](../../../2-examples/01-web-fundamentals/1.3-javascript/1.3.1.9.item-1-3-1-9-demo.html)

## 动手任务

1. 修改局部 theme，确认外层 theme 不变。

2. 创建嵌套函数，画出变量查找顺序。

3. 项目应用：将综合项目临时变量限制在函数或模块中，避免无关全局共享。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 能指出一个局部遮蔽与一个模块边界。

- [ ] 不依赖window自动产生的元素ID变量。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

在内层声明同名变量遮蔽外层，定位实际读取的绑定。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 尽量缩小变量作用域，避免多个 UI 操作共享不必要的可变全局。

- 局部同名变量会遮蔽外层变量，调试时先确认所读绑定。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
