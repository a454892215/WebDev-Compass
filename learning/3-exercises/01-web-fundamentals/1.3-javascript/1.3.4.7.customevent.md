# 1.3.4.7 独立练习

[配套笔记](../../../1-notes/01-web-fundamentals/1.3-javascript/1.3.4.7.customevent.md) · [配套实验](../../../2-examples/01-web-fundamentals/1.3-javascript/1.3.4.7.customevent-demo.html)

## 动手任务

1. 先注册父容器监听，再发送带detail的冒泡事件。

2. 移除bubbles:true，解释父容器为何收不到。

3. 项目应用：评估综合项目跨区域刷新是否需要CustomEvent，并定义detail契约。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 事件名称、传播和detail字段明确。

- [ ] 允许直接函数调用更合适时不引入事件总线。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

省略bubbles却期望父节点接收，复现并说明传播契约。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 为事件命名和detail结构定义契约，接收方仍应校验来源与数据。

- detail可共享对象引用，事件不是自动深拷贝或不可变消息。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
