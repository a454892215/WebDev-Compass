## 动手任务

1. 用retries=0比较??=与||=的结果。

2. 分别设置title为空串和null，说明产品规则应怎样决定默认值。

3. 项目应用：检查综合项目默认设置中的||、??与逻辑赋值，保护合法空值策略。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 0、false、空串分别按业务规则处理。

- [ ] 可选链不被当作数据校验。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

将??=换为||=并输入false或0，说明默认值策略差异。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 配置默认值一般优先??，但业务若明确把空串视为未填，应单独表达。

- ?.不能放在普通赋值目标左侧，也不会捕获函数内部错误。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
