# 1.3.5.6 独立练习

[配套笔记](../../../1-notes/01-web-fundamentals/1.3-javascript/1.3.5.6.json.parse.md) · [配套实验](../../../2-examples/01-web-fundamentals/1.3-javascript/1.3.5.6.json.parse-demo.html)

## 动手任务

1. 观察undefined、null和Date序列化后的差异。

2. 解析合法但字段不符的数据，要求独立的协议校验失败提示。

3. 项目应用：校验综合项目接口JSON和收藏存储结构。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 坏JSON与合法但结构不符的数据都被处理。

- [ ] 不把JSON往返用作所有对象的深复制。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

用JSON往返复制Date或BigInt，记录类型变化或异常。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 外部JSON解析后仍需验证类型、必需字段和范围，再映射到领域模型。

- 日期通常变成字符串，Map/Set、函数、原型和undefined不会按原语义保留。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
