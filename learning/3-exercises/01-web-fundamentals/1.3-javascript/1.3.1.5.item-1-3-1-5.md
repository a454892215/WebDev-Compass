## 动手任务

1. 保留数量0，比较 || 与 ?? 的输出。

2. 将 user 改为缺 profile 的对象，检查可选链的边界。

3. 项目应用：给综合项目分页大小和可选描述设置默认值，保留合法的0/false。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 对0、null、undefined分别说明处理结果。

- [ ] 默认值不会掩盖协议错误。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

用||覆盖数量0，说明错误结果并选择合适规则。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 业务判断默认用严格相等；NaN 与任何值都不严格相等，应使用 Number.isNaN。

- 0、false 和空字符串可能是有效值，不能一律用 || 覆盖。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
