# 1.3.1.14 独立练习

[配套笔记](../../../1-notes/01-web-fundamentals/1.3-javascript/1.3.1.14.js-dart-kotlin-swift-vs.md) · [配套实验](../../../2-examples/01-web-fundamentals/1.3-javascript/1.3.1.14.js-dart-kotlin-swift-vs-demo.html)

## 动手任务

1. 运行对照，明确字符串相加与数值相加。

2. 列出原生App与浏览器在存储、安全和导航上的三项差异。

3. 项目应用：审查综合项目从移动端经验迁移时的三个JS/Web差异。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 举出动态类型、对象共享及页面生命周期的具体代码位置。

- [ ] 说明未来TS也不替代运行期解码。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

将API字符串数量误当数字，提出解析、范围和协议三层检查。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 把网络数据视为 unknown 语义并校验，而不是靠强制断言跳过解析。

- 区分 undefined 的缺失和业务协议中的 null；JSON 不会保留所有 JS 值。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
