# 1.3.3.5 独立练习

[配套笔记](../../../1-notes/01-web-fundamentals/1.3-javascript/1.3.3.5.textcontent.md) · [配套实验](../../../2-examples/01-web-fundamentals/1.3-javascript/1.3.3.5.textcontent-demo.html)

## 动手任务

1. 输入包含strong标签的文本，确认DOM里没有因此新增strong。

2. 只用代码里固定可信常量对比HTML解析，禁止让输入走innerHTML。

3. 项目应用：让综合项目安全显示恶意形状的标题或错误文本。 先写预期与边界，再修改自己的练习副本；不要只复制示例日志。

## 验收标准

- [ ] 包含尖括号的输入以文本显示。

- [ ] DOM没有由该输入创建脚本或事件属性。

- [ ] 能不用逐行提示说明原因，并在一个变体输入上重复验证。

- [ ] 记录一个正常输入与一个边界输入，以及实际结果；将机械通过与自己的机制解释分开。

## 排错任务

审查一段把外部文本交给innerHTML的代码，只用静态样本分析风险并改textContent；不要执行真实攻击。

复现后记录：现象、最小触发条件、错误发生的作用域/节点/异步阶段、修复与回归。错误示例必须捕获或隔离，不让课程页面产生未处理异常。

## 参考要点

- 用户输入、接口错误消息和日志默认走textContent。

- 确需富文本时使用可信的净化方案与明确允许列表，并配合安全策略，而不是自写正则过滤。

先用配套笔记的“工作机制”解释结果，再检查源码。参考要点是提示，不是声称已完成练习；预期错误、网络模拟与真实环境结果必须区分。官方来源见配套笔记。
