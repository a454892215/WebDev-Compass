# 6.3.7 独立练习：axe与Lighthouse：自动发现、人工验证和回归边界

## 动手任务

在Nuxt当前页面/表单错误/dialog状态分别保存axe结果，保留incomplete清单并用键盘补验；可选运行Lighthouse，但单独记录版本和范围。

先在副本独立完成，保留自己的证据再对照参考。

## 验收标准

- [ ] 坏样本或受控缺陷能使检查失败，修复后相同范围恢复。
- [ ] 报告明确规则/版本/状态与人工未测项，不用零违规宣称完整WCAG符合。

## 排错任务

检查脚本只扫空白页而得到零违规；先断言h1/表单存在，再注入缺名称按钮证明检测有覆盖，最终恢复真实页面。

记录输入/状态→现象→原因→修复→同条件复验，不只写“已解决”。

## 参考要点

- axe-core可在浏览器页面运行规则，结果含violations/incomplete/passes等；incomplete需要进一步检查，不等于通过。工具的标签/规则覆盖随版本变化，应记录版本、页面、状态与选用规则。
- 先用受控坏样本证明检查真的会失败，再修复并回归。键盘、缩放、dialog动态状态、真实辅助技术需组合证据；不要为提高分数删除业务内容或忽略真实问题。
