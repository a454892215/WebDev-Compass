# 6.3.1 独立练习：WCAG 2.2：等级、范围与验收证据

## 动手任务

为Nuxt目录的列表、详情、dialog与错误反馈建立一张小范围验收表，记录自动、键盘、视觉与未测证据；不要求照抄所有WCAG条款。

先在副本独立完成，保留自己的证据再对照参考。

## 验收标准

- [ ] 能区分A/AA/AAA、适用范围与检测覆盖，不用分数替代符合性。
- [ ] 至少一种动态失败状态有实际操作证据，自动无法证明的条目标明人工/辅助技术待验。

## 排错任务

把axe零违规改写成“本网站完全符合WCAG AA”；对照弹窗/缩放/真实读屏的未测范围，修正结论并补相应计划。

记录输入/状态→现象→原因→修复→同条件复验，不只写“已解决”。

## 参考要点

- WCAG 2.2按可感知、可操作、可理解、健壮组织，成功准则分A/AA/AAA。宣称AA需满足该范围内所有适用A与AA，不是只满足若干常见规则或axe得分。WCAG标准与Understanding/APG技术说明用途不同，后者帮助解释而非另立强制规则。
- 本地lab只给特定页面和交互的部分证据：axe、焦点、受控文字放大等。没有真实屏幕阅读器/残障用户测试，不给完整符合性认证。
