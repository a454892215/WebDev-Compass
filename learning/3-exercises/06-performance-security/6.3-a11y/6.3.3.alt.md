# 6.3.3 独立练习：替代文本、可访问名称和ARIA的正确边界

## 动手任务

为Nuxt课程图和图标分别判断信息/装饰用途，写最短有效替代文本并审查按钮名称；不要为避免报错给所有图片同一alt。

先在副本独立完成，保留自己的证据再对照参考。

## 验收标准

- [ ] 信息图含任务相关等价描述，装饰图不会制造重复名称。
- [ ] 所有可操作图标/按钮有准确名称，无aria-hidden下仍可聚焦控件。

## 排错任务

删掉纯图标按钮文字且不提供名称，运行axe看到button-name；补恰当可见文案或名称，复查不要覆盖已有正确名称。

记录输入/状态→现象→原因→修复→同条件复验，不只写“已解决”。

## 参考要点

- 信息图像的alt描述其在当前任务的意义；装饰图像可用alt=""，复杂图表还需等价文字/数据说明。不能机械把文件名当alt，也不是所有图标都应加同一名称。
- 不要把aria-hidden=true放在可聚焦元素或其仍可聚焦祖先。原生button已有正确role通常不重复role=button；按钮中的装饰SVG隐藏而按钮保留可见文字。
