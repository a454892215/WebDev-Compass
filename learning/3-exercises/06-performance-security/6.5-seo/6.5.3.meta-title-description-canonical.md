# 6.5.3 独立练习：title、description、canonical与多语言对应URL

## 动手任务

对三种locale的课程详情核对自指canonical、互返hreflang、查询页noindex，并在导航后检查无陈旧标题/描述。

先在副本独立完成，保留自己的证据再对照参考。

## 验收标准

- [ ] SSR和客户端导航的title/description与当前页面一致。
- [ ] canonical来自可信基址，语言映射正确且不混用查询；noindex与robots不互相阻断。

## 排错任务

客户端换到另一课程却沿用旧title/canonical，或把恶意Host反射入canonical；改响应式生成和可信siteUrl，再验证SSR/导航。

记录输入/状态→现象→原因→修复→同条件复验，不只写“已解决”。

## 参考要点

- title应准确描述页面，description提供有用摘要；搜索系统可能重写展示内容，并非写了就必定原样显示。Nuxt用响应式useHead/useSeoMeta同时考虑SSR和客户端导航更新，不能只在mounted修改document.title。
- 查询/筛选页若选择noindex需与robots抓取策略配合，避免禁止抓取导致机器人看不到noindex。canonical去q是本项目明确取舍，不代表所有网站过滤参数都可无条件删除。
