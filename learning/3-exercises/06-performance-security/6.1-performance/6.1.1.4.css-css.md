# 6.1.1.4 独立练习：关键CSS、非关键样式与闪烁边界

## 动手任务

在Nuxt副本检查首屏必要样式、非首屏组件和打印样式，画依赖清单；只改一处后比较首屏/无JS/焦点与布局。

先在副本实现/观察，保存自己的操作和结果，再核对参考。

## 验收标准

- [ ] 关键内容与焦点样式没有晚到，样式分离有实际依赖依据。
- [ ] 记录HTML增量/缓存取舍，CSP或无JS条件不会使主内容无样式。

## 排错任务

把全部样式设media=print后靠JS改回all，关闭JS观察未恢复；按实际需要改为正常关键表和可选媒体表，不能用更长固定等待补救。

记录具体输入、现象、原因、修复和复验，不只写“已解决”。

## 参考要点

- 当前lab主样式仍正常加载，清单是独立改造任务。
- 不把某框架自动产物与手写preload技巧混为同一个保证。
