# 6.1.3.2 独立练习：Service Worker：公开白名单、离线与更新

## 动手任务

在独立lab副本升级v2并设计旧页面/新worker策略；不要给主Nuxt私人数据或未知API开全站缓存。

先在副本实现/观察，保存自己的操作和结果，再核对参考。

## 验收标准

- [ ] 缓存仅明确公开GET白名单；错误/未命中回退有状态，不缓存私有数据。
- [ ] 更新/注销只影响自己前缀与scope，离线/版本变化均真实观察。

## 排错任务

fetch事件无条件cache.put所有请求，把会话API也缓存；以白名单和身份边界定位，清理本实验错误缓存并重验，不删除其他项目缓存。

记录具体输入、现象、原因、修复和复验，不只写“已解决”。

## 参考要点

- 本轮不是完整PWA/生产更新/存储配额认证。
- 离线测试要真实切断请求，不能仅切一个UI标签。
