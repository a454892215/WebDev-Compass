# 6.1.1.3 独立练习：图片：格式、尺寸、srcset与加载时机

## 动手任务

给副本一张真实公开内容图片补picture回退和sizes，在两种宽度记录候选、布局宽度、传输量及替代文本；保留首屏不lazy。

先在副本实现/观察，保存自己的操作和结果，再核对参考。

## 验收标准

- [ ] 候选文件真实可解码、currentSrc属于声明集合，下载前后比例稳定。
- [ ] 首屏/离屏策略按位置区分，sizes反映实际CSS，质量与无障碍没有被忽略。

## 排错任务

把首屏图lazy，或sizes写100vw但桌面实际上只有640px；对照Network候选和布局，修正后同条件复验，不只改扩展名。

记录具体输入、现象、原因、修复和复验，不只写“已解决”。

## 参考要点

- 浏览器可因缓存/网络选择不同候选，不能硬写“手机必选320”。
- 固定尺寸不等于固定CSS宽度；保持响应式缩放。
