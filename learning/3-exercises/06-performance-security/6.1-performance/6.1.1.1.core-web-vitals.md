# 6.1.1.1 独立练习：Core Web Vitals：场数据与实验数据

## 动手任务

为同一页面制定一次加载/一次交互/一次位移的观测说明，分别指出可以由lab证明什么、还缺哪些field数据。

先在副本实现/观察，保存自己的操作和结果，再核对参考。

## 验收标准

- [ ] LCP/INP/CLS名称、单位、良好阈值和p75口径准确，不把TBT叫INP。
- [ ] 记录环境/操作/原始条目与限制，未用单次Lighthouse分数证明生产达标。

## 排错任务

把一次90ms longtask直接记作“INP=90ms、已达标”，指出其没有完整交互/访问算法与field样本；改记录为诊断条目并注明缺证据。

记录具体输入、现象、原因、修复和复验，不只写“已解决”。

## 参考要点

- 先度量目标，再选动作；分数不是用户价值的替代品。
- 实验与场数据可能因设备、网络、生命周期不同而不同。
