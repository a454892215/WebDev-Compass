# 6.2.6 独立练习：CORS错误配置：凭据读取与来源白名单

## 动手任务

为一个Nuxt外部API对接画出浏览器→宿主→API两跳，明确哪跳需要CORS、哪跳转发凭据。在隔离lab比较精确白名单与反射误配。

先在副本独立完成，保留命令、输入和实际结果，不逐行复制观察输出。

## 验收标准

- [ ] 不可信来源无法读取受保护响应；允许来源仍可正常运行。
- [ ] 不把CORS当认证/CSRF，不把dev代理的成功当生产部署证明。

## 排错任务

通配+credentials被阻止后，为“修复”而改成反射所有Origin，真实读取反而成功；恢复精确白名单再测恶意源与合法源。

记录故障输入→实际结果→原因→修复→复验，不能只写已解决。

## 参考要点

- 源包含scheme/host/port，站点不是相同概念。
- 仅测试curl成功不能证明浏览器CORS正确。
