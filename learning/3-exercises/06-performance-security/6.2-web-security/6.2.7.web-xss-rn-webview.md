# 6.2.7 独立练习：移动经验迁移：Web、原生UI与WebView脚本边界

## 动手任务

把已知移动项目的一处WebView需求写成边界图：谁加载页面、哪些来源可导航、谁能发消息、哪些原生能力可调用，并对照本地Web消息检查。

先在副本独立完成，保留命令、输入和实际结果，不逐行复制观察输出。

## 验收标准

- [ ] 每项类比都指出平台差异和权限边界，没有宣称DOM与原生控件等价。
- [ ] 没有让任意页面/消息执行原生能力；未做真机明确写未测。

## 排错任务

只检查消息type不检查origin/source，伪造来自其他窗口的同形对象；恢复来源与实例/schema验证，拒绝未授权操作。

记录故障输入→实际结果→原因→修复→复验，不能只写已解决。

## 参考要点

- 源限制、消息契约和原生能力授权是多层防线。
- 需要实际移动实现时按对应平台/版本官方指南另验。
