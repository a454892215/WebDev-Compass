# 6.2.1 独立练习：XSS：按输出上下文防护，而非依赖HttpOnly

## 动手任务

在副本添加一个只允许em的富文本场景，并列出数据源、sink和允许策略；主Nuxt目录继续使用文本插值，不为展示例子引入v-html。

先在副本独立完成，保留命令、输入和实际结果，不逐行复制观察输出。

## 验收标准

- [ ] 恶意形状标题只作为文本；富文本只留下明确允许内容，事件属性/危险URL不能执行。
- [ ] 能分别解释净化、CSP和HttpOnly的作用，没有声称其中任意一个单独解决全部XSS。

## 排错任务

把净化后的HTML再拼接原始input，安全边界会被绕过；在隔离fixture观察后改为一次净化最终HTML或完全采用文本，重跑同一输入。

记录故障输入→实际结果→原因→修复→复验，不能只写已解决。

## 参考要点

- 先选择合适输出上下文，再考虑必要净化。
- 更新净化库并测试实际允许内容；不运行不可信外网脚本。
