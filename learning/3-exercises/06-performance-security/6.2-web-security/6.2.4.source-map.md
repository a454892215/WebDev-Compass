# 6.2.4 独立练习：前端秘密与Source Map：构建、发布和读取边界

## 动手任务

在Nuxt副本列出public配置、SSR payload、JS/map与服务端配置发布路径；对一个无秘密标记建立客户端资产扫描，写清扫描不能保证什么。

先在副本独立完成，保留命令、输入和实际结果，不逐行复制观察输出。

## 验收标准

- [ ] 私有合成标记不进入公开产物，公开标签可以在客户端看到。
- [ ] 能核实map是否生成/发布/可读，不把hidden或压缩当秘密保护。

## 排错任务

误将server-only标记导入客户端模块，扫描应失败；移回真正服务端边界重新build，修复路径而非删掉检测器。

记录故障输入→实际结果→原因→修复→复验，不能只写已解决。

## 参考要点

- 任何真实泄露先按凭据性质撤销/轮换。
- 浏览器中用于调用公开API的可发布标识与服务端秘密不是同类。
