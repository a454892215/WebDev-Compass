# 6.2.2 独立练习：CSRF：凭据自动携带、Origin与会话绑定Token

## 动手任务

在lab副本给一个变更端点增加内容类型与Origin/token失败测试；主Nuxt公开表单只做本地反馈，若新增认证写入必须先引入明确会话契约。

先在副本独立完成，保留命令、输入和实际结果，不逐行复制观察输出。

## 验收标准

- [ ] 跨站/缺token的变更被服务端拒绝，失败后业务计数未变。
- [ ] 能指出SameSite/HttpOnly/CORS的不同作用，不把响应不可读当请求未发送。

## 排错任务

只移除CORS响应头却保留无保护的写操作，攻击者可能仍改变状态；对照Network与计数，恢复服务端变更前校验后复验。

记录故障输入→实际结果→原因→修复→复验，不能只写已解决。

## 参考要点

- Origin按完整可信源比较，不做任意后缀匹配。
- token失效、会话轮换和重试必须协调，不能无限自动重放写。
