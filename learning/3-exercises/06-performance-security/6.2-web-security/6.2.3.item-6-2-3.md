# 6.2.3 独立练习：点击劫持：frame-ancestors与嵌入需求

## 动手任务

确认Nuxt主项目是否需要被iframe嵌入；比较默认拒绝与一个明确伙伴源策略，在本地父页实际验证，而不是只复制头。

先在副本独立完成，保留命令、输入和实际结果，不逐行复制观察输出。

## 验收标准

- [ ] 默认保护页无法在未授权父源内执行，正常顶层访问可用。
- [ ] 能区分frame-src与frame-ancestors，未用meta冒充生效响应头。

## 排错任务

把frame-ancestors写进meta，观察HTTP头为空与嵌入仍可能成功；修正到实际服务响应后用同一父页面复验。

记录故障输入→实际结果→原因→修复→复验，不能只写已解决。

## 参考要点

- 先盘点合法嵌入再改策略，避免破坏已有伙伴流程。
- postMessage仍需校验origin/source/data，与嵌入策略相互补充。
