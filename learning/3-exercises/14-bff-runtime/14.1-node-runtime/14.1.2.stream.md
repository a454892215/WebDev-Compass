# 14.1.2 独立练习：Node Stream背压：write返回值、drain与pipeline清理

先读理论并运行操作卡；保留原例，在副本完成变体。目标是能改变输入并解释机制，不只复制测试成功输出。

## 动手任务

副本把高水位改为4096并保留32KiB输入；增加一个每次写入8192字节的变体，比较write(false)、drain次数和峰值。对pipeline再加一个抛错Transform，确认中间错误也传到调用者。

## 验收标准

- [ ] 两种chunk尺寸最终字节数正确，等待drain时不重复写导致重复字节。
- [ ] 记录队列峰值及单位，并解释大chunk可超过highWaterMark；错误用例Promise拒绝且资源结束。

## 排错任务

把copy(true)中的await once(sink, drain)删除但继续返回成功，原bytes检查仍绿、peak检查应红。修复生产等待，再恢复完整验证；不能仅把highWaterMark调得巨大让错误暂时不显现。

记录失败断言/日志、根因、修复和同输入复验。所有故障在隔离副本、固定输入范围内运行，不污染主教材或启动永久进程。

## 参考要点

先确认false不是丢弃，再看生产速度与消费速度。用pipeline处理完整链的错误传播；手动write模式还须处理error/abort/close，lab慢sink成功路径不是可直接复制的通用上传器。
