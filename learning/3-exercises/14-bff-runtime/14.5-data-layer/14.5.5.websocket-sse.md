# 14.5.5 WebSocket / SSE：心跳、重连、游标与连接资源：独立练习

## 动手任务

扩展事件窗口，让过旧cursor返回明确reset指令，客户端拉取快照后重新连接；用可控随机数验证退避上限。再为两个订阅组件设计引用计数复用与最后卸载close，记录取消后无心跳/重连timer。

先不看参考实现，提交输入、输出和解释；变更仅在隔离副本。观察任务给出记录，代码任务给出可运行变体，不要求提供真实凭据。

## 验收标准

- [ ] 同租户重放且不越权，重复id去重；过旧cursor有可解释的快照恢复路径而不是静默漏消息。
- [ ] 重试有抖动/上限且鉴权失败可终止，关闭最后订阅后清理timer/连接；不混淆EventSource自动retry与自定义算法。

## 排错任务

故障：在EventSource.onerror里新建实例却不close旧实例，会同时保留自动重连和新连接，消息重复。给连接编号与创建/关闭计数定位，再明确单一重连责任方；实验中的Node fetch不会自动复现浏览器该行为，应另写浏览器变体。

保存失败输入与现象，再修复并重跑受影响测试。不能删断言或把异常无条件吞掉作为修复。

## 参考要点

先分清协议、库自动行为与应用策略。TCP chunk不等于一条SSE事件，解析器须缓冲跨chunk的UTF-8/空行，游标不能替代权限。

未运行浏览器EventSource或真实WebSocket握手/ping，未经过CDN/移动网络/长时运行。Node fetch测试验证SSE字节/重放/关闭，不等于浏览器原生自动重连验证；生产需另测鉴权、游标过期、队列上限与扩容。
