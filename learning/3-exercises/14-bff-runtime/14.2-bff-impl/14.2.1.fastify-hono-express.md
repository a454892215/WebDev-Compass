# 14.2.1 Nuxt Nitro 路由与中间件边界：独立练习

前置与运行入口见[示例](../../../2-examples/14-bff-runtime/14.2-bff-impl/14.2.1.fastify-hono-express-demo.md)。先在隔离副本尝试，不改共享凭据/系统配置。

## 动手任务

在隔离副本新增 GET /api/version，仅返回公开版本号与当前请求追踪编号，并说明为什么不额外启动 Express。

## 验收标准

- [ ] GET /api/version 返回最小公开字段，不暴露 env。
- [ ] 两次请求有不同追踪编号，单次头部与DTO一致。

## 排错任务

把 API 写成 dashboard.post.ts 后仍发 GET，实际得到方法/路由不匹配；核对文件路径和请求方法，再恢复 .get.ts。

保存操作、状态码、脱敏响应和修复前后证据，解释故障根因；不要仅提交“通过”。

## 参考要点

检查 server/middleware/context.ts 与 server/api/dashboard.get.ts，连续两次 GET，比较响应头和 JSON 的追踪编号。 对照理论中的机制与误区，再核实际代码和断言。模型/本地证据不能作为生产部署结果。
