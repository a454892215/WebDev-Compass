# 14.4.2 独立练习：Vercel Functions 与 Cloudflare Workers：入口、适配与部署核对

前置：对应理论和edge-lab测试。先预测再操作，保存自己的变体及输出；以下任务是学习者新增扩展，不代表示例已实现。

## 动手任务

为主项目增加一份“如果迁移Workers”的操作清单，列Nitro preset、绑定名称、密钥注入、预览、撤销和验证路由。仅编制计划，不改现有宿主部署。

## 验收标准

- [ ] 区分Nuxt/Nitro部署与Next运行时配置，未复制runtime=edge到Nuxt。
- [ ] 预览验证列200/404/405、私有响应隔离、平台日志和回滚；没有账号时保持待验。

## 排错任务

故障设定：照抄旧Next页面 export const runtime="edge" 到Nuxt配置，以为改变了部署。查实际Nuxt/Nitro构建配置和产物；移除无效配置，按目标preset重新规划，只有真实目标预览通过后才能写部署成功。

## 参考要点

平台入口只是接口，部署还包含绑定和生命周期。Node版本、Nitro版本和平台兼容日期都应固定。
