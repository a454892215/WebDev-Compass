# 14.4.4 独立练习：Workers KV、D1 与 Global Config：一致性决定用途

前置：对应理论和edge-lab测试。先预测再操作，保存自己的变体及输出；以下任务是学习者新增扩展，不代表示例已实现。

## 动手任务

为实验开关、立即注销和库存扣减分别选择存储，并解释读写比、原子性、撤销延迟、失效策略。给D1写参数化查询观察片段并标明尚未执行。

## 验收标准

- [ ] 至少指出KV普通读改写不满足库存原子性和立即撤销，给出服务端权威校验或强协调替代。
- [ ] D1事务范围、读副本会话书签与登录session分清；Global Config不被当任意业务写库。

## 排错任务

故障设定：将全局限流写成KV get(count)后put(count+1)，两个并发请求读到同值。列出丢更新时序并用并发变体复现本地模型；修复判据是采用有原子保证的服务端操作/协调，而不是声称加await就会串行全球请求。

## 参考要点

选型先列必须保证的事情：能否旧读、能否丢写、是否需跨键原子、失效后允许什么；再选产品。
