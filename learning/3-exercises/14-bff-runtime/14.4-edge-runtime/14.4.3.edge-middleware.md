# 14.4.3 独立练习：Edge 中间件：可信身份、Geo 路由与稳定 A/B 分组

前置：对应理论和edge-lab测试。先预测再操作，保存自己的变体及输出；以下任务是学习者新增扩展，不代表示例已实现。

## 动手任务

扩展实验加入资源owner检查和一个实验曝光字段；同一用户稳定分桶，拒绝通过改x-user-id读取别人的数据。

## 验收标准

- [ ] 未登录401、已登录访问别人的资源403或统一404，服务端检查owner而非按钮或实验桶。
- [ ] 私有/实验响应不能污染公开目录缓存，记录缓存绕过或有界键策略。

## 排错任务

故障注入：把resolveSession替换成读取x-user-id并直接构造user，原先伪造Header测试应失败。恢复可信会话解析并保留回归；不得通过删除伪造测试或把header改名来修复。

## 参考要点

可信边界位于平台适配器和身份验证器，不在Header名称；散列分桶是体验策略，不是验证签名。
