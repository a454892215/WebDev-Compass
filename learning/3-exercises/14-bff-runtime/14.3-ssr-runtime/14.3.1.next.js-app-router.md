# 14.3.1 独立练习：Next.js App Router：Server Components 与路由边界（选修）

## 动手任务

画出可见输出与服务端代码边界，把误放入 Client props 的 fixtureServiceToken 移出 DTO；只使用公开占位字符串。

先预测结果，保存故障变体，再运行或进行明确标注的静态观察。不要修改预期来掩盖故障；主项目任务先阅读实际源码，未有的能力写成新增扩展。

## 验收标准

- [ ] 边界图同时包含页面、交互组件、HTTP Route Handler；标出每处谁负责鉴权。
- [ ] 列出至少两个浏览器可见输出（HTML/RSC props等），并解释服务端运行不能阻止主动返回的泄漏。

## 排错任务

故障：把名为 serverSecret 的公开 fixture 字符串作为 Client Component prop，误认为 Server Component 包装后不可见。检查 props 和网络 payload；修复为只返回展示 DTO。若没有 Next 环境，提交标注“静态审查”的前后数据流图，不捏造运行日志。

## 参考要点

服务端代码位置与输出保密是两回事；Route Handler 仍是独立权限入口，Next 实测属于选修扩展。
