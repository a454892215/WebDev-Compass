# 11.3.3 独立练习：A/B实验：分配、可见曝光、转化与污染控制

先读[理论](../../../1-notes/11-observability/11.3-release-management/11.3.3.a-b.md)，按[实验说明](../../../2-examples/11-observability/11.3-release-management/release-lab/README.md)在隔离副本操作；不要改真实生产资源。先独立完成，再看参考。

## 动手任务

把可见阈值改为75%，明确目标卡片在窄视口的尺寸；给同一曝光重复请求和错误variant转化加负例，并写匿名→登录如何保持单位的设计。

## 验收标准

- [ ] 只读分配不增加曝光；满足新定义才发送，重复请求不增加unique计数。
- [ ] 无匹配曝光、错误variant和额外PII字段拒绝；不依据小fixture报告统计显著性。

## 排错任务

把event(exposure)移入assignment接口或组件setup，刷新/预取会计数。复现“未显示卡片但exposed增长”，恢复到实际展示触发并保留服务端幂等。

## 参考要点

渲染前就当曝光；同一人每次换组；把分母用PV、分子用unique用户；没有归因窗口/实验版本；把两三个fixture推断成显著提升。 保留前提、实际输入/输出和未测范围；不要只交一张“成功”截图。运行node server.mjs，读分配后查看exposed仍0；显示卡片进入视口后为1，重复显示仍1，转化为1。pnpm verify自动用390/1440视口复验，并用HTTP验证无曝光转化409/额外字段400。
