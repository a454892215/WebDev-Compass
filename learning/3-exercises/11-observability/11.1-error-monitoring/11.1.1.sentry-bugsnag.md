# 11.1.1 独立练习：Sentry/BugSnag集成：事件、Release与Source Map必须匹配

先独立操作再对照参考；从干净隔离副本开始，不改共享教学工程或真实站点。

## 动手任务

在隔离副本将release改为error-lab@2.0.0，并在fixtureFailure前新增两行，再重新构建。比较新旧压缩行列/map，不修改SDK协议。

## 验收标准

- [ ] 新信封release确为2.0.0、环境仍local-fixture；同次map能还原到改变后的fixture源位置。
- [ ] 给出仅隐藏sourceMappingURL仍可下载.map的反例及生产阻止公开map的部署检查，上传token不出现在client产物。

## 排错任务

保留旧dist的.map却替换新JS，或者按浏览器colno直接传给0起列的Source Map API。若映射位置漂移，核对文件哈希/同次构建、列号基准及真正帧来源；恢复匹配产物后重新验证。

## 参考要点

保存release、JS/map哈希和还原位置作为一组证据；上传平台仅列未执行项，不伪造截图或响应。

SDK DSN、CI上传token与用户身份各有职责；隐藏map引用不等于禁止HTTP下载；保留release标签也不自动保证映射正确。
