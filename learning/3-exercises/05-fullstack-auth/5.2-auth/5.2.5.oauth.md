# 5.2.5 独立练习：OAuth 2.0与OIDC：授权码、PKCE与第三方登录

## 动手任务

选一个提供方官方文档，列出authorize/token/identity或OIDC discovery、callback、PKCE支持与凭证所属位置；用本地URL样本识别恶意returnTo，先做设计审查而非真实授权。

先用自己的副本实现/记录，不使用真实账户凭据；先预测再运行。

## 验收标准

- [ ] 能区分OAuth授权、OIDC认证与本应用会话，明确secret不进入浏览器包。
- [ ] 回调事务与redirect验证逐项列出；缺真实提供方条件明确标为未实测。

## 排错任务

把returnTo=https://attacker.example.test直接传给最终重定向，或把state写成常量；在纸面/本地URL样本重现缺少绑定/allowlist的问题，改用一次性事务与限定站内目标，不能仅用includes域名。

保留“输入→现象/状态码→原因→修正→复验”，不只写已解决。

## 参考要点

- 采用成熟OAuth/OIDC库并验证发行者，避免手写完整协议。
- CSRF保护具体组合按BCP/SDK条件，不一概声称每个流必须同样使用所有参数。
