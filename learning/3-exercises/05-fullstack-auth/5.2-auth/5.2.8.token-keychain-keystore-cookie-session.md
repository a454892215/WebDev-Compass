# 5.2.8 独立练习：浏览器凭证存储与移动安全存储的差异

## 动手任务

为同一应用列出Cookie、memory、sessionStorage、localStorage四方案的脚本读取/自动发送/刷新恢复/退出撤销矩阵，再依据实际后端契约选择，不用关键词决定。

先用自己的副本实现/记录，不使用真实账户凭据；先预测再运行。

## 验收标准

- [ ] 能说明HttpOnly防直接读但不防同源恶意请求；Web Storage仍脚本可读。
- [ ] 本地观察仅教学值并清理；方案说明包含CSRF/XSS和服务器撤销，不等价Keychain。

## 排错任务

给sessionStorage变量改名secureToken后认为安全；用同源脚本仍能getItem重现。改存储名称没有改变威胁边界，应重新选凭证/会话契约并减少暴露。

保留“输入→现象/状态码→原因→修正→复验”，不只写已解决。

## 参考要点

- 不在日志、截图或错误报告展示真实Cookie/token。
