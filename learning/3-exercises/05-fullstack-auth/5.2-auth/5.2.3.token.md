# 5.2.3 独立练习：登录恢复、刷新协调、失效与退出

## 动手任务

为本地Cookie应用增加一次“恢复失败→重试”与退出时清理可视状态；在Bearer独立实验控制慢refresh，退出后才释放结果。

先用自己的副本实现/记录，不使用真实账户凭据；先预测再运行。

## 验收标准

- [ ] 按协议区分匿名/过期、401与网络/服务器错误；本项目session查询200 user:null不当作登录成功，失败能重试。
- [ ] logout后慢结果不复活旧身份；刷新有上限，并发只在同一会话内合并。

## 排错任务

让所有401都触发同一个拦截器refresh，包括refresh端点本身，画出递归链；改为端点排除与一次重试。再在受控Promise实验中退出后释放旧值，必须被session epoch拦住。

保留“输入→现象/状态码→原因→修正→复验”，不只写已解决。

## 参考要点

- Cookie app不必为了演示而强加refresh token。
- 不能仅清localStorage就声称退出所有会话。
