# 5.2.1 独立练习：Session与Cookie：轮换、过期和CSRF边界

## 动手任务

在副本画出登录前、登录成功、过期、退出四次Cookie/Session状态；实现或检查旧会话撤销，不用改前端按钮模拟退出。

先用自己的副本实现/记录，不使用真实账户凭据；先预测再运行。

## 验收标准

- [ ] 旧会话在登录轮换或退出后不能再访问受保护API；过期由服务器判断。
- [ ] 缺失/错误CSRF或不允许Origin的写请求失败，合法写入仍可用；本地HTTP限制明确。

## 排错任务

仅删除已登录UI而保留Cookie，/api/session仍能恢复用户，不是真正退出；调用服务器退出后，旧Cookie请求/api/notes应401，session查询应user:null。

保留“输入→现象/状态码→原因→修正→复验”，不只写已解决。

## 参考要点

- Cookie属性与服务器会话生命周期共同起作用。
- in-memory session Map是教学后端存储，生产多实例需共享存储/策略；不要与Nuxt页面顶层ref混为一谈。
