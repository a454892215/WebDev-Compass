# 5.3.3 独立练习：开发代理：浏览器同源，服务器再转发

## 动手任务

在副本把固定代理目标路径写错，观察404或响应类型不符合；恢复路径，并列出生产托管仍需配置的三项内容。

先在副本实现，记录命令、请求/响应或连接状态；不要只复制预期答案。

## 验收标准

- [ ] 浏览器请求仍是4404同源，后端记录来自服务器转发，能够画清两跳。
- [ ] 未把密钥/用户指定target直接透传；明确server.proxy不随vite build部署。

## 排错任务

错误地把/api前缀重复两次，收到404后先查代理重写与真实后端路由。不要通过catch返回空数组掩盖接口失败；修正路径后核对Content-Type和body。

保留故障输入→实际现象→定位→修复→复验，不只写“已解决”。

## 参考要点

- 开发代理解决本地拓扑，不提供服务端资源授权。
- SSR转发认证头只能面向受信任目标，Nuxt会话边界见5.2.9。
