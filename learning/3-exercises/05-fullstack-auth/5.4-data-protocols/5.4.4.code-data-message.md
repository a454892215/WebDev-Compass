# 5.4.4 独立练习：HTTP状态、业务错误与响应契约

## 动手任务

给资料库列出正常、空、未登录、无权、输入错误和暂时不可用的恢复表；确保界面操作与状态类别一致。

先在自己的副本动手，保留运行命令、预期/实际和修复记录，不以复制示例代替实现。

## 验收标准

- [ ] 204不读JSON，错误状态不被包成成功，业务消息不泄漏诊断秘密。
- [ ] 400/401/403/429的恢复动作不同且有上限；协议没有强制统一包壳。

## 排错任务

把403交给无限登录刷新循环，说明为何权限不会因此增加；改为明确无权反馈，保留服务端逐请求拒绝。

## 参考要点

- 状态码是协议的一部分，不是按提示文案随意猜。
- 是否隐藏资源存在性由后端威胁模型决定。
