# 5.4.2 独立练习：分页、排序与筛选：稳定身份和参数边界

## 动手任务

在副本增加分类筛选或降序选择，改变条件时回第一页；用同名条目和越界页验证稳定身份及空态。

先在自己的副本动手，保留运行命令、预期/实际和修复记录，不以复制示例代替实现。

## 验收标准

- [ ] 排序并列有稳定id作为次序，size/页码范围明确，重复参数按协议处理。
- [ ] 筛选后页码不指向旧集合；空页不与HTTP失败混淆，说明动态数据下offset局限。

## 排错任务

删除id次排序并只按可能重复字段排序，在有数据更新的副本观察边界；恢复明确顺序并记录为何仍需后端一致性契约，不能只靠前端去重掩盖漏项。

## 参考要点

- 稳定排序不自动提供数据库快照。
- 分页策略服务于产品与数据规模，不默认必须cursor。
