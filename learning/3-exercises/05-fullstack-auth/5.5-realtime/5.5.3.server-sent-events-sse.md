# 5.5.3 独立练习：SSE：事件流、Last-Event-ID与停止重连

## 动手任务

在副本模拟重复id2和过期cursor，决定去重/快照恢复协议；比较EventSource与带Bearer的fetch流方案，不把任意header参数传给原生构造器。

先在副本实现，记录命令、请求/响应或连接状态；不要只复制预期答案。

## 验收标准

- [ ] 服务端记录Last-Event-ID:1，客户端收到1/2并去重，显式close后无新连接。
- [ ] 能说明断线窗口超出历史时的恢复方法，客户端提交另走明确HTTP接口。

## 排错任务

把响应写成普通JSON或漏事件结尾空行，观察事件未分发；修复Content-Type/分隔符并核对代理是否缓冲，不靠刷新页面掩盖。

保留故障输入→实际现象→定位→修复→复验，不只写“已解决”。

## 参考要点

- Last-Event-ID只是恢复线索，历史保存与重放由服务端负责。
- 长连接要在离开/退出时关闭，连接数量和多标签页成本需评估。
