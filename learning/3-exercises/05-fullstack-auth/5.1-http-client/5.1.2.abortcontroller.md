# 5.1.2 独立练习：请求生命周期：取消、超时、迟到结果与状态恢复

## 动手任务

用一个可控制完成顺序的loader重现慢A快B，再增加清空输入与离开组件。将取消、超时、网络错误分别记录。

先在自己的副本动手，保留运行命令、预期/实际和修复记录，不以复制示例代替实现。

## 验收标准

- [ ] 慢A晚返回不能覆盖快B；清空或dispose后无旧结果回写。
- [ ] 取消不显示成空列表成功，loading只由当前请求结束；定时器和监听器可清理。

## 排错任务

删掉own===generation检查，使用故意忽略signal的loader按B→A顺序返回；先看到错误覆盖，再恢复代次保护并复验清空/离开。

## 参考要点

- 传signal证明可请求取消，代次判断证明谁能写状态。
- HTTP写操作取消后应核实最终结果，不能直接安全重发。
