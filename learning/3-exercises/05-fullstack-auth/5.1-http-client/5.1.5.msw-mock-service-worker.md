# 5.1.5 独立练习：Mock服务器与MSW：可控失败，不伪装真实后端

## 动手任务

给mock增加一个错误字段样本和一个迟到响应样本，先让客户端暴露错误，再修复解码/代次保护；标记生产后端未验证。

先在自己的副本动手，保留运行命令、预期/实际和修复记录，不以复制示例代替实现。

## 验收标准

- [ ] 同一测试可重复运行且结果确定，未知路由404，不访问真实生产服务。
- [ ] 测试后服务与拦截器清理；报告清楚区分本地HTTP、内存异步和真实后台。

## 排错任务

将错误fixture从503误改200并返回看似成功对象，检查测试是否真的会失败；补明确status和UI失败断言，恢复目标故障后再跑。

## 参考要点

- 替身应保留重要协议，不必实现完整后台。
- MSW为可选工具，本轮没有安装或验证其Worker。
