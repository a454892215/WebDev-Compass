# 5.1.7 独立练习：安全重试与幂等：限额、退避和重复写入边界

## 动手任务

在副本为一个读取设计最多3次/总预算/取消策略，再写取消后结果不确定的写入处理说明；不要用重试掩盖认证或格式错误。

先在自己的副本动手，保留运行命令、预期/实际和修复记录，不以复制示例代替实现。

## 验收标准

- [ ] 429/503按契约重试且有上限，403/坏数据/用户取消不会无限重试。
- [ ] 写入不自动重放；若用幂等键，服务端能拒绝同key不同body并说明有效期/主体/事务限制。

## 排错任务

将safeRead允许所有method并在POST超时后重发，说明可能重复写入的时间线；恢复只读策略，再用明确服务端key契约验证重放/冲突两种结果。

## 参考要点

- 关闭按钮只能减少UI双击，不是服务端幂等。
- 超预算应延后/提示，不得把Retry-After:120擅改1秒立即重试。
