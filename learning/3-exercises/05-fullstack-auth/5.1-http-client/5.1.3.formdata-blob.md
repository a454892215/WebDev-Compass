# 5.1.3 独立练习：FormData上传、XHR进度与Blob下载生命周期

## 动手任务

在副本上传合法/超限/伪装文本三种文件，分别记录传输完成和服务端校验结果；重复准备下载并确认旧对象URL被撤销。

先在自己的副本动手，保留运行命令、预期/实际和修复记录，不以复制示例代替实现。

## 验收标准

- [ ] 请求含自动生成的boundary，合法文件201、超限413；没有把100%进度当保存成功。
- [ ] 下载HTTP失败有反馈；对象URL替换和离开时清理，真实下载名正确。

## 排错任务

手写Content-Type:multipart/form-data覆盖浏览器boundary，重现400；删除该头并保持FormData请求体，同一文件恢复成功。

## 参考要点

- 本例只验证公开文本fixture，返回stored:false，不创建服务器文件。
- 大文件/断点续传/病毒扫描/真实持久化为后续专项。
