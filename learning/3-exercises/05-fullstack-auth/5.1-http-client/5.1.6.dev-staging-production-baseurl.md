# 5.1.6 独立练习：环境配置与baseURL：公开值、凭据目标和SSR边界

## 动手任务

在副本为dev/staging分别配置明确的API目标并写启动前校验；演练错误origin被拒绝，不发送真实凭据。

先在自己的副本动手，保留运行命令、预期/实际和修复记录，不以复制示例代替实现。

## 验收标准

- [ ] 浏览器包/public配置无秘密，静态构建不假称可由服务器env实时改变。
- [ ] 意外绝对URL和非允许origin被拒绝；SSR不会把Cookie转发到任意配置目标。

## 排错任务

把环境baseURL错写到未允许的origin，先让校验阻止请求，再修正配置；不要通过关闭CORS/浏览器安全设置掩盖目标错误。

## 参考要点

- 用URL解析origin，避免includes/后缀字符串误判。
- 开发便利与生产路由/凭据边界分别验证。
