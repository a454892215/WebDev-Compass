# 13.4.7 Print CSS：打印媒体、折叠内容与PDF边界：独立练习

## 动手任务

在隔离副本增加长标题/多条记录，检查打印隐藏操作、保留必要信息及分页。对必须打印的折叠内容设计独立视图或明确展开快照，不靠普通屏幕样式猜测。

## 验收标准

- [ ] 真实print媒体computed与PDF生成分别有证据，保留正文且不含无关操作区域。
- [ ] 指出长表/分页/真实打印与隐私未验范围，不把一个PDF头当完全排版通过。

## 排错任务

删@media print后导航/按钮进入打印、grid仍保留屏幕布局；恢复专用媒体覆盖再验。若闭合details重要正文没打印，补共享数据打印视图而非假称display已展开。

## 参考要点

打印是独立媒体和分页环境：隐藏导航/操作、保留正文和必要标识，考虑颜色、链接、表格断页、页边距与私有数据。@media print和@page不等于屏幕截图导出；浏览器PDF也不保证所有打印机、OS对话框或页眉页脚设置一致。

PDF头/文件存在不能证明每页分页和全文语义都正确；本轮截图检查与media computed是有限证据，未做物理打印/系统打印对话框、复杂长表或机密导出。静态副本需与正文同步；真实项目更适合共享数据生成专用打印视图。

仅改隔离副本，用输入/现象/原因/修复/复验回答；未跑平台保持未测。
