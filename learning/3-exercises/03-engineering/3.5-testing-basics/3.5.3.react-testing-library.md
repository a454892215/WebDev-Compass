# 3.5.3 独立练习：Vue Test Utils：挂载 Vue 3 组件并验证 props/emits

在实验副本或临时目录操作，先独立完成，再对照[示例](../../../2-examples/03-engineering/3.5-testing-basics/3.5.3-react-testing-library/README.md)。不改真实仓库全局配置，不使用真实凭据，不发布 npm 包。

## 动手任务

在副本组件添加 disabled 属性：disabled 时点击不发 toggle；分别测正常与禁用情况，并清理 mount。

## 验收标准

- [ ] 正常点击发一次合法 id，禁用状态不发事件。
- [ ] props 更新后按钮 aria-pressed 正确且挂载被清理。

## 排错任务

点击后期待 props.done 自动变 true；指出受控组件契约，使用父级回传或 setProps 验证状态变化。

记录复现输入、实际错误、定位依据、修复与复验命令；只有结果可观察地恢复才关闭问题。

## 参考要点

从公开DOM、props和emitted验证行为；React选修可比较用户行为断言思想，但工具API不混用。
