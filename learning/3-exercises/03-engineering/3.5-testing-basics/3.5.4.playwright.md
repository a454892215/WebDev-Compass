# 3.5.4 独立练习：Playwright：用可访问定位和条件等待验收用户流程

在实验副本或临时目录操作，先独立完成，再对照[示例](../../../2-examples/03-engineering/3.5-testing-basics/3.5.4-playwright/README.md)。不改真实仓库全局配置，不使用真实凭据，不发布 npm 包。

## 动手任务

为添加空白标题补一个浏览器用例：确认不新增列表项并出现可理解的错误/状态反馈；若副本尚无反馈先实现，标明扩展。

## 验收标准

- [ ] 使用 label/role 定位和可重试断言，不使用固定 sleep。
- [ ] 390与1440视口的成功/失败恢复流程均可独立重跑。

## 排错任务

把按钮名称定位写错为“保存”；读 locator 日志，对照实际可访问名称，修正定位或真正缺失的标签，不盲目加等待。

记录复现输入、实际错误、定位依据、修复与复验命令；只有结果可观察地恢复才关闭问题。

## 参考要点

先确认页面就绪、名称和定位范围，再检查状态；不要把测试超时一律归因电脑慢。
