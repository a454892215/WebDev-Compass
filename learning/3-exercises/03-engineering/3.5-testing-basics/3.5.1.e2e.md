# 3.5.1 独立练习：测试分层：单元、组件与端到端如何配合

在实验副本或临时目录操作，先独立完成，再对照[示例](../../../2-examples/03-engineering/3.5-testing-basics/3.5.1-e2e/README.md)。不改真实仓库全局配置，不使用真实凭据，不发布 npm 包。

## 动手任务

为 JSON 导入失败、按钮发事件、键盘添加任务、服务器鉴权各选择测试层；写明为什么其他层不能完全替代。

## 验收标准

- [ ] 至少列出一项必须真实浏览器观察的行为。
- [ ] mock 与真实后端、视口与真机的证据边界明确。

## 排错任务

在 jsdom 写一个“没有横向溢出”的断言并试图证明移动布局；说明测量环境缺口，改用 Playwright viewport + scrollWidth 观察。

记录复现输入、实际错误、定位依据、修复与复验命令；只有结果可观察地恢复才关闭问题。

## 参考要点

先看风险和失败代价，再决定层级；不要单凭测试数量或覆盖率承诺质量。
