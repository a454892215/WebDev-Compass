# 3.5.2 独立练习：Vitest：边界断言、异步失败和依赖替身

在实验副本或临时目录操作，先独立完成，再对照[示例](../../../2-examples/03-engineering/3.5-testing-basics/3.5.2-vitest/README.md)。不改真实仓库全局配置，不使用真实凭据，不发布 npm 包。

## 动手任务

为 loadTasks 增加一个响应 json() 拒绝的独立测试，并检查错误上抛；不要只测成功返回。

## 验收标准

- [ ] 失败 Promise 被 await expect(...).rejects 捕获。
- [ ] HTTP失败时 json 未调用，成功路径结果保持原协议。

## 排错任务

故意删掉 await 观察异步断言可靠性；恢复 await，并用明确错误信息/调用计数防止假阳性。不要依赖这次机器恰好及时报错。

记录复现输入、实际错误、定位依据、修复与复验命令；只有结果可观察地恢复才关闭问题。

## 参考要点

安排输入—执行—结果；错误路径也必须有真实断言。参考完整 tests/service.test.ts，注意与实际函数签名一致。
