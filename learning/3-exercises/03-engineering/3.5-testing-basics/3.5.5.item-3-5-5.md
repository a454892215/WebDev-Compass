# 3.5.5 独立练习：覆盖率与测试边界：用报告发现遗漏而非追逐数字

在实验副本或临时目录操作，先独立完成，再对照[示例](../../../2-examples/03-engineering/3.5-testing-basics/3.5.5-item-3-5-5/README.md)。不改真实仓库全局配置，不使用真实凭据，不发布 npm 包。

## 动手任务

在副本增加一个有两个合法分支的纯函数并纳入 include，只测一侧观察报告，再补另一侧有意义断言；比较各列。

## 验收标准

- [ ] 未import目标模块仍出现在报告分母。
- [ ] 能指出一个高覆盖率但错误断言/缺失需求的反例。

## 排错任务

删除 coverage.include 再比较报告文件集合；恢复明确范围，解释百分比上升为何未必质量提高。

记录复现输入、实际错误、定位依据、修复与复验命令；只有结果可观察地恢复才关闭问题。

## 参考要点

看文件集合、未覆盖分支和断言，再看阈值；报告范围变化必须说明，不能直接比较不同分母。
