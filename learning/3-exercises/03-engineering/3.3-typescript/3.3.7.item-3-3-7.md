# 3.3.7 独立练习：函数参数、返回值与回调契约

## 动手任务

给标题格式化、筛选谓词及请求函数写契约，再用测试替身实现同样签名。

先在自己的副本实现，不逐行抄实验。记录运行命令、预期编译/运行结果与实际差异。

## 验收标准

- [ ] 错误参数类型的回调不能赋给正确契约。
- [ ] 省略/undefined/null的行为按明确约定处理。

## 排错任务

把处理number的函数当作string回调，观察strictFunctionTypes诊断；修复契约或真正转换输入，不盲目强断言。

保留“故障输入→编译/运行现象→原因→修正→复验”，不要只写已修复。

## 参考要点

- 可选参数是调用方权利，不要滥标导致实现处处判空。
- 返回值和异常路径都要说明。
