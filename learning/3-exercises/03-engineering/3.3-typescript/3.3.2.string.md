# 3.3.2 独立练习：基础类型、unknown、元组与enum

## 动手任务

创建含字符串id、布尔状态、数值时长和元组坐标的模型；比较unknown与any访问同一坏输入。

先在自己的副本实现，不逐行抄实验。记录运行命令、预期编译/运行结果与实际差异。

## 验收标准

- [ ] unknown未收窄访问属性被拒绝。
- [ ] 元组位置错误被拒绝，数组不存在元素有显式回退。
- [ ] 记录enum输出JS对象与type擦除的不同。

## 排错任务

把unknown换成any让坏字段参与乘法，得到NaN；改回unknown并检查Number.isFinite后再使用。

保留“故障输入→编译/运行现象→原因→修正→复验”，不要只写已修复。

## 参考要点

- unknown适合边界；any不是解决所有类型错误的工具。
- void不等于运行时返回值一定为undefined，never不能作为普通成功结果。

主综合任务：为任务板id、标题、完成状态和筛选条件写准确类型，评估用字面量联合而非强引enum。 具体项目代码以阶段说明为准。
