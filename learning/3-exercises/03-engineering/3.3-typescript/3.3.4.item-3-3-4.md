# 3.3.4 独立练习：联合、交叉与可辨识状态

[理论](../../../1-notes/03-engineering/3.3-typescript/3.3.4.item-3-3-4.md) · [实验](../../../2-examples/03-engineering/3.3-typescript/3.3.4.item-3-3-4-demo.md)

## 动手任务

把loading、success、error表示为联合，在各分支只访问对应字段；新增一种状态检查遗漏。

先在自己的副本实现，不逐行抄实验。记录运行命令、预期编译/运行结果与实际差异。

## 验收标准

- [ ] 未收窄直接访问专属value被拒绝。
- [ ] 新增状态后穷尽分支检查失败，补齐后恢复。
- [ ] 解释冲突交叉字段为何不能赋值。

## 排错任务

把{id:string}与{id:number}交叉后试写id；不要用as压过去，改为统一协议或更换字段名。

保留“故障输入→编译/运行现象→原因→修正→复验”，不要只写已修复。

## 参考要点

- 联合是可能性，交叉是同时约束。
- 穷尽检查与运行期未知输入解码分别负责。

主综合任务：审查任务板加载/失败/成功分支，若多个布尔标志能形成矛盾状态，在副本用判别联合整理。 具体项目代码以阶段说明为准。
