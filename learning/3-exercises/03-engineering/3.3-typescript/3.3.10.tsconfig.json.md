# 3.3.10 独立练习：strict、target、module与paths

## 动手任务

对照strictNullChecks开关与数组索引选项；添加别名并分别验证tsc、构建器和运行器。

先在自己的副本实现，不逐行抄实验。记录运行命令、预期编译/运行结果与实际差异。

## 验收标准

- [ ] null/undefined错误能被检查，边界输入仍运行期验证。
- [ ] paths编译通过但Node失败可复现，补运行时解析后再验收。
- [ ] 高版本lib没有被说成安装了旧浏览器polyfill。

## 排错任务

只配paths不配真实解析，运行产物出现ERR_MODULE_NOT_FOUND；修复宿主配置或相对导入，不用skipLibCheck解决路径。

保留“故障输入→编译/运行现象→原因→修正→复验”，不要只写已修复。

## 参考要点

- 类型层解析和运行层解析分别验证。
- strict/target/lib的目标不同，skipLibCheck不是检查自己代码的总开关。
