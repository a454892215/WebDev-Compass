# 3.3.3 独立练习：interface与type：结构契约和声明合并

## 动手任务

分别用interface定义阅读项、type定义筛选联合；比较字面量多余字段与变量赋值。

先在自己的副本实现，不逐行抄实验。记录运行命令、预期编译/运行结果与实际差异。

## 验收标准

- [ ] 缺必需title时编译失败。
- [ ] 说明额外字段的运行期对象仍存在，类型注解不裁剪数据。

## 排错任务

用同名interface意外合并不相关字段，让实现突然缺字段；隔离模块命名并判断是否本应是不同契约。

保留“故障输入→编译/运行现象→原因→修正→复验”，不要只写已修复。

## 参考要点

- 选型取决于可读性和表达能力。
- 编译器的多余属性诊断不等于运行期精确schema。

主综合任务：整理任务板的Task与Filter契约，区分服务端字段、UI派生字段，避免把所有扩展塞进同一可选接口。 具体项目代码以阶段说明为准。
