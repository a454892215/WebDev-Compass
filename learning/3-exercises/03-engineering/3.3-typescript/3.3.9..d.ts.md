## 验收标准

- [ ] 输出JS没有import type和interface。

## 排错任务

为不存在的SDK写declare const sdk后直接调用；观察运行期ReferenceError，再正确安装/导入实现，不继续加断言。

保留“故障输入→编译/运行现象→原因→修正→复验”，不要只写已修复。
