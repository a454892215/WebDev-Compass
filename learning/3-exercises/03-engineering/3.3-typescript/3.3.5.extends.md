## 动手任务

从两种带id的模型抽出byId，再用Pick定义列表摘要、Omit定义创建输入。

先在自己的副本实现，不逐行抄实验。记录运行命令、预期编译/运行结果与实际差异。

## 验收标准

- [ ] 返回类型保留各模型特有字段。
- [ ] 缺id的输入被拒绝，找不到时有undefined分支。
- [ ] 工具类型没有被误当运行期对象变换。

## 排错任务

把返回值断言为T导致找不到项时崩溃；改为T|undefined并由调用方处理空结果。

保留“故障输入→编译/运行现象→原因→修正→复验”，不要只写已修复。

## 参考要点

- 泛型用于保持关系，不等于万能抽象。
- Record的键约束不替代外部字典校验。
