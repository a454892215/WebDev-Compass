## 验收标准

## 排错任务

用as把数字title断言成string，再调用toUpperCase；先解释为什么编译器相信你，改为unknown与守卫后对坏输入给明确错误。

保留“故障输入→编译/运行现象→原因→修正→复验”，不要只写已修复。

## 参考要点

- 类型是契约，不是接口响应的事实证明。
- 先修复数据入口，不能靠连用as unknown as绕过错误。
