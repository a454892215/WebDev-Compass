# 3.2.4 练习：HMR：更新边界与状态保留

[理论](../../../1-notes/03-engineering/3.2-build-tools/3.2.4.hmr.md) · [实验](../../../2-examples/03-engineering/3.2-build-tools/3.2.4.hmr-demo.md)

## 动手任务

在自己的副本完成：先在vite-lab副本修改message.ts观察计数/document保持，再回任务板比较CSS模块更新与全页刷新；任务板没有实验计数器或手工accept。 先记录预期，再运行并解释实际差异；不要直接复制参考结果。

## 验收标准

- [ ] vite-lab消息变化后计数仍3且document不变；任务板另行记录实际更新结果，不套用状态保持结论。
- [ ] 能说明不受接受边界覆盖的变更可能刷新，资源需要相应清理。

## 排错任务

在副本移除accept，再改依赖，观察刷新和计数归零；还原后重测，不把浏览器自动刷新都叫HMR。

记录复现输入、实际输出/退出码、原因、修正及复验；不能只写“已解决”。

## 参考要点

- 观察文字、状态和导航三类证据。
- 真实工程优先使用框架官方插件。
