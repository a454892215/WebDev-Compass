# 3.2.6 练习：Source Map：生成代码与源码的映射

[理论](../../../1-notes/03-engineering/3.2-build-tools/3.2.6.source-map.md) · [实验](../../../2-examples/03-engineering/3.2-build-tools/3.2.6.source-map-demo.md)

## 动手任务

在自己的副本完成：为任务板决定开发/生产map策略，写明哪些产物公开、错误诊断如何取得映射。 先记录预期，再运行并解释实际差异；不要直接复制参考结果。

## 验收标准

- [ ] 实际产物map可解析且mappings非空，能区分生成/发布/消费。
- [ ] 不声称hidden防止下载，不把映射当运行时校验。

## 排错任务

在vite-lab副本的sourcemap:true构建中删去map但保留sourceMappingURL，观察调试获取失败；在副本修正部署清单或策略而不改业务逻辑掩盖。

记录复现输入、实际输出/退出码、原因、修正及复验；不能只写“已解决”。

## 参考要点

- 可调试性与源码暴露需要一起考虑。
- 本轮只证明实际映射产物存在与正确关联，完整断点对应为手工扩展。
