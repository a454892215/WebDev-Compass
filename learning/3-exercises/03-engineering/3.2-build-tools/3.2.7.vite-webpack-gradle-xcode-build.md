## 验收标准

- [ ] 能解释浏览器资源URL、开发服务器和生产静态资源的关系。
- [ ] 类比说明职责与差异，不宣称移动工具或真实部署实测。

## 排错任务

把vite build成功当签名发布完成，列出实际尚未发生的部署、配置和验收步骤并修正交付描述。

记录复现输入、实际输出/退出码、原因、修正及复验；不能只写“已解决”。
