# 3.4.3 独立练习：EditorConfig：约定编辑器缩进、换行与编码

在实验副本或临时目录操作，先独立完成，再对照[示例](../../../2-examples/03-engineering/3.4-code-quality/3.4.3-editorconfig/README.md)。不改真实仓库全局配置，不使用真实凭据，不发布 npm 包。

## 动手任务

在实验副本为 *.md 单独保留尾空格，并为一个临时目录设四空格；记录工具解析到的缩进设置。

## 验收标准

- [ ] 能解释 root 和 section 的匹配/覆盖次序。
- [ ] 支持工具读到四空格，根配置保持两空格且排版检查通过。

## 排错任务

把 indent_size 错写为 indent-size 后解析；修回标准属性名并重新读取，不只在编辑器肉眼看空白。

记录复现输入、实际错误、定位依据、修复与复验命令；只有结果可观察地恢复才关闭问题。

## 参考要点

先确认工具是否支持，再看属性拼写、glob 和更近的配置；它与 Prettier 互补。
