# 3.4.6 独立练习：Git ignore 与 npm 打包：分别核对跟踪范围和发布产物

在实验副本或临时目录操作，先独立完成，再对照[示例](../../../2-examples/03-engineering/3.4-code-quality/3.4.6-.gitignore/README.md)。不改真实仓库全局配置，不使用真实凭据，不发布 npm 包。

## 动手任务

仅在临时目录创建无敏感内容的 config.demo，演示跟踪后添加忽略无效；为临时包设置 files:["dist"] 并核对 dry-run 清单。

## 验收标准

- [ ] 说明已跟踪文件为何仍出现在 git ls-files。
- [ ] dry-run 产物符合白名单且无 config.demo、源码测试缓存。

## 排错任务

只把 config.demo 写进 .gitignore，再新建 .npmignore 而遗漏它；观察清单，修复为明确 files 白名单或正确排除。禁止放真实秘密做实验。

记录复现输入、实际错误、定位依据、修复与复验命令；只有结果可观察地恢复才关闭问题。

## 参考要点

分别查 Git 索引和 npm 清单；两者不互相证明安全。
