# 3.4.2 独立练习：Prettier：统一排版并用 check 阻止漂移

在实验副本或临时目录操作，先独立完成，再对照[示例](../../../2-examples/03-engineering/3.4-code-quality/3.4.2-prettier/README.md)。不改真实仓库全局配置，不使用真实凭据，不发布 npm 包。

## 动手任务

在副本把 domain.ts 一段改成双引号/紧凑对象；先 check 再 write，再 check，并保存差异。

## 验收标准

- [ ] check 第一次失败且没有改写文件。
- [ ] write 后 check 通过，业务测试仍通过。

## 排错任务

把目标文件加入 .prettierignore 后再次 check；解释为什么“全部匹配文件通过”可能没有检查目标，再移除误忽略。

记录复现输入、实际错误、定位依据、修复与复验命令；只有结果可观察地恢复才关闭问题。

## 参考要点

区分 check/write；核对配置路径、忽略规则和文件 glob，不将 Prettier 失败当业务 Bug。
