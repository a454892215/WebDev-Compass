# 3.1.1 练习：package.json：依赖、脚本与运行环境

[理论](../../../1-notes/03-engineering/3.1-package-management/3.1.1.package.json.md) · [实验](../../../2-examples/03-engineering/3.1-package-management/3.1.1.package.json-demo.md)

## 动手任务

在自己的副本完成：为任务板逐项解释scripts、依赖类型、Node范围与private，指出真实命令入口，不把声明当验证。 先记录预期，再运行并解释实际差异；不要直接复制参考结果。

## 验收标准

- [ ] 能说明typecheck、build、test各检查什么，错误退出能被发现。
- [ ] 依赖版本和运行环境有记录，private防误发布且不把它当秘密保护。

## 排错任务

在副本把check脚本改成不存在文件，运行并记录退出码；恢复路径后同一命令通过。

记录复现输入、实际输出/退出码、原因、修正及复验；不能只写“已解决”。

## 参考要点

- manifest是契约，命令运行是证据。
- 客户端是否包含依赖要检查导入/构建，不只看devDependencies。
