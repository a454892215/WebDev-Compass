## 动手任务

在自己的副本完成：在任务板保持manifest与pnpm锁一致，升级时同时审查锁变化并运行检查。 先记录预期，再运行并解释实际差异；不要直接复制参考结果。

## 验收标准

- [ ] 原工程冻结安装退出0且锁文件未被改写。
- [ ] 临时副本manifest不一致时冻结命令非0，能指出修复路径。

## 排错任务

制造依赖声明/锁不一致，定位ERR_PNPM_OUTDATED_LOCKFILE；按明确升级目标重生成锁，不用关闭冻结掩盖问题。

记录复现输入、实际输出/退出码、原因、修正及复验；不能只写“已解决”。

## 参考要点

- 冻结要求一致，不是锁文件不存在也无条件通过。
- 版本、操作系统与脚本条件仍需记录。
