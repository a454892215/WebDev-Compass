# 0.3.1 URL 结构：协议、域名、端口、路径、查询参数、锚点：独立练习

本练习配套阶段 0 的知识点；资料审查结果与学习者实操结果分别记录。仅使用虚构数据，记录实际观察，不把未执行项标成通过。

## 动手任务

1. 用无凭据的 https://example.com:8443/resources?q=Vue%203&page=2#intro 解析 URL，增加同名查询参数，再比较默认端口的归一化。
2. 把该能力应用于[学习资源目录综合实践](../../../4-practice/01-web-fundamentals/index.html)：记录该页面或它的本地服务能提供什么证据、不能证明什么；不为完成清单擅自添加生产能力。

## 验收标准

- [ ] 正确标出 protocol、hostname、port、pathname、search 与 hash。
- [ ] 说明 URLSearchParams 对空格和重复参数的处理，以实际输出为证。
- [ ] 从本地目录的 Network 请求确认 fragment 不作为 HTTP 请求目标发送。
- [ ] 保存复现步骤、运行条件与结果；未执行或无法观察的部分明确标记，不提交真实个人数据。

## 排错任务

手工拼接含 & 和中文的参数导致歧义；改用 URL/URLSearchParams 并比较编码。

给出“复现步骤 → 实际证据 → 原因假设 → 修正/核对 → 复验”的记录。只在练习副本操作；观察类清单无需修改知识库代码。
