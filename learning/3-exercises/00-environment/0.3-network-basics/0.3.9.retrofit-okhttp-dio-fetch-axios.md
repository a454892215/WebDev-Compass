# 0.3.9 📱 移动端对照：Retrofit/OkHttp/Dio ≈ fetch/axios；SharedPreferences ≈ localStorage：独立练习

本练习补充阶段 0 的学习任务；不表示旧正文和旧服务已按现行规范完成技术复审。仅使用虚构数据，记录实际观察，不把未执行项标成通过。

## 动手任务

1. 把同一个本地用户资源契约映射为 fetch 与熟悉的 Retrofit/Dio 调用流程，用伪代码解释请求、状态校验、解析、错误和取消边界，不新增 axios 依赖。
2. 把该能力应用于[学习资源目录综合实践](../../../4-practice/01-web-fundamentals/index.html)：记录该页面或它的本地服务能提供什么证据、不能证明什么；不为完成清单擅自添加生产能力。

## 验收标准

- [ ] 区分传输异常、非成功 HTTP、JSON 解析异常和业务失败。
- [ ] 指出浏览器 CORS/凭据条件是原生客户端类比的额外边界。
- [ ] 说明 localStorage 与 SharedPreferences 类比不等于安全存储保证。
- [ ] 保存复现步骤、运行条件与结果；未执行或无法观察的部分明确标记，不提交真实个人数据。

## 排错任务

认为封装拦截器后就无需处理 response.ok；用本地 404 响应展示状态检查位置。

给出“复现步骤 → 实际证据 → 原因假设 → 修正/核对 → 复验”的记录。只在练习副本操作；观察类清单无需修改知识库代码。
