# 0.1.2 浏览器的角色：HTML / CSS / JS 解析、渲染、执行：独立练习

本练习配套阶段 0 的知识点；资料审查结果与学习者实操结果分别记录。仅使用虚构数据，记录实际观察，不把未执行项标成通过。

## 动手任务

1. 在示例中分别修改一个 DOM 文本、一条 CSS 规则和一个事件处理断点，记录三个修改对页面的影响；刷新后区分源文件与运行期 DOM。
2. 把该能力应用于[学习资源目录综合实践](../../../4-practice/01-web-fundamentals/index.html)：记录该页面或它的本地服务能提供什么证据、不能证明什么；不为完成清单擅自添加生产能力。

## 验收标准

- [ ] 提交 Elements 文本、Computed 样式与 Sources 断点各一项观察。
- [ ] 说明 DOM 检查器修改为何通常在刷新后消失。
- [ ] 区分 Node 终端和页面 Console 的 document 可用性。
- [ ] 保存复现步骤、运行条件与结果；未执行或无法观察的部分明确标记，不提交真实个人数据。

## 排错任务

修改了被覆盖的 CSS 规则却认为浏览器没有加载样式；查看匹配规则及 Computed 来源。

给出“复现步骤 → 实际证据 → 原因假设 → 修正/核对 → 复验”的记录。只在练习副本操作；观察类清单无需修改知识库代码。
