# 0.1.1 客户端—服务器（C/S）模型与请求—响应循环：独立练习

本练习补充阶段 0 的学习任务；不表示旧正文和旧服务已按现行规范完成技术复审。仅使用虚构数据，记录实际观察，不把未执行项标成通过。

## 动手任务

1. 启动本地 REST 示例，读取列表，再提交仅含虚构姓名与示例邮箱的创建请求；给两次请求分别画出浏览器、服务器和内存数据的流向。
2. 把该能力应用于[学习资源目录综合实践](../../../4-practice/01-web-fundamentals/index.html)：记录该页面或它的本地服务能提供什么证据、不能证明什么；不为完成清单擅自添加生产能力。

## 验收标准

- [ ] 记录读取与创建的 URL、方法、状态码、响应体，不用页面提示代替 Network 证据。
- [ ] 指出页面静态资源请求与用户操作产生的 API 请求至少各一例。
- [ ] 说明服务停止时前端能做什么，以及哪些数据只有服务器能返回。
- [ ] 保存复现步骤、运行条件与结果；未执行或无法观察的部分明确标记，不提交真实个人数据。

## 排错任务

把页面按钮已经变色当作服务器已保存成功；停止本地服务后重试并对照 Network。

给出“复现步骤 → 实际证据 → 原因假设 → 修正/核对 → 复验”的记录。只在练习副本操作；观察类清单无需修改知识库代码。
