# 0.2.1 安装与配置：Node.js、npm / yarn / pnpm：独立练习

本练习补充阶段 0 的学习任务；不表示旧正文和旧服务已按现行规范完成技术复审。仅使用虚构数据，记录实际观察，不把未执行项标成通过。

## 动手任务

1. 在示例副本中先检查 package.json 与锁文件，再记录 node/npm 版本并运行现有 info/start 脚本；依赖已就绪时不重复安装，需安装时按项目锁文件处理。
2. 把该能力应用于[学习资源目录综合实践](../../../4-practice/01-web-fundamentals/index.html)：记录该页面或它的本地服务能提供什么证据、不能证明什么；不为完成清单擅自添加生产能力。

## 验收标准

- [ ] 记录实际运行时版本、所选包管理器与对应脚本。
- [ ] 解释 npm 脚本如何调用 Node 以及浏览器为何无需运行这段 CLI。
- [ ] 指出依赖缺失与 Node 版本不符合要求的不同排查步骤。
- [ ] 保存复现步骤、运行条件与结果；未执行或无法观察的部分明确标记，不提交真实个人数据。

## 排错任务

在错误目录执行 npm start；先检查当前目录和 package.json 的 scripts。

给出“复现步骤 → 实际证据 → 原因假设 → 修正/核对 → 复验”的记录。只在练习副本操作；观察类清单无需修改知识库代码。
