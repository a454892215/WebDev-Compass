# 7.2.2 独立练习：Next.js选修：Pages/App路由、组件边界与部署模型

先阅读[理论](../../../1-notes/07-deployment/7.2-ssr/7.2.2.next.js.md)，运行[操作卡](../../../2-examples/07-deployment/7.2-ssr/7.2.2.next.js-demo.md)后关闭参考，在副本独立完成。只用合成数据，不在公网或真实账号上故意制造泄露。

## 动手任务

取一篇使用getServerSideProps的Pages示例与一篇App Server Component示例，分别列出入口、数据返回和客户端可见范围；判断是否能直接静态export。

## 验收标准

- [ ] 文档记录包含访问日期、路由体系和缓存模型，不把两套接口拼为一份代码。
- [ ] 指出至少一个静态export不具备的请求时能力，凭据与浏览器DTO明确分开。

## 排错任务

方案中在app页面导出getServerSideProps并承诺读取每用户Cookie后静态导出；依据对应路由文档找出两个独立冲突，选择正确体系/profile，而不是改文件名掩盖。

## 参考要点

先确认路由目录与框架版本，再谈接口；静态export没有每请求服务端身份环境。若今后选择Next再新建独立验证工程，本轮仅完成决策与官方观察。

保存改动/命令、原始输出或官方观察摘录、原因与恢复证据；类型/文件存在不等于实际部署和掌握。
