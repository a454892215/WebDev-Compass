# 7.2.5 独立练习：同构部署验收：依赖兼容、请求隔离与静态边界

先阅读[理论](../../../1-notes/07-deployment/7.2-ssr/7.2.5.api.md)，运行[操作卡](../../../2-examples/07-deployment/7.2-ssr/7.2.5.api-demo.md)后关闭参考，在副本独立完成。只用合成数据，不在公网或真实账号上故意制造泄露。

## 动手任务

在隔离副本用合成身份数据比较“模块全局currentUser”与“从当前event读取身份”，用并发而不是串行请求验证；列出Node、浏览器、静态托管各自可用能力。

## 验收标准

- [ ] Alice/Bob/匿名并发结果互不串用，缺失/非法fixture Cookie不能获得Alice/Bob DTO；响应和服务器缓存规则适当。这里是合成选择边界，不是真实认证。
- [ ] 静态输出不含私有页/payload/合成敏感标记，浏览器专属依赖没有在SSR导入时执行。

## 排错任务

在模块顶层保存lastUser并让匿名请求回退lastUser；使用测试身份复现泄露，改为请求内读取与明确401/匿名响应后重跑，不用延时或串行化请求掩盖。

## 参考要点

将公开常量与私有可变状态分开；每一层缓存都能产生混用，必须检查实际返回内容而非只看配置。静态站点若需要账户功能，应接独立受保护服务，不把私有数据构建进HTML。

保存改动/命令、原始输出或官方观察摘录、原因与恢复证据；类型/文件存在不等于实际部署和掌握。
