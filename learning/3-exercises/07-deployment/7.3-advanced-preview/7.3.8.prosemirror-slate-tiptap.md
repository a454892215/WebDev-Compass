# 7.3.8 富文本编辑：文档模型、Schema与安全输出 — 独立练习

## 动手任务

设计课程备注的最小文档版本和允许结构；对HTML粘贴与javascript:链接列验证/净化边界，并补中文IME与撤销场景。

## 验收标准

- [ ] 区分编辑器schema、存储验证、展示安全和资源授权，不能把schema称通用净化器。
- [ ] 保存含格式版本/revision，失败不丢未保存输入；测试含IME、粘贴、撤销和不可信URL。

## 排错任务

故障：接收任意HTML并直接v-html展示，认为编辑器已保证安全。沿输入→持久化→展示追踪危险URL/属性，在对应边界验证/净化并保持版本迁移；原恶意样本应不执行，正文仍可读。

## 参考要点

先独立尝试，再对照[理论机制](../../../1-notes/07-deployment/7.3-advanced-preview/7.3.8.prosemirror-slate-tiptap.md)和[操作卡](../../../2-examples/07-deployment/7.3-advanced-preview/7.3.8.prosemirror-slate-tiptap-demo.md)；记录输入、实际输出/设计证据、原因与修复。为Nuxt目录副本写课程备注编辑器对接设计和威胁/验收清单；当前主工程未集成完整编辑器，若实施须另做组件与实际浏览器验证。
