# 7.3.3 GraphQL客户端：查询、部分错误与身份缓存 — 独立练习

## 动手任务

给课程详情+可选推荐设计operation/variables和部分失败UI；另设计用户A退出、用户B登录后的缓存处置。

## 验收标准

- [ ] 保留可用课程内容的同时显示推荐失败，不把HTTP200或data存在当全成功。
- [ ] 说明变量与实体ID/参数的缓存关系；SSR请求不共享身份客户端，注销后不展示前用户私有数据。

## 排错任务

故障：将errorPolicy:ignore用于必须成功的权限字段，界面吞掉错误。对照data/errors/path恢复明确错误分支；分别列出网络失败与字段失败的预期，未接真实服务只提交响应fixture分析。

## 参考要点

先独立尝试，再对照[理论机制](../../../1-notes/07-deployment/7.3-advanced-preview/7.3.3.graphql.md)和[操作卡](../../../2-examples/07-deployment/7.3-advanced-preview/7.3.3.graphql-demo.md)；记录输入、实际输出/设计证据、原因与修复。在主目录副本为课程/推荐准备GraphQL对接设计与部分失败样本；当前主工程使用既定本地数据，不虚构已迁移GraphQL。
