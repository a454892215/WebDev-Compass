# 7.3.6 React Native Web/Expo Web：复用边界与平台行为 — 独立练习

## 动手任务

对“手机课程卡+桌面课程表格”列复用清单，并为一个原生依赖设计.web与.native适配边界。

## 验收标准

- [ ] 共享模型与UI适配分别列明，保留真实href/键盘/可见焦点等Web行为。
- [ ] 说明原生依赖不会被Web构建静态导入；验证矩阵区分浏览器、SSR与原生设备。

## 排错任务

故障：Web条件分支不执行原生代码，但文件顶层仍导入仅原生模块，构建已失败。将导入移动到平台入口/适配层，分别检查Web与原生打包路径；未实际构建必须标观察方案。

## 参考要点

先独立尝试，再对照[理论机制](../../../1-notes/07-deployment/7.3-advanced-preview/7.3.6.react-native-web.md)和[操作卡](../../../2-examples/07-deployment/7.3-advanced-preview/7.3.6.react-native-web-demo.md)；记录输入、实际输出/设计证据、原因与修复。比较Nuxt双宿主与RNW方案的团队/产品约束，输出适配清单；当前主目录保持Vue/Nuxt，不声称已实现Expo替代宿主。
