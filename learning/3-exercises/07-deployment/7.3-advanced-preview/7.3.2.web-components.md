# 7.3.2 Custom Elements与Shadow DOM：生命周期、语义和边界 — 独立练习

## 动手任务

在副本把计数器改为收藏状态；定义boolean property/事件，反复移除与连接两次，再检查外部监听和键盘行为。

## 验收标准

- [ ] 断开后全局事件不改变状态，重连后一次输入只产生一次变化；状态保留规则明确。
- [ ] 真实button可用Tab/Enter操作，状态有文字或适当aria-pressed，名称不引用另一shadow tree的id。

## 排错任务

故障：connectedCallback每次创建新箭头window监听但断开用另一个函数移除，重连后一次事件累计多次。将处理函数保存为稳定引用，在disconnectedCallback匹配移除；重复两次重连后单次变化仍为1。

## 参考要点

先独立尝试，再对照[理论机制](../../../1-notes/07-deployment/7.3-advanced-preview/7.3.2.web-components.md)和[操作卡](../../../2-examples/07-deployment/7.3-advanced-preview/7.3.2.web-components-demo.md)；记录输入、实际输出/设计证据、原因与修复。运行独立lab生命周期与事件测试；仅当课程控件要提供给非Vue宿主时，在Nuxt副本设计嵌入接口，不声称主工程已使用自定义元素。
