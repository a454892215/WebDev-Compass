# 7.3.7 数据可视化：原生SVG基础与D3/ECharts/Chart.js取舍 — 独立练习

## 动手任务

把数据换为四个环节，并加入0值；保持表格单位与图形比例一致，再写出换ECharts或Chart.js需要补的无障碍与清理责任。

## 验收标准

- [ ] 数据校验拒绝NaN/Infinity/负值/越界，图形与文字使用同一份有效数据。
- [ ] 有明确单位、等价表格和图像名称，窄屏可读，不依赖颜色辨识数值。

## 排错任务

故障：直接把服务器字符串当数字绘宽，出现NaN或条形超出。先解码并检查有限值/允许范围，非法数据显示错误，不画误导图；再核对SVG viewBox与CSS实际尺寸。

## 参考要点

先独立尝试，再对照[理论机制](../../../1-notes/07-deployment/7.3-advanced-preview/7.3.7.d3.js.md)和[操作卡](../../../2-examples/07-deployment/7.3-advanced-preview/7.3.7.d3.js-demo.md)；记录输入、实际输出/设计证据、原因与修复。在Nuxt发布演练副本展示构建/检查的合成数据，先保留HTML表格；按真实交互需要决定是否添加图库，不把合成工时当生产测量。
