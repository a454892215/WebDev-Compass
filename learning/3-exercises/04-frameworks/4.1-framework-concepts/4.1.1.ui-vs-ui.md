# 4.1.1 独立练习：声明式UI与命令式DOM操作

## 动手任务

在副本增加“清空书单”命令，保持列表按钮与数量一致；另外写一个纯原生计数器比较两种更新方式。

先在副本完成，不逐行复制主工程；保留改动和实际结果。

## 验收标准

- [ ] 同一次状态改变后按钮aria-pressed与数量一致，无手工复制第二份数量状态。
- [ ] 能说明状态改变后DOM批量更新，读取DOM要等待nextTick或测试可重试断言。

## 排错任务

先只用开发者工具把output文字改成999，再执行正常状态变化；观察其不是数据源。若项目代码主动改框架DOM，删除重复写入并由状态驱动，不能把DOM文字再反读成权威状态。

记录故障输入→现象→原因→修复→复验。

## 参考要点

- 把事实状态保留一份，数量用派生值或ids.length。
- 小型静态控件可以原生实现；采用Vue不等于绕过浏览器机制。
