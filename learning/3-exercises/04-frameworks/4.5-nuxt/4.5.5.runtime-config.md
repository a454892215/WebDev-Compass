# 4.5.5 独立练习：runtimeConfig：公开配置、服务端秘密与运行时覆盖

[理论](../../../1-notes/04-frameworks/4.5-nuxt/4.5.5.runtime-config.md) · [实验](../../../2-examples/04-frameworks/4.5-nuxt/4.5.5.runtime-config-demo.md)

## 动手任务

在副本新增一个公开站点标签与一个私有空配置键，用不同NUXT_值启动同一构建并验证；不添加真实密钥。

先在自己的副本尝试，记录预期/实际与命令；不要直接复制操作卡结论。

## 验收标准

- [ ] public覆盖在客户端可观察，私有演示值未进入HTML/payload/客户端产物或API返回。
- [ ] 能解释.env开发读取与生产环境注入、SSR服务与静态部署的差别。

## 排错任务

用不匹配名称OTHER_SITE_NAME启动后界面没变；检查结构和NUXT_命名，修正后重启，不靠重写源码假装运行时覆盖。

保留故障输入、具体表现、原因、修正和同条件复验。预期失败不是正常工程运行成功。

## 参考要点

- 公开/私有是传输边界，运行期/构建期是生效时机，两者分开说明。
- 静态部署没有按请求执行useRuntimeConfig的服务进程。

综合关联：核对资料库public标签与配置端点，在副本检验同一构建的覆盖与泄漏边界；不把布尔configured标志当生产安全审计。
