# 4.3.3.2 独立练习：Vue组件库选型：Nuxt UI、Vant与实际产品约束

## 动手任务

选一套候选库，在自己的隔离分支用真实表单和弹层做小样；记录版本、Nuxt/SSR与触控/键盘表现后决定。

在自己的副本先实现，保存修改与实际运行命令，再对照参考。

## 验收标准

- [ ] 比较结果至少覆盖需求、版本/SSR、交互/无障碍、主题与产物成本。
- [ ] 区分文档声明和自己实测；未安装/运行的库不写已通过。

## 排错任务

选择只支持Vue2的旧示例并尝试对照Vue3类型/API，指出不兼容证据；换成目标版本官方安装与组件API，不靠关闭类型检查解决。

记录“故障输入→现象→原因→修正→复验”，不能只写已解决。

## 参考要点

- 按产品约束减少候选，不要求一次装完全部流行库。
- 同一应用混入两套主题/弹层体系要有明确理由及集成验证。
