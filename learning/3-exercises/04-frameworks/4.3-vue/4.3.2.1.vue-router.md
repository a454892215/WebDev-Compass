# 4.3.2.1 独立练习：Vue Router：动态参数、懒加载、导航守卫与历史

## 动手任务

独立增加列表/详情/缺失页，支持id切换和一个query筛选；用导航守卫做明确的演示跳转但不添加伪安全承诺。

在自己的副本先实现，保存修改与实际运行命令，再对照参考。

## 验收标准

- [ ] 详情id1→id2不出现旧数据，返回/刷新/不存在id均有可解释结果。
- [ ] 链接是原生可导航锚点，能说明生产fallback与服务端授权责任。

## 排错任务

在onMounted只读取一次route.params.id，从详情1点详情2后保留旧内容；用computed/watch特定参数修复并保留回归。

记录“故障输入→现象→原因→修正→复验”，不能只写已解决。

## 参考要点

- 本例Router5.5.1使用基础公开API，不能把最新自动文件路由/loader实验特性无条件套给旧项目。
- SSR应用须按框架处理历史与实例；Nuxt已装配路由时不要再手工createRouter争夺职责。
