# 4.3.3.3 独立练习：Nuxt概览：Vue应用框架与4.5的学习入口

## 动手任务

根据一个列表/详情产品写Vue→Nuxt迁移清单；给静态宣传页与带会话动态应用分别选择运行模式和验证任务。

在自己的副本先实现，保存修改与实际运行命令，再对照参考。

## 验收标准

- [ ] 能说明Vue与Nuxt分工，不把Nuxt等同组件库或单一SSR模式。
- [ ] 静态托管/server能力、配置公开边界和每请求状态风险表述准确。

## 排错任务

将server/api目录直接复制到已预渲染静态托管并以为仍能运行，指出产物与托管不匹配；改用适当服务端目标或独立后端，不伪造静态API动态能力。

记录“故障输入→现象→原因→修正→复验”，不能只写已解决。

## 参考要点

- 先跑通4.5官方骨架与一个完整页面，再抽象Layers/模块。
- Nuxt默认约定可调整，但不能把别的主版本目录直接当当前事实。
