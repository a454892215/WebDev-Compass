# 4.3.3.1 独立练习：Vue单文件组件：template、script setup与scoped CSS

## 动手任务

独立建一个有label/input/button的小计数或草稿SFC，拆分到父组件，保留TS检查与样式边界。

在自己的副本先实现，保存修改与实际运行命令，再对照参考。

## 验收标准

- [ ] 两个实例各自拥有本地状态，修改一个不改另一个。
- [ ] vue-tsc与生产构建都通过，能解释scoped与Shadow DOM的差别。

## 排错任务

在副本删除Vue Vite插件后构建.vue，保留解析失败；恢复插件再通过。不要用把.vue改名.ts掩盖模板转换缺失。

记录“故障输入→现象→原因→修正→复验”，不能只写已解决。

## 参考要点

- 先定位入口→插件→组件导入，不能只检查文件扩展名。
- defineProps等宏的类型与运行规则由SFC编译环境提供。
