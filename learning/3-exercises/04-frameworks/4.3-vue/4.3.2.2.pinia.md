# 4.3.2.2 独立练习：Pinia：state、getters、actions与实例边界

## 动手任务

独立整理跨页收藏或阅读状态的store，用局部ref保存尚未提交草稿；增加一个getter和明确的action。

在自己的副本先实现，保存修改与实际运行命令，再对照参考。

## 验收标准

- [ ] 同应用两处状态一致，storeToRefs解构后getter仍实时变化。
- [ ] 第二Pinia实例不继承第一实例状态，刷新/持久化边界有明确说明。

## 排错任务

const { doneCount } = store取得普通值后修改条目，观察摘要不更新；用storeToRefs或直接store.doneCount修复。

记录“故障输入→现象→原因→修正→复验”，不能只写已解决。

## 参考要点

- defineStore工厂可导出；在不恰当的模块顶层调用useStore会依赖错误活跃实例。
- actions失败需要真实错误状态/回退，不能自动把所有网络操作等同成功。
