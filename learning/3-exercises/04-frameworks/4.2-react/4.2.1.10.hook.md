# 4.2.1.10 独立练习：自定义Hook：复用有状态逻辑而非共享实例

[理论](../../../1-notes/04-frameworks/4.2-react/4.2.1.10.hook.md) · [实验](../../../2-examples/04-frameworks/4.2-react/4.2.1.10.hook-demo.md)

## 动手任务

在React副本提取两个独立展开卡片的Hook，记录它与Vue composable的相同目标及调用/生命周期差异。

先在自己的副本尝试，再查参考。保存改动、命令、预期和实际；选修对照不要求把React放进Nuxt主工程。

## 验收标准

- [ ] 两个调用默认状态独立。
- [ ] 若Hook订阅外部资源，卸载时完整清理。

## 排错任务

在if(expanded)内部调用useToggle，再切换条件，观察Hook顺序错误；改为顶层无条件调用并由结果决定渲染。

记录具体输入→可观察故障→原因→修复→同条件复验。不要只写“修好了”，也不要删除规则掩盖问题。

## 参考要点

- React Hook的调用规则不能照抄Vue composable写法。
- 共享逻辑不等于共享状态。
