# 4.2.2.4 独立练习：lazy路由：按需代码、等待与失败

[理论](../../../1-notes/04-frameworks/4.2-react/4.2.2.4.react.lazy.md) · [实验](../../../2-examples/04-frameworks/4.2-react/4.2.2.4.react.lazy-demo.md)

## 动手任务

在React副本把低频帮助页拆成懒模块，比较Nuxt页面自动分块；提供等待和加载失败恢复方案。

先在自己的副本尝试，再查参考。保存改动、命令、预期和实际；选修对照不要求把React放进Nuxt主工程。

## 验收标准

- [ ] 生产产物确有独立动态模块。
- [ ] 失败与等待是不同状态，后续能离开或重试。

## 排错任务

模块只导出具名组件导致lazy失败；提供default导出或显式映射，并验证真实路由。

记录具体输入→可观察故障→原因→修复→同条件复验。不要只写“修好了”，也不要删除规则掩盖问题。

## 参考要点

- 加载和错误分别处理。
- 不以chunk数量作为性能得分。
