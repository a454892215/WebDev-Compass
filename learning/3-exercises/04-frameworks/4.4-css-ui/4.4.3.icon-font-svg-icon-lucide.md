# 4.4.3 独立练习：本地SVG图标：装饰、名称与外部资源边界

[理论](../../../1-notes/04-frameworks/4.4-css-ui/4.4.3.icon-font-svg-icon-lucide.md) · [实验](../../../2-examples/04-frameworks/4.4-css-ui/4.4.3.icon-font-svg-icon-lucide-demo.md)

## 动手任务

新增一个下载按钮：有文字时图标装饰；只显示图标时为按钮提供动作名称，比较可访问树。

先在自己的副本尝试，记录预期/实际与命令；不要直接复制操作卡结论。

## 验收标准

- [ ] 装饰图标不重复命名，纯图标动作仍有明确按钮名称。
- [ ] 独立信息图标有名称，图标加载失败时关键按钮含义不丢失。

## 排错任务

移除纯图标按钮aria-label后观察它失去动作名称；恢复名称，而不是仅给SVG添加“图标”这样的无意义描述。

保留故障输入、具体表现、原因、修正和同条件复验。预期失败不是正常工程运行成功。

## 参考要点

- 先判断图标作用，再决定名称放在哪里。
- currentColor在外部img与内联SVG中的继承边界不同。

综合关联：核对阅读资料卡片动作是否有可见文字或按钮名称；若新增图标，使用本地资源并验证装饰/信息区分，不为图标强装组件库。
