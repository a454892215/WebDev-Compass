# 1.1.3.1 Canvas 2D 绘图基础

> [← 返回 HTML 目录](./README.md) · [知识地图](../../../knowledge-map/01-foundation-stages-0-2.md)

## 一句话理解

canvas 提供位图绘图表面；画上去的矩形和文字不是可独立聚焦、查询的 DOM 节点。

## 工作方式与使用规则

Canvas 有两套尺寸：width/height 属性决定像素缓冲区，CSS 决定显示大小。只把 CSS 放大可能模糊；高 DPI 显示器可按 devicePixelRatio 放大缓冲区，再缩放绘图坐标。改变 width/height 会清空画面并重置状态，因此尺寸更新后需要重画。

2D 上下文由 getContext('2d') 获取，可能返回 null，应准备后备。常用 fillRect、strokeRect、beginPath、moveTo、lineTo、arc；样式是绘图状态，用 save/restore 隔离临时变化。

图表应提供同等文字/数据表，不能仅把说明放在只对不支持 Canvas 的浏览器才显示的后备内容里。Canvas 上的交互热点需要自己实现命中测试、键盘和可访问性，普通按钮仍使用 HTML。

跨源图片缺少合适 CORS 授权可能污染画布，随后导出像素失败。不要为了导出而绕过来源限制。

## 最小示例

```html
<canvas id="plot" width="320" height="120">销量：42 件。</canvas>
<p>销量：42 件。</p>
<script>
  const canvas = document.querySelector("#plot");
  const dpr = window.devicePixelRatio || 1;
  canvas.width = 320 * dpr;
  canvas.height = 120 * dpr;
  canvas.style.width = "320px";
  canvas.style.height = "120px";
  const ctx = canvas.getContext("2d");
  if (ctx) {
    ctx.scale(dpr, dpr);
    ctx.fillRect(0, 0, 42, 40);
  }
</script>
```

## 📱 移动端对照

接近 Android Canvas、Flutter CustomPainter；浏览器这里没有自动生成每个绘制对象的语义节点。SVG 更接近保留独立图形节点的矢量树。

## 常见误区

- CSS 尺寸等于绘图分辨率：高 DPI 需要额外处理。
- 用 canvas 绘制整个表单：会失去原生输入、选择、键盘和辅助技术能力。
- 每次 resize 后不重画：设置尺寸会清空缓冲区。
