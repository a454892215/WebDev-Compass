# 1.1.3.2 SVG 矢量图形基础

> [← 返回 HTML 目录](./README.md) · [知识地图](../../../knowledge-map/01-foundation-stages-0-2.md)

## 一句话理解

SVG 用形状、路径和文本节点描述矢量图；缩放时由浏览器重新绘制，不依赖固定像素截图。

## 工作方式与使用规则

viewBox="minX minY width height" 定义内部坐标系；外部 width/height 或 CSS 决定显示区域。rect、circle、path、text 等是 DOM 元素，可以用 CSS 和 JS 修改；复杂图形路径通常由绘图工具导出。

信息图形使用 role="img" 和关联 title/desc 的 aria-labelledby，复杂图表另提供可见文字或数据表。装饰 SVG 使用 aria-hidden="true"，不要把它的可聚焦后代隐藏后留在 Tab 顺序中。只有图标的按钮仍需要独立可访问名称。

内联 SVG 便于主题和交互；img 引用 SVG 更适合静态资源，但外层不能直接通过 CSS 选择内部路径。第三方 SVG 也可能包含脚本或外部引用，按不可信内容处理，不直接插入 innerHTML。

## 最小示例

```html
<svg viewBox="0 0 100 100" role="img" aria-labelledby="title desc">
  <title id="title">完成比例</title>
  <desc id="desc">已完成 70%。</desc>
  <circle cx="50" cy="50" r="40" fill="none" stroke="currentColor"></circle>
  <text x="50" y="55" text-anchor="middle">70%</text>
</svg>
```

## 📱 移动端对照

近似 Android VectorDrawable 的矢量概念，但内联 SVG 的子节点进入浏览器 DOM；Flutter SVG 库是否暴露独立节点取决于实现。

## 常见误区

- 只放绿色和红色传达状态：应有文字/形状补充。
- 把 title 当作所有复杂图表的完整替代：仍需可理解的数据描述。
- 任意 SVG 字符串都安全：必须考虑脚本与来源。
